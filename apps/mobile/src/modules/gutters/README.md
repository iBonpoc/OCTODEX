# Модуль Gutters (отключён)

Решение основателя 04.11.2026: сначала ядро для любых подрядчиков, модули потом.
Здесь лежит код модуля Gutters (быстрая смета по замерам, чертёж по фото, тестовый price book).
Экраны **не подключены** к приложению: у них нет маршрутов в `src/app/`, кнопок и настроек.
Когда модуль будет включаться в настройках компании, экраны вернутся как маршруты модуля и
будут заполнять строки универсальной сметы (`src/features/estimateDoc.ts`).
