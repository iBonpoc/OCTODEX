# Модуль Gutters

`module.ts` — описание модуля для реестра ядра (`src/modules/registry.ts`, спека 33 П15): места (заявка, объект, «＋»),
обработчик очереди (`data.ts`, module.op), чтение таблиц замера, экраны `/module/gutters/<screen>`.

- `draw/` — холст «Замер» (спека 33 П20, П21): рисунок, панель свойств (`AttrPanel.tsx`), фото (`Photos.tsx`).
- `canvas/` — чистая часть холста: сцена, подписи, правки и история, атрибуты (`attrs.ts`), хранение (`model.ts`).
- `geometry.ts` — рисунок → вход движка (`@octo/estimating-engine`, детали `gutterParts`).
- `bench/` — проверка скорости холста.

Старые экраны без маршрутов (быстрая смета, чертёж по фото, тестовый price book) удалены в M5e (спека 33 П21.12).
