# ADR-004. Карты, геокодинг и снимки для замера

- **Статус:** Proposed — needs founder/tech review **и ответ юриста (Б2)**; путь уточнён по юридическому исследованию (`../legal/legal-research.md` §2, LEG-18)
- **Дата:** 03.11.2026 (ревизия 03.11.2026: EagleView/Hover, уточнение по Esri)
- **Закрывает:** Д1, вход для Б2 (`03-prd/00-decisions-for-founder.md`); `06` §15 п. 1; `16` §15 п. 1
- **Связано:** `06-architecture.md` §10.4, PRD `06-gutters-module.md`, `08-map-dispatch.md`, `16-offline-sync.md`

## Контекст
Главная фича v1 — обвести гаттеры пальцем на снимке дома и получить длины в футах (`06`). Для этого нужны **три** права: (1) **обводить** снимок и получать из него данные (длины), (2) **хранить** снимок или его часть в объекте, (3) **кэшировать** офлайн на телефоне на 14 дней вперёд. Плюс отдельно: карта для диспетчеризации и геокодинг адресов с постоянным хранением координат.

**Вывод [Факт + Совет]:** PRD 06 предполагал «Google Static Maps или Mapbox» — **оба варианта для обводки нарушают условия**. Это не формальность: Google прямо приводит обводку контуров зданий по спутнику как пример запрета.

## Варианты
| Вариант | Плюсы | Минусы |
|---|---|---|
| A. Google или Mapbox «как все» | Дёшево, лучшее покрытие и качество | Нарушение условий → блокировка ключа и риск претензий; неприемлемо |
| **B. Nearmap как основной снимок для замера** | Лицензия под измерения; 5–7.5 см — точнее для ±2% (`06` §7.1); несколько облётов LA в год, даты снимков; модель «BYO key / кредиты» уже работает у RoofLink | Цена только по запросу, договор платформы; кэш/хранение — согласовывать отдельно |
| **C. Esri World Imagery (ArcGIS Location Platform)** | Явное разрешение на «data collection and editing»; официальный офлайн-слой; оплата по использованию | Разрешение для коммерческого SaaS и хранения — подтвердить; разрешение в LA [Проверить]: если ~30 см, точность замера хуже, нужен пилот |
| **D. «Своё фото / скриншот с калибровкой» + быстрый ввод** | Нет лицензионных рисков; работает офлайн всегда | Дольше и менее «вау»; масштаб по одной известной длине |
| E. Свой облёт/дрон | Полный контроль | Не для MVP |
| **F. Импорт отчётов EagleView / Hover по аккаунту подрядчика** | Лицензия и оплата — у подрядчика, Octo не хранит снимок; «замер по адресу» без своего договора на снимки; привычно роферам | Отчёт стоит денег подрядчику и приходит не мгновенно; нужна партнёрская заявка и OAuth/ключ подрядчика; Hover — только платные планы |

## Решение
**Слой снимков — заменяемый адаптер `ImageryProvider`; реалистичный путь для стартапа (`../legal/legal-research.md` §2, LEG-18)** [Совет]:

| Этап | Что | Условие |
|---|---|---|
| **MVP (срез 3)** | **D: своё фото / скриншот с калибровкой + быстрый ввод** (GUT-US-14) | Без лицензионного риска; работает офлайн всегда |
| **Срез 3–4** | **F: импорт отчётов EagleView / Hover по аккаунту самого подрядчика** (OAuth или ключ подрядчика): Octo хранит только числа и геометрию отчёта в пределах условий партнёра | Подать заявки в EagleView Developer и Hover Partners сейчас; адвокат читает партнёрские условия (§11.1 п. 18) |
| **Параллельно, без срока** | **C: Esri World Imagery** — только после **письменного** ответа Esri: коммерческий SaaS, сторонние мобильные приложения, хранение векторов и длин, офлайн «for Export». При «да» — Esri как основной слой (дёшево: 2 млн тайлов бесплатно, далее $0.15 / 1,000; 15–30 см) | **Pending:** до письменного подтверждения Esri в продукте не включается |
| **Позже (после первых платящих)** | **B: Nearmap** как Integration Partner (5–7.5 см), модель «ключ подрядчика / кредиты» | Переговоры; реально после первых клиентов |
| Идея на проверку | Открытые контуры зданий (Microsoft Building Footprints — ODbL; LA County Building Outlines) как стартовый контур без снимка | Лицензии (ODbL: атрибуция, share-alike для баз) [Проверить] |

1. **Не используем Google и Mapbox снимки для чертежа** (подтверждено исследованием 03.11.2026: Google Map Tiles API Policies запрещают «extracted, traced, or otherwise derived», image analysis и кэш, S20). Mapbox/Apple — только для показа карты (Apple MapKit: Map Data нельзя хранить, кроме временного кэша, S21).
2. **Пилот** (2 недели, когда будет доступ к Esri и/или EagleView/Hover): 20 объектов основателя — импорт отчёта EagleView/Hover vs Esri (если подтверждено) vs своё фото vs рулетка. Критерии: ошибка длины ≤ 2% на чистых снимках, дата снимка, деревья/тени, время загрузки ≤ 3 с на LTE, цена за чертёж для подрядчика.
3. **Модель данных** (`04` v0.3): вершины `DrawingRun.points` и `DrawingPoint` хранятся в **гео-координатах** (lat/lng, плюс локальная плоская проекция в футах для расчёта), снимок — подложка `Drawing.imagery_ref {provider, capture_date, bbox, zoom, attribution}`; `base_image_file_id` — только для `upload` или если лицензия разрешает хранение. Длины считаются из геометрии, не из пикселей → смена провайдера не меняет сметы.
4. **Офлайн-кэш** снимков (OFF-US-07) включается флагом провайдера `allows_offline_cache` с его TTL; иначе на офлайн-объекте предлагаем «своё фото» (`16` §7 «Спутниковые снимки — лицензия»).
5. **Карта (диспетчеризация, слои):** iOS — Apple MapKit через `react-native-maps` (без оплаты за загрузку [Проверить лимиты]); веб — Mapbox GL JS (только показ).
6. **Геокодинг:** Mapbox Geocoding **Permanent** — [Факт] постоянное хранение разрешено (§2.7.3), временные результаты хранить нельзя (§2.7.2) (F3). Google Geocoding не берём: координаты из Google можно кэшировать ограниченно (F2) [Проверить точный пункт для Geocoding API], а `Property.geo` хранится постоянно.
7. **Атрибуция** провайдера и дата снимка — всегда на чертеже и в PDF (если снимок в PDF разрешён договором; иначе в PDF только векторный чертёж).
8. **Флаги провайдера** в адаптере: `allows_tracing`, `allows_vector_storage`, `allows_image_storage`, `allows_offline_cache` (+ TTL), `allows_image_in_pdf`, `license_holder` (`octo` / `contractor`), `attribution_text`; источник импорта (`Drawing.imagery_ref.provider = eagleview | hover`, `report_id`) хранится вместе с геометрией.
9. **Дисклеймер точности** (LEG-18, §9.4 исследования): под итогом замера, в cut list и в смете из чертежа — «Измерения приблизительные — проверьте на месте перед заказом материалов».

## Последствия
- ✅ **Срез 3 больше не блокируется** ответом провайдеров: он строится на варианте D (своё фото + калибровка + быстрый ввод GUT-US-14). «Замер по адресу» приходит в срезе 3–4 через импорт EagleView/Hover (F), Esri — только после письменного подтверждения, Nearmap — позже.
- 📝 Действия сейчас: заявки EagleView Developer и Hover Partners; письменный запрос в Esri (4 вопроса из таблицы выше); юристу — партнёрские условия выбранных провайдеров.
- 💰 `02a` §1 (Google Static Maps ~$2/1,000) больше не верна: в MVP себестоимость снимка = 0 (своё фото); при импорте EagleView/Hover отчёт оплачивает подрядчик своим аккаунтом; Esri (если подтвердят) — по использованию; Nearmap — возможно кредиты снимков в модуле Gutters, как у RoofLink.
- ✅ Гео-геометрия чертежа полезна и для карты, повторных работ (чистка, guards) и будущего импорта Hover/EagleView/Solar-подобных контуров.
