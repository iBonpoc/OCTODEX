# ADR-004. Карты, геокодинг и снимки для замера

- **Статус:** Proposed — needs founder/tech review **и ответ юриста (Б2)**
- **Дата:** 03.11.2026
- **Закрывает:** Д1, вход для Б2 (`03-prd/00-decisions-for-founder.md`); `06` §15 п. 1; `16` §15 п. 1
- **Связано:** `06-architecture.md` §10.4, PRD `06-gutters-module.md`, `08-map-dispatch.md`, `16-offline-sync.md`

## Контекст
Главная фича v1 — обвести гаттеры пальцем на снимке дома и получить длины в футах (`06`). Для этого нужны **три** права: (1) **обводить** снимок и получать из него данные (длины), (2) **хранить** снимок или его часть в объекте, (3) **кэшировать** офлайн на телефоне на 14 дней вперёд. Плюс отдельно: карта для диспетчеризации и геокодинг адресов с постоянным хранением координат.

**Вывод [Факт + Совет]:** PRD 06 предполагал «Google Static Maps или Mapbox» — **оба варианта для обводки нарушают условия**. Это не формальность: Google прямо приводит обводку контуров зданий по спутнику как пример запрета.

## Варианты
| Вариант | Плюсы | Минусы |
|---|---|---|
| A. Google или Mapbox «как все» | Дёшево, лучшее покрытие и качество | Нарушение условий → блокировка ключа и риск претензий; неприемлемо |
| **B. Nearmap как основной снимок для замера** | Лицензия под измерения; 5–7.5 см — точнее для ±2% (`06` §7.1); несколько облётов LA в год, даты снимков; модель «BYO key / кредиты» уже работает у RoofLink | Цена только по запросу, договор платформы; кэш/хранение — согласовывать отдельно |
| **C. Esri World Imagery (ArcGIS Location Platform)** | Явное разрешение на «data collection and editing»; официальный офлайн-слой; оплата по использованию | Разрешение для коммерческого SaaS и хранения — подтвердить; разрешение в LA [Проверить]: если ~30 см, точность замера хуже, нужен пилот |
| **D. «Своё фото / скриншот с калибровкой» + быстрый ввод** | Нет лицензионных рисков; работает офлайн всегда | Дольше и менее «вау»; масштаб по одной известной длине |
| E. Свой облёт/дрон | Полный контроль | Не для MVP |

## Решение
**Слой снимков — заменяемый адаптер `ImageryProvider`; в MVP: D всегда + B или C по итогам пилота и ответа юриста** [Совет]:
1. **Не используем Google и Mapbox снимки для чертежа.** Mapbox/Apple — только для показа карты.
2. **Пилот до среза 3** (2 недели): 20 объектов основателя — Nearmap (trial) vs Esri vs рулетка. Критерии: ошибка длины ≤ 2% на чистых снимках, дата снимка, деревья/тени, время загрузки ≤ 3 с на LTE, цена за чертёж. Параллельно — письменные условия: Esri (коммерческий SaaS, хранение снимка в объекте, офлайн), Nearmap (платформенный договор, кредиты, офлайн 14 дней, хранение).
3. **Модель данных** (`04` v0.3): вершины `DrawingRun.points` и `DrawingPoint` хранятся в **гео-координатах** (lat/lng, плюс локальная плоская проекция в футах для расчёта), снимок — подложка `Drawing.imagery_ref {provider, capture_date, bbox, zoom, attribution}`; `base_image_file_id` — только для `upload` или если лицензия разрешает хранение. Длины считаются из геометрии, не из пикселей → смена провайдера не меняет сметы.
4. **Офлайн-кэш** снимков (OFF-US-07) включается флагом провайдера `allows_offline_cache` с его TTL; иначе на офлайн-объекте предлагаем «своё фото» (`16` §7 «Спутниковые снимки — лицензия»).
5. **Карта (диспетчеризация, слои):** iOS — Apple MapKit через `react-native-maps` (без оплаты за загрузку [Проверить лимиты]); веб — Mapbox GL JS (только показ).
6. **Геокодинг:** Mapbox Geocoding **Permanent** — [Факт] постоянное хранение разрешено (§2.7.3), временные результаты хранить нельзя (§2.7.2) (F3). Google Geocoding не берём: координаты из Google можно кэшировать ограниченно (F2) [Проверить точный пункт для Geocoding API], а `Property.geo` хранится постоянно.
7. **Атрибуция** провайдера и дата снимка — всегда на чертеже и в PDF (если снимок в PDF разрешён договором; иначе в PDF только векторный чертёж).

## Последствия
- ⛔ **Блокер среза 3:** без письменного «да» от Esri или договора с Nearmap срез 3 строится на варианте D (своё фото + калибровка + быстрый ввод GUT-US-14) — функция работает, но без «снимок по адресу».
- 💰 `02a` §1 (Google Static Maps ~$2/1,000) больше не верна: себестоимость снимка пересчитать после ответа Nearmap/Esri; возможно — кредиты снимков в модуле Gutters, как у RoofLink.
- ✅ Гео-геометрия чертежа полезна и для карты, повторных работ (чистка, guards) и будущего импорта Hover/EagleView/Solar-подобных контуров.
