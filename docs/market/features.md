# Матрица функций: Jobber · Workiz · Housecall Pro · ServiceTitan · OCTODEX

Дата: 06.11.2026. Снимок OCTODEX — `main` после сборки 148. Подробности по продуктам — `jobber.md`, `workiz.md`, `others.md`. Отметки HCP с пометкой «(скр. 06.11)» — по скриншотам основателя 06.11 (`others.md` §1.4).

**Решения принимают основатель и руководитель.** Колонка «Предложение» — только предложение.

**Как читать**
- Колонки продуктов: ✅ есть · ◐ частично, только в дорогом тарифе, бета или через партнёра · — нет · ? не проверено.
- «OCTODEX сейчас»: ✅ работает · ◐ частично · 🎭 имитация (выглядит настоящим, но не работает) · — нет.
- «В плане»: где запланировано. Шкалы из наших документов: волны каркаса `docs/specs/13-app-structure.md` v2 (1–9, С, П, 7а, 7б, «Запуск», «Пуши»), шаги `docs/10-build-plan.md`, волны лидов L1–L6 (`docs/14-leads-spec.md`), смет E1–E3 (`docs/specs/07-estimates.md`), почты П1b, PRD (`docs/03-prd/*`), клетки карты `docs/15-story-map.md` (кл.). «—» — нигде не запланировано.
- «Предложение»: **MVP** · **Запуск** · **Позже** · **Не брать** · **Вопрос** (решает основатель) · **есть** (уже сделано, держать).
- **★** — функция есть у всех четырёх лидеров, у нас её нет и в плане её нет. Это главные пробелы.

## Топ-15 пробелов

Порядок — по пользе для подрядчика. ★ — нет даже в плане.

1. **Настоящая оплата картой и ACH** (сейчас 🎭). У всех есть. Деньги вперёд — главное, за что платят. План: шаг 20, Запуск. Вопрос: раньше?
2. **Отправка писем с сервера** (сейчас 🎭, ждёт домен П1b). Без неё клиент не получает копию договора и счёт без телефона подрядчика.
3. **5 готовых автонапоминаний:** ответ на лид, дожим сметы, напоминание о визите, напоминание об оплате, просьба об отзыве (PRD 13). У всех есть.
4. **★ Учёт времени: смена, табель, журнал, отчёт.** У всех четырёх, у нас нет ни в коде, ни в волнах. Дешёвый путь — табель сам из шагов выезда (как у ServiceTitan).
5. **★ Часовая ставка × время в прибыли работы.** Без неё «прибыль» завышена. Идёт вместе с п. 4.
