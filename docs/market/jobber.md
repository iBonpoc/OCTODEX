# Jobber — полная шпаргалка

Дата: 06.11.2026. Источники: 42 скриншота основателя (05.11.2026, iPhone, пробный период, версия приложения 6.101) и справка Jobber (см. `README.md`). Описано нашими словами. Английское имя дано один раз в скобках.

**Главная мысль Jobber.** Всё стоит на одной цепочке: **Заявка → Смета → Работа (визиты) → Счёт → Оплата**. Каждый шаг превращается в следующий одной кнопкой, данные переносятся сами. Телефон сделан для работы в поле, веб — для офиса; часть настроек есть только в вебе.

**Тарифы** (снизу вверх, каждый включает предыдущий): **Core** (1 человек) → **Connect** → **Grow** → **Plus**. Есть платные дополнения: маркетинг-пакет, ИИ-ресепшн, доска продаж. Цены сюда не пишем.

Содержание: 1. Навигация · 2. Экраны со скриншотов · 3. Все функции по разделам · 4. Роли и права · 5. ИИ · 6. Только телефон / только веб / офлайн · 7. Настройки · 8. Что понравилось · 9. Что неудобно · 10. Чего нет на скриншотах.

## 1. Навигация

### 1.1 Телефон
- **5 нижних вкладок:** Главная (Home) · Расписание (Schedule) · Учёт времени (Timesheet) · Поиск (Search) · Ещё (More). Активная вкладка отмечена тёмной полоской над значком.
- **Поиск** — это и вход во все списки: клиенты, заявки, сметы, работы, счета. Отдельных вкладок под документы нет.
- **Круглая тёмная «+»** справа внизу на каждом экране с вкладками. Что внутри (по справке): клиент, заявка, смета, работа, счёт, расход, задача. На экране визита вместо «+» стоит кнопка «Камера».
- **Кнопка ИИ** (значок с искрами) в правом верхнем углу **каждого** экрана, даже в формах и в окне тарифов.
- **Шапка главной:** «пилюля» «осталось N дней пробного периода», значки «сообщения», «колокольчик», «ИИ».
- **Плашка «подтвердите почту»** серой полосой над шапкой на всех экранах, пока почта не подтверждена.
- **Формы создания** открываются на весь экран: слева крестик, по центру заголовок, справа ИИ; внизу одна широкая зелёная кнопка «Сохранить», прибита к низу.
- **Подэкраны «Ещё»** открываются со стрелкой «назад».

### 1.2 Веб (и сайт в браузере телефона)
- **Левое меню по порядку:** Создать · Главная · Расписание · Клиенты · Заявки (Requests) · Сметы (Quotes) · Работы (Jobs) · Счета (Invoices) · Маркетинг · ИИ-ресепшн · Отчёты (Insights) · Расходы · Учёт химии · Табели · Сообщество · Приложения. «Расходы» и «Учёт химии» видны только после включения в настройках.
- **Верхняя панель:** общий поиск (клиенты, адреса, номера документов, позиции, свои поля), колокольчик (лента событий), центр сообщений, «?», шестерёнка (настройки, команда, бета-функции, тема), ИИ.
- В браузере телефона сверху голубая полоса системных объявлений («1 из 2»), счётчик пробного периода и кнопка «Выбрать тариф».

### 1.3 Меню «Ещё» (телефон), сверху вниз
1. Название компании.
2. **Карточка «Состояние»:** «В сети» (зелёный квадрат), «Всё синхронизировано», «В сети уже N мин». Это показатель синхронизации.
3. Большие плитки по 2 в ряд: **Платежи** · **Приложения и интеграции** · **Маркетинг**.
4. Строки: Поддержка · Подписка · Что нового · Пригласить друга (реферальная программа самого Jobber) · О приложении.
5. Строки: Профиль · Команда · Данные компании · Настройки.
6. **Выйти** — красным.

## 2. Экраны со скриншотов

### 2.1 Главная (Home)
Открывается после входа. Сверху вниз:
1. Плашка «подтвердите почту».
2. Слева «пилюля» пробного периода (ведёт к тарифам), справа сообщения · колокольчик · ИИ.
3. Крупное приветствие по имени и времени суток («Добрый день, …»).
4. Дата и **погода** (значок, температура, «ясно»).
5. Карточка «Давайте начнём» с зелёной кнопкой **«Начать смену»** (Clock In) — запуск учёта времени прямо с главной.
6. **Карта** во всю ширину с точками визитов на сегодня. Ссылка «Все ›» → экран «Визиты на сегодня».
7. **Лента карточек визитов** — листается вбок, виден край следующей. Пустая — карточка с пунктирной рамкой «+ Запланировать новую работу».
8. **«Эта неделя»** с датами и ссылкой «Табель»: «Всего отработано 00:00».
9. **«Сделать»** (To do) — шаги первой настройки, у каждого значок, заголовок, подпись, стрелка: сделать первую смету, собрать список клиентов, закончить настройку аккаунта, попробовать веб-версию.
10. **«Здоровье бизнеса»** (Business health), «Все»: стоимость работ за неделю и число визитов за неделю, у каждой цифры процент к прошлой неделе.
11. **«Открыть для себя»** — скрываемая крестиком лента промо-карточек (например, форум сообщества).
12. Кнопка-контур «Получить помощь».

### 2.2 Учёт времени (Timesheet)
Две вкладки сверху: **«Учёт»** и **«Журнал»**.
- **«Учёт»:** серая плашка «Не на смене» → большой таймер 00:00:00 → «Всего сегодня: 0 мин» → зелёная «Начать смену» → **«Что учитывать»** сеткой 3×2: Визит · Дорога · Офис · Закупка материалов · Перерыв · Общее. Время пишется по типу.
- **«Журнал»:** переключатель дня «‹ Сегодня ›», строки сотрудников с инициалами (свернуть или развернуть), пусто — «Время не записано». Владелец видит всех.

### 2.3 Визиты на сегодня (Today's appointments)
Главная → карта → «Все ›». Три фильтра-таблетки: **Выполнены** (выбран по умолчанию) · **Идут сейчас** · **Предстоят**. Пустой список — просто серый фон без подсказки.

### 2.4 Новый клиент (New client)
1. Кнопка-контур **«Добавить из контактов»** — берёт человека из телефонной книги.
2. Имя, Фамилия.
3. Ссылка «+ Название компании» (поле появляется по нажатию).
4. «+ Телефон», «+ Почта», «+ Источник лида».
5. «Адрес объекта» (Property address).
6. «Сохранить».

Клиент и объект создаются одной формой. Необязательные поля спрятаны за «+ …».

### 2.5 Новая работа (New job)
Сверху вниз:
1. **Клиент:** «Выбрать существующего клиента» или поля нового клиента прямо тут (имя, фамилия, адрес объекта, «+ Телефон», «+ Почта»).
2. **Описание:** название работы, «Инструкции» для мастера.
3. **Товары и услуги:** строка «Позиции» с «+».
4. **Итоги:** подытог, скидка (нажимается), налог (нажимается), итого.
5. **Расписание:** переключатель **«Запланировать позже»** (по умолчанию выкл). Когда выкл — календарь месяца (неделя с воскресенья, сегодня подчёркнуто). Время визита и повтор на видимой части не видны.
6. **Бригада:** по умолчанию назначен сам владелец, стрелка — выбрать людей.
7. **Счёт:** переключатель **«Напомнить выставить счёт, когда закрою работу»** (по умолчанию вкл).
8. «Сохранить».

### 2.6 Новая смета (New quote)
**Шторка «Создать новую смету»** — 4 способа:
- плитка **«Голос ИИ»** — продиктовать, ИИ собирает смету;
- плитка **«Пробная смета»** — отправить себе и посмотреть, как увидит клиент;
- строка **«По шаблону»**;
- строка **«Вручную»**.

**Форма сметы:**
- верх: «Для кого» — выбрать клиента или ввести нового (имя, фамилия, адрес, «+ Телефон»);
- середина: позиции и итоги (на скриншотах не снята);
- низ, сверху вниз: **«Обязательный задаток»** (нажимается) → **«Вложения»** (файлы, миниатюра документа) → **«Фото»** (ряд фото объекта) → **«Отзывы»** «+» (прикрепить отзывы клиентов к смете) → **«Сообщение клиенту»** → **«Договор / оговорка»** с текстом по умолчанию (смета действует 30 дней) → зелёная **«Проверить и отправить»** и текстовая «Сохранить».

Основателю особенно понравилось: **вложения (документы) и фото — два отдельных блока**.

### 2.7 Позиция сметы (Edit line item)
1. Название (подтянулось из каталога).
2. Описание из каталога, можно править.
3. **«Прикрепить фото»** — у каждой строки своё фото.
4. Цена за единицу, Количество (по умолчанию 1).
5. Переключатель **«Необязательная позиция»** — клиент сам решит, добавить ли.
6. Когда «необязательная» включена, появляется **«Рекомендовать»** — позиция уже отмечена у клиента, клиент может снять.
7. Итого строки.
8. Зелёная «Сохранить позицию» и квадратная «…» (ещё действия).

### 2.8 Задаток (Add required deposit)
Переключатель-таблетки **«Процент (%)» · «Сумма ($)»** → поле → сразу под ним пересчёт в долларах → цифровая клавиатура открывается сама → «Сохранить задаток».

### 2.9 Уведомления
Колокольчик на главной. Две вкладки: **«Упоминания»** (Mentions) и **«События»** (Activity). Пусто: значок «@», «здесь появятся упоминания коллег», ссылка на справку «как отмечать коллег в заметках». То есть в заметке пишут @имя — человеку приходит уведомление.

### 2.10 Настройки (Preferences)
1. **Оформление:** три плитки с картинкой-образцом — Системная · Светлая · Тёмная.
2. **Фото и видео:** «Сохранять фото и видео на телефон» (копия снятого попадает в галерею).
3. **Push-уведомления**, все включены по умолчанию: сводка работ на сегодня · изменилось расписание на сегодня · новая заявка · новая онлайн-запись · клиент открыл смету · клиент одобрил смету · идёт таймер (не забыть выключить).

### 2.11 О приложении (About)
- Сведения: версия приложения, почта аккаунта, **часовой пояс аккаунта** и текущее время в нём, модель телефона и iOS, **состояние связи** («В сети, N с»).
- Ссылки: политика конфиденциальности, условия.
- Три кнопки самопомощи: **«Очистить весь кэш»** · **«Починить push-подписки»** · **«Сбросить счётчик уведомлений»**.

### 2.12 Поддержка (Support)
Строки: чат с поддержкой (живые люди) · справочный центр · видео-уроки · **«Поделиться диагностикой»** (данные устройства копируются в буфер) · **«Показать экран»** поддержке.

### 2.13 Добавить сотрудника (Add new user)
1. «Добавить из контактов».
2. Полное имя, почта, мобильный телефон.
3. Роль: новые получают «Работник (ограниченный доступ)»; менять права — только в вебе.
4. Серая карточка роли — что можно и нельзя: ✓ своё расписание и отметка «выполнено» · ✓ данные клиента по своим работам · ✓ своё время · ✓ заметки; ✗ цены · ✗ приём оплаты.
5. «Отправить приглашение».

### 2.14 Выбор тарифа (Choose a plan)
- Синяя «i»: сколько дней пробного периода осталось.
- **Карусель из 5 карточек** (листать вбок, точки снизу). В каждой: название, одна фраза, список с галочками, кнопка «Выбрать тариф».
  - Core: онлайн-запись и расписание, сметы, счета и онлайн-оплаты, отчёты, 1 человек.
  - Connect: + автонапоминания и автоплатежи, напоминания по неоплаченным счетам, чек-листы.
  - Grow: + необязательные позиции, фото и напоминания по сметам, себестоимость работ, двусторонние SMS.
  - Те же Connect и Grow на 5 и 10 человек.
- Внизу: оплата через Apple ID, пробный период при покупке кончается, подписка продлевается сама, отменить — в настройках Apple.

### 2.15 Маркетинг (Marketing Suite) — открывается в Safari
Не экран приложения, а страница сайта Jobber (вверху «◀ Jobber» — вернуться). В пробном периоде это описание пакета, а не сам инструмент. Что в пакете:
- **Отзывы:** просьба об отзыве в Google по SMS или почте сама уходит после визита, после закрытия работы или после оплаты счёта. У клиента переключатель «Просить отзыв: да / нет». ИИ пишет черновик ответа на отзыв. Панель: средняя оценка и число отзывов с ростом. Сравнение с местными конкурентами по отзывам.
- **Рефералы:** клиент приводит друга и получает бонус.
- **Рассылки:** письма по своей базе клиентов (фото работы, кнопка).

## 3. Все функции по разделам (по справке)

Тариф: «все» — на всех тарифах; Core / Connect / Grow / Plus — начиная с этого тарифа; «доп.» — платное дополнение; «бета» — не у всех.

### 3.1 Заявки и онлайн-запись
| Функция | Как работает | Тариф |
|---|---|---|
| Заявка (Request) | Карточка «клиент хочет работу»: название, клиент, желаемая дата, источник, ответы формы, позиции. Статусы: новая → не назначена → просрочена → осмотр выполнен → превращена (в смету или работу) → архив | все |
| Осмотр (Assessment) | Выезд по заявке с исполнителем, сразу в календаре. На осмотр вешается чек-лист | все |
| Лид = метка клиента | Новый человек сразу клиент с меткой «лид». Метка снимается сама: одобрена смета, создана работа или отправлен счёт | все |
| Конструктор формы заявки (Request forms) | Свои вопросы, обязательные поля, вставка на сайт. Только админ | все |
| Онлайн-запись (Online booking) | Клиент сам выбирает свободное время. Два вида: запись на осмотр (создаётся заявка + осмотр) или сразу на работу (разовая работа с визитом); на одной форме один вид. До 100 услуг, у каждой длительность 15 мин – 12 ч. Исполнитель подбирается по рабочим часам. Самое раннее время записи, шаг слотов. «Умное расписание»: учёт дороги (нужен адрес), фиксированный зазор или без ограничений. Отпуск блокирует запись только как задача. Подтверждение клиенту уходит само | все |
| Запись через Google (AI Mode / Reserve) | Клиент записывается прямо из поиска Google, заявка падает в Jobber. Только США, с ноября 2026 | ? |

### 3.2 Клиенты и объекты
| Функция | Как работает | Тариф |
|---|---|---|
| Карточка клиента | Телефоны, почты, условия оплаты, источник лида, метки, свои поля; доп. контакты; объекты; обзор документов с фильтром по типу и объекту; деньги (счета, оплаты, депозиты, баланс, сохранённые карты); прошлые и будущие визиты; выручка за всё время, последнее сообщение, заметки, файлы | все |
| Вкладки клиента | Переписка · Информация · Файлы и медиа | Файлы и медиа — Plus |
| Свой порядок блоков (Customize view) | Каждый пользователь сам переставляет блоки карточки | все |
| Объекты (Properties) | Несколько адресов у клиента, у каждого свой налог, контакты, поля | все |
| Свои поля (Custom fields) | У клиента, объекта, сметы, работы, счёта, сотрудника | все |
| Импорт и экспорт клиентов | Только админ | все |
| Клиент из телефонной книги | «Добавить из контактов» | все |

### 3.3 Портал клиента (Client hub)
| Функция | Как работает | Тариф |
|---|---|---|
| Вход без пароля | По ссылке из письма или SMS. Через 14 дней просит подтвердить: почта или 4 последние цифры телефона | все |
| Что может клиент | Одобрить смету (с подписью или без), попросить изменения, внести депозит, оплатить счёт целиком или «другую сумму», скачать PDF и квитанции, видеть прошлые и 5 ближайших визитов, отправить новую заявку, пригласить друга | все |
| Настройки портала | Ссылка на портал в напоминаниях и в SMS «в пути»; видит ли клиент все документы или только по ссылке; подпись обязательна; кнопка «Попросить изменения» (смета скрывается, пока не отправят заново); показывать время визита или только дату; новые заявки из портала; баннер «пригласи друга» | все |

### 3.4 Сметы (Quotes)
| Функция | Как работает | Тариф |
|---|---|---|
| Смета | Внутреннее название, клиент, продавец, свои поля, до 100 позиций, скидка, налог, депозит, «что видит клиент», сообщение, договор или оговорка, история изменений. Каждая секция правится своим карандашом | все |
| Статусы | Черновик → ждёт ответа → просят изменения → одобрена → превращена в работу; архив с причиной («дорого») | все |
| Смета → работа | Два нажатия, позиции, цены, название и продавец копируются | все |
| Грубая оценка → смета | Сначала примерная цифра, потом точная смета | все |
| Шаблоны смет | Сметы на частые работы | все |
| Пробная смета себе | Посмотреть глазами клиента до отправки | все |
| Смета голосом | Продиктовать, ИИ собирает | все (админ) |

## 4. Роли и права

Где: шестерёнка → Команда → человек. Права меняет только админ, **только в вебе**. У человека: рабочие часы (их учитывает онлайн-запись), часовая ставка (для себестоимости), цвет в календаре. Права — с тарифа Connect; Core — для одного человека.

**Готовые уровни** (каждый включает предыдущий):
| Уровень | Может | Не может |
|---|---|---|
| Полевой рабочий (Field crew) | Своё расписание, закрыть свои визиты, заметки и фото к своим работам, таймер | Чужое расписание, цены, затраты, ручная правка табеля |
| Старший рабочий | + файлы клиента, цены, создавать и править клиентов, сметы, работы, счета, принимать оплату | Чужое расписание и табели, отчёты |
| Бригадир (Crew lead) | + всё расписание с правкой, все табели, переписка с клиентами | Маркетинг, отчёты |
| Менеджер | + отчёты, маркетинг, продажи | Добавлять людей, настройки |
| Свой (Custom) | Любой набор переключателей | |
| Админ (галочка) | Всё: компания, команда, платежи, чек-листы, письма, приложения, подписка, импорт и экспорт, отчёты платежей, подтверждение зарплаты | |

**Переключатели своего уровня**
- Расписание: своё смотреть → смотреть и закрывать → своё править → чужое править → чужое править и удалять.
- Время: свой таймер → своё время вводить и править → время всех.
- Заметки: только по работам и визитам → все → все с правкой → с правкой и удалением.
- Клиенты: только имя и адрес → вся информация → с правкой → с удалением; показывать ли раздел.
- Заявки, сметы, работы, счета: нет → смотреть → смотреть, создавать, править → + удалять; показывать ли раздел.
- Вкл/выкл: показывать цены · себестоимость · расходы · файлы и медиа · маркетинг · продажи · переписка с клиентами · оплаты · двусторонние SMS.
- Отчёты — видны только те, что разрешают остальные права.

На телефоне при приглашении роль выбрать нельзя: человек получает «Работник (ограниченный)» — без цен и без приёма оплаты.

## 6. Только телефон / только веб / офлайн

- **Только телефон:** ИИ-голос, Tap to Pay, автотаймер по месту и GPS-точки, «Камера» на визите, CarPlay и Android Auto, «Собрать подпись» на месте.
- **Только веб:** события календаря, оптимизация маршрута, варианты сметы, задачи и заметки в продажах, конструктор форм, почти все отчёты, права ролей, большинство настроек. Маркетинг на телефоне открывается в браузере.
- **Офлайн:** долго официально «нет», работали только заметки (пропадали при выходе или обновлении), файлы без сети не прикреплялись. 18.03.2026 вышло обновление «работать без интернета» — что именно работает, не проверено. Обзоры пишут: без сети нельзя создать работу и принять оплату. В меню «Ещё» есть карточка «В сети / Всё синхронизировано».

## 8. Что понравилось (основателю и нам)

Основателю Jobber нравится больше, чем Workiz.

1. **Вложения и фото в смете — два отдельных блока** (основатель хочет у нас).
2. **Короткие формы:** необязательные поля за «+ Добавить …».
3. **Клиент создаётся прямо в смете и в работе.**
4. **«Добавить из контактов»** в новом клиенте и в приглашении сотрудника.
5. **Позиция сметы:** фото у строки, «необязательная», «рекомендовать».
6. **Задаток процентом или суммой** с мгновенным пересчётом в доллары, цифровая клавиатура сама.
7. **4 способа начать смету:** голосом, пробная себе, по шаблону, вручную. Особенно «пробная смета себе».
8. **Отзывы клиентов и фото работ внутри сметы** — доверие.
9. **Договор или оговорка с текстом по умолчанию.**
10. **«Напомнить выставить счёт при закрытии работы»** (по умолчанию вкл) и вопрос после визита «счёт сейчас / позже / оставить открытой».
11. **«Начать смену» на главной** и учёт времени по типам (дорога, закупка, перерыв).
12. **Карточка «В сети / Всё синхронизировано»** — нам с офлайном нужен такой же понятный показатель.
13. **Пуши по событиям с выключателями** (клиент открыл или одобрил смету, изменилось расписание, идёт таймер).
14. **Роль «Работник» без цен и без оплаты по умолчанию** и карточка «что можно / нельзя» при приглашении.
15. **@упоминания коллег** в заметках и вкладка «Упоминания».
16. **Самопомощь:** диагностика в буфер, показ экрана, «починить пуши», «очистить кэш».
17. **Главная с итогами недели** и процентом к прошлой неделе.
18. **Автозапрос отзыва после оплаты** с выключателем у каждого клиента.
19. **Таблица прав «смотреть / создавать / править / удалять»** по объектам + «показывать цены».
20. **Тема: системная / светлая / тёмная** плитками с образцом.
21. **«Визиты на сегодня»: Выполнены · Идут · Предстоят.**

## 9. Что неудобно или не брать

1. **Кнопка ИИ на каждом экране**, даже в окне тарифов и задатка, — шум и занимает угол для «Готово».
2. **Верх главной забит служебным:** «пилюля» пробного периода, 3 значка, плашка «подтвердите почту».
3. **Карта на пол-экрана, когда визитов нет** (показывает весь континент).
4. **Онбординг и промо на главной** («попробуйте на компьютере», форум) мешают работе.
5. **Маркетинг открывается в браузере** и там описание, а не инструмент.
6. **Права ролей только в вебе.** У нас всё с телефона.
7. **«Визиты на сегодня» без пустого состояния** — серый экран.
8. **Календарь в форме работы** с воскресенья, без времени на виду; дни следующего месяца серой плашкой похожи на выделение.
9. **Тарифы каруселью** — сравнить нельзя.
10. **Покупка через Apple ID** — комиссия магазина, сложный возврат (для нас — решение основателя и юриста).
11. **Тип работы (разовая / повторная) нельзя сменить**, работы не объединить.
12. **Самое ценное — в дорогих тарифах** (SMS, автоматизации, ресепшн, необязательные позиции).
13. **Телефон беднее веба:** нет отчётов, событий, маршрута, вариантов сметы.
14. **ИИ-чат не создаёт записи** — только голос.
15. **Зелёный цвет не только для статуса** (кнопки, ссылки, переключатели). У нас цвет только для статуса, один акцент для главного действия.
16. **Кнопки и поля крупнее наших правил** (поля около 60 pt, кнопки во всю ширину выше 36).
