# Правки прототипа по Jobber (и немного по Workiz)

Дата: 06.11.2026. Для следующего шага: правка прототипа OCTODEX. Основа — скриншоты Jobber (основателю он нравится больше Workiz), заметки основателя 06.11 и `features.md`.

**Это список предложений, не решений.** Решают основатель и руководитель. Перед кодом по каждой правке — этап 0 (`docs/ai/WORKER.md`): найти клетку в `docs/15-story-map.md`, написать коротко в спецификацию, зачем это OCTODEX.

**Что не переносим из Jobber, даже если нравится** (наши правила в `CLAUDE.md`):
- кнопку ИИ на каждом экране — ИИ у нас ещё нет, а пустой угол нужен для «Готово»;
- зелёный акцент на ссылках и переключателях — у нас один акцент `acc` только для главного действия, цвет — только статус со значком и словом;
- поля около 60 pt и кнопки во всю ширину выше 36 — у нас видимая кнопка ≤ 36, зона нажатия 44, поле 44;
- полосы «подтвердите почту» и «пробный период» на каждом экране — у нас одна строка в «Требует внимания»;
- настройки только в вебе — у нас всё с телефона, на всех 3 ширинах;
- карту на пол-экрана при пустом дне — у нас пустое состояние с действием.

Каждая правка: новый экран — в `SCREENS` спеки `08-layouts`; e2e на 6 видах (3 ширины × 2 темы); все строки через i18n (RU / EN / ES); необратимое — с «Отменить».

Колонка «Чьи файлы» — по таблице направлений в `CLAUDE.md`: **ЛК** — «Лиды и клиенты», **СГ** — «Сметы и модуль Gutters», **КС** — «Дизайн системы карточек списков», **Рук** — руководитель. Колонка «Когда» — волна из `docs/specs/13-app-structure.md` v2, если правка туда ложится.
