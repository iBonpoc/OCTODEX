# Housecall Pro и ServiceTitan — коротко

Дата: 06.11.2026. Housecall Pro: справка (см. `README.md`) и 29 скриншотов основателя 06.11 (§1.4). ServiceTitan: скриншотов нет, только справка. Скриншоты ServiceTitan основатель пришлёт позже — дописать сюда и в `features.md`. Описано нашими словами.

---

## 1. Housecall Pro (HCP)

**Главная мысль.** «Малый бизнес, всё в одном». Сильные стороны: доска продаж (лиды → сметы → работы), «ИИ-команда» с ролями, маркетинг (рассылки, открытки, сайт, отзывы), деньги (карты расходов, зарплата, бухгалтерия под ключ), готовые наборы под нишу (HVAC, сантехника, электрика).
**Тарифы:** три уровня (Basic, Essentials, Max) по числу людей; ИИ на звонках — отдельно. Цены сюда не пишем. Что в каком тарифе и что продаётся надстройкой — §1.4.11 (по скриншоту 06.11).
Ссылка на статью: `https://help.housecallpro.com/en/articles/<номер-имя>`.

### 1.1 Навигация
- **Левое меню (май 2026):** «+ Create», Клиенты, Работы, Сметы, Лиды, Счета, Каталог; группы Связь, Деньги, Маркетинг, Отчёты, Команда; ниже «Мои приложения» и Настройки. Сверху поиск, карта, колокольчик, задачи, лента событий.
- **«Мои приложения» (My Apps)** — включение функций (время, табели, абонементы, профиль объекта), как Центр функций у Workiz.
- **Пересборка 2026:** у работы и сметы вкладки по типу данных и **постоянная панель внизу** (время, «Еду», «Начал», «Закончил»); свайп вверх по панели — фото и заметка с любой вкладки.
- **Общий поиск:** клиенты, работы, сметы, счета, оборудование, до 5 в группе.
- **Лента событий** по компании, клиенту, работе. **Центр уведомлений:** для каждого вида — кому и как (браузер, колокольчик, пуш).
- **Главная в телефоне:** сверху полоса **«Требует внимания»** (без даты, не оплачено — только свои), кнопка «приход / уход» и табель недели, **«Открытая работа»** (сегодня, начато не закончено, закрыто сегодня).

### 1.2 Функции по разделам
- **Лиды:** лиды на всех тарифах. **Доска продаж (Pipeline):** 3 доски (лиды, сметы, работы), у лидов колонки «новый, 1-й / 2-й / 3-й контакт, выигран, проигран»; в «выигран» → сделать смету или работу; автоматизации на каждую колонку. **Приём обращения (Customer Intake):** офис ведёт звонок по шагам — по нише и услуге появляются вопросы, напоминания, готовые ответы. **Входящие заявки (Job Inbox):** все площадки в одном месте; **ИИ сразу отвечает новому лиду личным SMS** от имени ответственного (вкл. по умолчанию). Онлайн-запись (Google, сайт, ссылка, оплата при записи, зоны). Форма и чат-виджет на сайт. Источники лидов.
- **Клиенты:** вкладки профиль, сметы, работы, счета, вложения, заметки; несколько адресов, под-клиенты, слияние дублей, удаление с восстановлением. **«Не обслуживать»** — красная метка, запись блокируется, уведомления выключаются. **Профиль объекта:** оборудование (тип, марка, модель, серийный номер, дата установки). **«Расскажи подробнее»:** ИИ одной кнопкой даёт сводку по клиенту. Условия оплаты у клиента.
- **Сметы:** имя сметы, исполнитель, срок действия, «Объём работ» (видно при любом варианте, ИИ может написать); **варианты** отдельной вкладкой, у каждого свои позиции, заметки, чек-листы, вложения; инструмент предложений «хорошо / лучше / лучшее» с фото и рассрочкой рядом с ценой; подпись пальцем со ссылкой на условия; ручное «одобрено / отклонено»; **одобрена → работа создаётся сама** (настройка); депозит, срок по умолчанию, «клиент открыл смету», шаблоны. **Ценовые формы:** цена от количества, часов, частоты, площади. **Цена по замерам** (только покраска, только партнёры) — близко к нашему модулю Gutters.
- **Работы:** визиты (одна работа — много выездов), части работы со своими счетами (подномер), повторяющиеся работы, поля работы (тип, бизнес-единица, «повторный вызов»), скрытые заметки, **чек-листы** (разделы, пункты «галочка / текст / прошёл–флаг–провал / фото / выбор», обязательные, PDF, шаблоны под нишу), **фото с разметкой** (рисунок, текст, время), **видео до 1 минуты**, **фотоотчёт клиенту** (обложка с логотипом, разделы, PDF, в портале, несколько на работу), задачи без работы, шаблоны работ, копировать работу ↔ смету, «снять с расписания / отменить / удалить» с отменой, окно приезда, SMS-напоминание о визите.
- **Расписание:** день, неделя, месяц, колонки по мастерам; **маршруты** (работа ставится на маршрут, люди привязаны к маршруту); **порядок по дороге** (дорогой тариф); **окна-слоты** «утро 8–12» с ёмкостью (бета); события и отгулы закрывают окна онлайн-записи; Google Календарь; GPS мастеров и машин.
- **Время:** приход и уход только в телефоне, место на карте; дорога и время на работе; **новая панель:** обычные, сверхурочные, двойные часы, отгулы, сетка «дни × люди», ручная правка, выгрузка; зарплата из табелей.
- **Счета и оплата:** фильтры (не отправлены / к оплате / просрочены), счета по этапам (отдельные счета), пакетная отправка и оплата нескольких счетов, автосчёт, напоминания, ИИ пишет письмо к счёту; карта, ACH, Apple/Google Pay, Tap to Pay, ридер, частичная оплата, чаевые, возврат, быстрая выплата, **фото чека клиента → депозит в банк**; рассрочка; **налог сам по адресу**.
- **Расходы и прибыль:** расходы по работе (чек, счёт поставщика), карты расходов с лимитами; **себестоимость работы** (полная ставка × время, дорога тоже, материалы, расходы, комиссии → маржа), деление выручки между мастерами, комиссии, бухгалтерия под ключ, зарплата, заказы поставщику, склад через партнёра.
- **Каталог:** фото у позиций, артикулы, налоговые категории, массовая правка, «поднять цены», фиксированные цены.
- **Связь:** общие входящие (клиенты, команда, ИИ, заявки), письма со своего домена, статус доставки; телефон (дополнение): номер, голосовое меню, маскировка, учёт звонков; живые операторы (платно); правила SMS.
- **Маркетинг:** кампании SMS и почта, цепочки, «клиенты с открытыми сметами», выручка от кампании; **ИИ возвращает старых клиентов** — до 10 в день, личное SMS по истории, 3 дня на проверку, пропускает отписавшихся и «не обслуживать»; отзывы (Google, Facebook, привязка к работе, ответы); открытки по почте; «приведи друга»; сайт под ключ.
- **Абонементы:** панель (регулярная выручка, «пора выставить счёт», визиты без даты), статусы, шаблоны под нишу, продление.
- **Отчёты:** панель ключевых цифр (цель по выручке, тренд 12 месяцев, собрано по способам, средний чек, долги по срокам, процент одобрения смет, работы по источникам, сравнение с прошлым годом и «i»); **рейтинг мастеров**; отчёты по конверсии, себестоимости, абонементам и др.
- **ИИ («ИИ-команда»):** ИИ на звонках (платно), чат на сайте, ответы на SMS (альфа), аналитик «вопрос → отчёт», «напиши за меня», «расскажи подробнее», голосовой помощник (альфа), авто-ответ лиду, возврат старых клиентов.
- **Команда:** 3 роли (владелец/админ, офис, мастер) + галочки прав (деньги, настройки, маркетинг, отчёты, маржа, доска продаж, видеть цены — без этого нельзя взять подпись, видеть телефон клиента, вся база); один «ответственный за переписку»; **мастер работает только в телефоне**. Франшизы.
- **Подключения:** QuickBooks Online и Desktop, Google Календарь, Gusto, Zapier, API, вебхуки, CompanyCam, CallRail и др. Импорт и выгрузка.
- **Офлайн — только просмотр:** приложение само качает свои работы на сегодня и 2 дня вперёд, до 10 в день; править нельзя; полоса «Вы не в сети» со временем синхронизации; «Синхронизировать сейчас». Испанский в приложении.

### 1.3 Что взять на заметку
Полоса «Требует внимания» на главной мастера · «не обслуживать» · фото с разметкой и фотоотчёт · одобрена → работа сама · окна-слоты с ёмкостью · ИИ-ответ новому лиду · ИИ возвращает старых клиентов с проверкой человеком · процент и «i» у цифр · рейтинг мастеров.
**Не брать:** офлайн «только смотреть», мастер без веба, канбан как главный вид (у нас правило 12 — списки карточками), финансовые продукты (карты, кредит, бухгалтерия), цена по замерам только для партнёров.

### 1.4 Экраны по скриншоту 06.11

Источник всего подраздела — **по скриншоту 06.11**: 29 снимков основателя, iPhone, пробный период, 19:00–19:05. 13 снимков — приложение HCP для iOS, 16 — страница тарифов `pro.housecallpro.com` в Safari, открытая из приложения. Английское имя дано один раз в скобках. Цены, суммы и проценты не пишем. Имена людей со снимков не переписываем.

Как устроены формы (по скриншоту 06.11): почти все формы открываются **шторкой** поверх прошлого экрана. Слева крестик или «Отмена», по центру заголовок, справа «Сохранить» или «Готово». «Сохранить» серая и не нажимается, пока форма пустая. Крупный заголовок при прокрутке уменьшается и уходит в шапку. Ссылки и кнопки «＋» синие.

#### 1.4.1 Нижние вкладки
Видны на экране «Входящие». Слева направо: **Главная** (Dashboard, значок спидометра) · **Расписание** (Schedule) · **Входящие** (Inbox) · **Клиенты** (Customers) · **Ещё** (More, три кружка). Активная вкладка — тёмный залитый значок и тёмная подпись, остальные серые. Отдельной плавающей «＋» на этом экране нет.

#### 1.4.2 Входящие (Inbox)
Как попасть: вкладка «Входящие». Сверху вниз:
1. Справа вверху — шестерёнка (настройки входящих).
2. Крупный заголовок «Входящие».
3. Группа **«Чат»**, одна строка-карточка: **«Вся переписка»** (All comms) ›.
4. Вторая карточка из четырёх строк со стрелками:
   - **Клиенты** (Customers) ›;
   - **Сотрудники** (Employees) › — чат команды;
   - значок искр + **«ИИ-команда»** (AI Team) с синей меткой **«Бета»** ›;
   - **«Входящие по работам»** (Job inbox) › — заявки с площадок.
5. Ниже пусто. Счётчиков непрочитанного на строках нет (в пробном аккаунте сообщений нет).

#### 1.4.3 Новый лид (New Lead)
Как попасть: на снимке не видно (по справке — «＋» или доска продаж). Экран на весь рост, сверху вниз:
1. Слева «Отмена» (Cancel), справа «Сохранить» (серая, пока клиент не выбран).
2. Крупный заголовок «Новый лид».
3. Подпись **«Клиент (обязательно)»**, строка-карточка **«Клиент»** ›. **Лид без клиента создать нельзя.**
4. Подпись **«Необязательно»**, четыре строки-карточки со стрелкой:
   - **«Ответственный за лид»** (Lead assignee) ›;
   - **«Личные заметки»** (Private notes) ›;
   - **«Метки лида»** (Lead tags) ›;
   - **«Источник лида»** (Lead source) ›.
5. Больше полей нет: ни адреса, ни услуги, ни описания, ни телефона — всё это берётся из клиента.

#### 1.4.4 Новый клиент (Add customer), полностью
Как попасть: шторка поверх другого экрана (по снимку — из выбора клиента; откуда именно, не видно). Шапка: крестик слева, «Сохранить» справа (серая, пока пусто); крупный заголовок «Новый клиент» при прокрутке уходит в шапку. Сверху вниз:
1. Группа **«Контакт»** — серые поля с подписью внутри, все пустые:
   - Имя (First name);
   - Фамилия (Last name);
   - **Отображаемое имя** (Display name) — как клиент будет подписан в списках и документах;
   - Email;
   - **Мобильный телефон**;
   - **Домашний телефон**;
   - **Рабочий телефон**;
   - ссылка **«＋ Телефон»** — ещё номер.
2. Переключатель **«Отправлять уведомления»** (Send notifications) — **по умолчанию включён**. Подпись: если выключить, клиенту не уходят ни SMS, ни письма.
3. Переключатель **«Не обслуживать»** (Do not service) — **по умолчанию выключен**. Подпись: уведомления выключатся, и клиенту **нельзя будет назначить работу или смету**.
4. **«Метки»** (Tags) — ссылка «＋ Метка».
5. **«Источник лида»** (Lead source) — ссылка «＋ Источник лида» (открывает список §1.4.5).
6. **«Адреса»** (Addresses) — ссылка «＋ Адрес»; адресов может быть несколько.
7. **«Заметки»** (Notes) — ссылка «＋ Заметка».
8. Группа **«Компания»** (Company): поле **«Название»** (Name) и поле **«Должность»** (Role) — кем этот человек работает в компании клиента.
9. Ниже ничего нет. Кнопки «Сохранить» внизу нет — только в шапке.

#### 1.4.5 Источник лида (Lead source)
Как попасть: «＋ Источник лида» в форме клиента, лида или работы. Шторка:
1. Крестик слева, синий **«＋»** справа — добавить свой источник.
2. Крупный заголовок «Источник лида».
3. Поле поиска (пустое, со значком лупы).
4. Список строк без значков, по алфавиту. В пробном аккаунте — готовые источники: два сторонних сервиса для HVAC, ИИ-оператор HCP (CSR AI), Google Local Services, кампании маркетинг-центра HCP, приложение HCP для клиентов, маркетплейс HCP, сервис заявок для HVAC, сервис онлайн-смет, конструктор сайтов HCP. То есть **собственные продукты HCP сами стоят в списке источников** — так HCP считает, сколько заявок принёс каждый его платный продукт.
5. Выбор строки — источник ставится, шторка закрывается (по виду; сам момент на снимке не виден).

#### 1.4.6 Новая работа (New job)
Как попасть: на снимке не видно (по справке — «＋» или вкладка «Расписание»). Шапка: крестик, «Новая работа», синяя «Сохранить» (активна — клиент уже выбран). Верх формы с клиентом прокручен и не виден. Сверху вниз видно:
1. Карточка **адреса**: город, штат, ZIP; справа синий значок булавки (адрес на карте).
2. Карточка **«Расписание»** (Schedule): значок календаря, справа синий карандаш (изменить).
   - «С» — день недели и дата, время;
   - «По» — та же дата, время на 2 часа позже. По умолчанию подставлено само: сегодня, ближайшее время, окно 2 часа;
   - ниже — исполнитель: круглый аватар (серый силуэт) и имя. По умолчанию — тот, кто создаёт работу.
3. Шесть одинаковых карточек-кнопок с синей рамкой, у каждой значок слева и синий «＋» справа:
   - **«Позиции»** (Line Items) → §1.4.7;
   - **«Поля»** (Fields) → §1.4.9;
   - **«Чек-листы»** (Checklists) → §1.4.10;
   - **«Метки работы»** (Job tags);
   - **«Личные заметки»** (Private notes);
   - **«Источник лида»** (Lead source) → §1.4.5.
4. Пустые блоки не раскрыты: виден только заголовок и «＋». Форма короткая, на одном экране.

#### 1.4.7 Позиции (Line items): услуги и материалы
Как попасть: «＋» у «Позиций» в новой работе. Шторка, заголовок «Позиции», справа синее **«Готово»** (Done). Сверху вниз:
1. Раздел **«Услуги»** (Services); справа в строке заголовка синяя ссылка со значком планшета **«Прайс услуг»** (Service Price Book).
   - Строка позиции: слева красный круг «−» (удалить), название в две строки, под ним **«Кол-во N × цена / шт.»**, справа сумма строки, «›» (открыть позицию).
   - Зелёный круг «＋» и серое **«Добавить услуги»** ›.
2. Раздел **«Материалы»** (Materials); справа ссылка **«Прайс материалов»** (Material Price Book).
   - Зелёный «＋» и **«Добавить материалы»** ›.
3. Строка **«Подытог»** (Subtotal) с суммой справа.
4. Раздел **«Скидки»** (Discounts): зелёный «＋» и **«Добавить скидку»** ›.
5. Строка **«Итого»** (Total), жирным.
6. Раздел **«Сообщение в счёте»** (Invoice message): зелёный «＋» и **«Добавить сообщение»** ›. Текст для клиента пишется прямо здесь, у позиций работы.
7. **Пустое состояние:** в разделах только строки «Добавить…», подытог и итог — ноль долларов. Строки «Налог» на этом экране нет (налог ставится у позиции, §1.4.8).
- Услуги и материалы — **два разных списка и два разных прайса**. Строка «Добавить услуги» открывает простой выбор позиции (на снимке не виден), ссылка «Прайс услуг» — каталог по нише с плитками (§1.4.8).

#### 1.4.8 Прайс по нише (Price book): категории → позиции → карточка → «Добавить в работу»
Как попасть: «Прайс услуг» в позициях работы. В пробном аккаунте ниша — **«Генеральный подрядчик»**: прайс заполнен заранее, его не делали руками.
1. **Категории.** Шапка: заголовок — название ниши, справа крестик. Поле **«Искать в прайсе»** (Search Price Book). Ниже плитки по 2 в ряд: сверху место под картинку (в пробном аккаунте — серый значок «нет картинки»), снизу название, длинное обрезано многоточием. Видны: ремонт ванных; бетон и фундамент; снос и подготовка участка; электрика и свет; заборы, террасы и уличное; полы и плитка; каркас и столярка; HVAC и утепление; ниже — ещё (прокрутка).
2. **Позиции категории** (например, «Электрика и свет»). Шапка: «‹ Назад», название категории, крестик. Список строк: слева квадрат под картинку (пустой), справа название позиции, **цена** (во всех готовых позициях — ноль, цены HCP не даёт), полное описание в несколько строк. Примеры: замена электрощита и автоматов; проводка, светильники и потолочные вентиляторы; осушители и управление HVAC; праздничная подсветка дома. Под каждой — тонкая линия.
3. **Карточка позиции.** Шапка: «‹ Электрика и свет» (назад к категории), крестик. Сверху вниз: крупное название (обрезано); **«Код задачи»** (Task code) — служебный код вида `DEFAULT_<НИША>_SERVICE_<номер>`; **«Описание»**; **«Цена позиции»** (ноль). Внизу во всю ширину синяя кнопка **«Добавить в работу»** (Add to Job).
4. **Панель «Добавить в работу»** — выезжает снизу на серой подложке, карточка остаётся сверху:
   - поле **«Цена за единицу»** (Unit price) — подставлена цена из прайса, можно поменять;
   - поле **«Количество»** (Quantity) — по умолчанию 1, справа две большие серые кнопки **«−»** и **«＋»**;
   - переключатель **«Облагается налогом»** (Taxable) — **по умолчанию выключен**;
   - строка **«Итого по позиции»** (Total item price) — считается сама;
   - внизу две кнопки: серая **«Отмена»** и синяя широкая **«Подтвердить»** (Confirm).
5. После «Подтвердить» позиция встаёт в раздел «Услуги» (§1.4.7) строкой «Кол-во × цена».

#### 1.4.9 Поля работы (Fields)
Как попасть: «＋» у «Полей» в новой работе. Шторка: синий крестик слева, заголовок «Поля», кнопки «Сохранить» нет (закрыл — сохранилось). Одна белая карточка, три строки:
1. **«Подразделение»** (Business unit) — пусто;
2. **«Повторный вызов»** (Callback) — **по умолчанию «Нет»**; значит, у работы есть признак «это возврат по прошлой работе»;
3. **«Тип работы»** (Job type) — пусто.

#### 1.4.10 Чек-листы (Checklists) у работы
Как попасть: «＋» у «Чек-листов» в новой работе. Шторка: крестик, крупный заголовок «Чек-листы». **Пустое состояние:** по центру серая картинка (три галочки и три линии), под ней серый текст о том, что чек-листы помогают держать одинаковый порядок на каждой работе, и синяя кнопка-пилюля **«Добавить чек-лист»** (Add a checklist). #### 1.4.12 Что понравилось
- **Лид всегда с клиентом** — форма нового лида из 5 строк, всё остальное берётся из клиента. Быстро и без дублей данных.
- **«Не обслуживать» с понятным следствием** прямо в подписи переключателя: уведомления выключены, работу и смету назначить нельзя.
- **«Отправлять уведомления»** у клиента одним переключателем — просто и честно для клиента, который не хочет SMS.
- **Три вида телефона** с подписями и «＋ Телефон»; **отображаемое имя** отдельно от имени и фамилии; **должность** в компании клиента — удобно для коммерческих клиентов.
- **Пустые блоки свёрнуты в «＋»** — форма работы короткая, на одном экране телефона.
- **Расписание подставлено само** (сегодня, ближайшее время, 2 часа, я сам) — можно сразу «Сохранить».
- **Услуги и материалы раздельно** со своими прайсами; «Сообщение в счёте» рядом с позициями.
- **Прайс по нише готов с первого дня**: категории плитками, описания, поиск. Добавление позиции — цена, «−/＋», «Облагается налогом», итог — на одном экране.
- **Входящие одной вкладкой:** клиенты, сотрудники, ИИ и заявки по работам в одном месте.
- **Подписка на сайте:** нет комиссии Apple, одна цена; приложение просто открывает сайт.

#### 1.4.13 Что неудобно
- **Лид нельзя создать без клиента** — при звонке надо сначала завести клиента. У нас лид живёт без клиента до S3, это быстрее.
- В готовом прайсе **все цены нулевые, картинок нет** — плитки с серыми заглушками; подрядчику всё равно вводить цены руками.
- **Код задачи** вида `DEFAULT_..._SERVICE_31` — служебный текст на экране мастера, человеку не нужен.
- **Налог у каждой позиции вручную** и по умолчанию выключен — легко забыть.
- Строки «Добавить услуги» и ссылка «Прайс услуг» стоят рядом и делают похожее — непонятно, что выбрать.
- **Поля работы без «Сохранить»** и без подсказок, что значит «Подразделение».
- **Много функций за дополнительную плату:** доска продаж, налоги по адресу, Tap to Pay, рассылки, сайт, ИИ-оператор — надстройки; чек-листы, пометки на фото, QuickBooks — только со среднего тарифа. В пробном периоде всё открыто, после покупки базового часть пропадёт.
- **Тарифы — отдельный сайт** с каруселью и длинной таблицей; с телефона сравнивать тарифы тяжело (видна одна колонка).
- Формы разные по виду: где-то «Отмена» текстом, где-то крестик; где-то крупный заголовок, где-то мелкий.

## 2. ServiceTitan (ST)

**Главная мысль.** Для больших компаний (колл-центр, склад, флот, бизнес-единицы). Малому подрядчику полезно немногое, но это немногое — сильное. Тарифы и цены только по запросу.

| Запись звонка | Экран: тип работы, дата (подставляется сама), кампания (сама по номеру), приоритет, мастер | Идея «подставить само», но без лишних обязательных полей |
| Мастер: «мой день» | Текущая работа сверху; Сегодня / Впереди / Прошлые / На паузе | Совпадает с нашими «Выездами» (`visits.tsx`) |
| Выезд | Отправлен → На месте → Закрыть; при закрытии выбор: **пауза / перенос / ещё визит / готово** | Наши шаги выезда; взять выбор при закрытии |
| Табель | Ведётся сам: «еду» → дорога, «на месте» → работа | Позже — из наших статусов выезда |
| Смета на месте | Варианты рядом на одном экране, «рекомендуем», подпись → «сделать сейчас или позже» | У нас есть варианты и «рекомендуем» |
| Счёт | Один счёт на работу, оплата в 2 нажатия | ✅ |
| **Офлайн (обн. 29.10.2026)** | Без сети работают статусы, время, заметки, подписи, фото, сметы (создать и править), чек-листы и формы. Только с сетью: заказы поставщику, склад, рассрочка, договоры, Tap to Pay | **Образец для нас:** список «что работает без сети» и «отложенные платежи» |

| Тяжело для малых | Бизнес-единицы, детальные права, колл-центр, склад, флот, зарплата, стройка, франшизы | Не брать |
