## Что готово

## Главный принцип (решение основателя)
OCTODEX — CRM для **любых** подрядчиков. Ядро не привязано к нише; гаттеры, крыша, электрика — **модули-калькуляторы**, которые заполняют позиции универсальной сметы. Объяснение для основателя: https://claude.ai/artifact/XsuchM4KpoSCQ8UBtFmVRw

## Следующая задача
1. **Универсальная смета** (ядро): позиции из каталога/вручную, кол-во × цена, 1–3 варианта (Good/Better/Best, «Рекомендуем»), доп. опции, скидка, налог (в цене / сверху / без), депозит с лимитом CA, подпись, депозит. Расчёт только через `@octo/estimating-engine`. Таблицы в БД уже есть (`estimate_versions/options/line_items`).
2. **Каталог** услуг и материалов компании (таблица по `docs/04-domain-model.md` CatalogItem), тестовые позиции для нескольких ниш с пометкой «тестовые».
3. Перенести «Быструю смету гаттеров» и «Чертёж» в модуль Gutters (включается в настройках компании).
4. Затем: счета из сметы, загрузка фото в Storage, настройки компании и приглашение команды.
