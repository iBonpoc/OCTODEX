# Проверка этапа (чек-лист чата аудита)

Согласовано чатом аудита 11.11.2026 (`docs/ai/DIRECTOR.md` «Порядок работы агентов» п.8). Проверку делает **свежий** чат аудита на сильной модели. Первым сообщением ему — файлы `docs/audit/2026-11-11-*` и этот чек-лист, затем отчёт руководителя «Этап N готов» (`DIRECTOR.md` «Проверка этапа»).

1. У каждой находки этапа есть тест с её ID, и он был красным до правки.
2. 3–5 самых опасных правок этапа прочитаны по коду.
3. 20 случайных влитых PR этапа: у каждого задача `до-1.0` в эпике.
4. Замеры «до/после», если этап их обещал.
5. Что перенесено из этапа и почему.
6. Новые находки — задачами (Issues) в тот же день.
7. 3 случайные К2 этапа прочитаны по коду (проверка ревью «по выводу»). Пропущенная ошибка → руководитель снова читает диффы К2.

Вердикт: «принято» или список доделок. Следующий этап той же дорожки не начинается до «принято».
