# Разбор брифа от GPT (`gpt-octo-brief-2026-11-02.md`)

**Вывод:** бриф полезен как чек-лист инженерной и продуктовой дисциплины, но не знает наших решений. Он написан «в общем» для любого подрядчика, без gutter-специфики, LA, позиционирования «помогаем зарабатывать», multi-company и уже сделанного анализа. Берём из него процессные и инженерные пункты, продуктовый объём оставляем свой.

## Не согласны (оставляем наше решение)
| Бриф | Наше решение и почему |
|---|---|
| Спутник для гаттеров = P2 «исследование, очень высокий риск» | Бриф путает **автоизмерение** (сложно) и **ручной чертёж поверх снимка** (снимок с известным масштабом + линии пальцем). Ручной чертёж — это ядро Gutters-модуля и главное отличие, он реален в MVP. Автоизмерение остаётся на потом |
| Offline-first = P2 | Основатель требует офлайн. В MVP: офлайн для полевых сценариев (смета, чертёж, фото, подпись). Сложные конфликты решаем простыми правилами |
| Клиентский портал = P1, «может, хватит ссылок» | Портал-витрина = механизм заработка (cross-sell, отзывы, рефералки). MVP: защищённая ссылка на смету/инвойс с подписью, оплатой и блоком витрины. Полный «кабинет» позже |
| Позиционирование «управлять полным циклом в одной системе» | Слишком общее, так говорят все конкуренты. Наше: «CRM, которая зарабатывает тебе деньги» + gutters-first |
| Не выбран первый сегмент | Выбран: gutters → roofing, LA, команды 1–15 человек |
| Цены и модель монетизации — открытый вопрос | Уже есть черновик: Starter $50 / Pro $99, модули, комиссия с платежей (`02a`) |

## Справедливая критика нашего плана
- **MVP у нас широкий.** Нужно ещё раз сузить при фиксации MVP (Фаза 1.4): возможно, AI-помощник v1 только для поиска, создания сметы и расходов; ROI только по ручным данным; карта простая.
- **Дискавери шире одного основателя.** Кроме компании основателя нужно 5+ интервью с другими подрядчиками (gutters и соседний trade) до масштабной разработки.
