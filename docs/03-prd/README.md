# 03. PRD по модулям

Каждый модуль — отдельный файл по шаблону ниже. Сущности и статусы берутся только из `../04-domain-model.md`. Если модулю нужна новая сущность или поле, это пишется в разделе «Изменения модели данных», а не придумывается молча.

## Шаблон модуля
1. **Назначение** — одна-две фразы.
2. **Как это приносит деньги подрядчику** (`money_impact`) — обязательно.
3. **Пользователи и роли** — кто работает с модулем.
4. **User stories** — «Как <роль>, я хочу <действие>, чтобы <результат>», с ID (например `EST-US-04`).
5. **Критерии приёмки** — проверяемые, по формату Given / When / Then, для каждой story.
6. **Экраны** — телефон / планшет / веб: список экранов и главные элементы.
7. **Бизнес-правила и расчёты** — формулы, ограничения, переходы статусов.
8. **AI-помощник** — какие команды доступны, что требует подтверждения.
9. **Офлайн** — что работает без сети.
10. **Уведомления и автоматизации**.
11. **Ошибки и крайние случаи** — двойное нажатие, нет сети, конфликт, нет прав.
12. **MVP / позже** — что входит в первую версию.
13. **Метрики** — как поймём, что работает.
14. **Изменения модели данных** — если нужны.
15. **Открытые вопросы**.
