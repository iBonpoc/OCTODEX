# Фиксация MVP (Фаза 1.4) — черновик на утверждение

> Критерий MVP: **основатель и его команда из 4 человек ведут свой gutter-бизнес только в Octo**: от лида до оплаты и отзыва, на iPhone и в браузере, в том числе без сети.
> Всё, что не нужно для этого критерия, переносится в «Бета+» (до первых платящих клиентов) или «Позже».
> Карта экранов (`05-user-flows.md`) насчитала 262 экрана. Цель MVP: **~70–90 экранов**.

---

## 1. MVP: обязательно

| Блок | Что входит | Что НЕ входит в MVP |
|---|---|---|
| **Компания и доступ** | Регистрация, 1 компания, роли owner/admin/office/tech/**subcontractor**, переключение между своими компаниями | «Все компании» (объединённый вид), биллинг, пробный период, пауза |
| **Лиды** | Ручной ввод, **разбор email-уведомлений** Thumbtack/Yelp/Google/Angi, источник и стоимость лида, «чей ход», статусы, причина проигрыша | API маркетплейсов, call tracking, эскалации |
| **Клиенты и объекты** | Клиенты, контакты, **несколько объектов**, раздел «Объекты», лента событий, задачи, заметки | Слияние дублей, импорт из других CRM (кроме CSV) |
| **Каталог и поставщики** | Каталог, **тестовый прайс**, сборки и формулы, поставщики, **импорт/экспорт CSV/XLSX/XML**, **AI-скан прайса и ценника**, массовое обновление цен через предпросмотр | Склад coil, API поставщиков |
| **Сметы** | Смета из формы, из чертежа, из шаблона и через AI; версии; G/B/B; add-ons; скрытый BOM; маржа по ролям; депозит; отправка ссылкой и PDF; подпись; отслеживание открытий; change orders; **настраиваемые налоги** | Финансирование «от $X/мес» |
| **Gutters** | **Быстрая форма** (футы по этажам, углы, даунспауты, guards); **чертёж на своём фото с калибровкой**; авто-углы; BOM; cut list; стандарты (отход 5%, хэнгер 2 ft, 3 A-elbow, высоты этажей) | Спутниковая подложка (ждём решение по лицензии, ADR-004), авто-распознавание крыши, coil-склад |
| **Работы и расписание** | Авто-создание работы из сметы, лоток «Не запланировано», календарь день/неделя, **drag & drop**, бригады, **назначение субподрядчику с нарядом по ссылке**, «в пути», фото до/после, чек-лист | Отпуска, оптимизация для нескольких бригад |
| **Повторяющиеся работы** | План чистки (пресет «октябрь + апрель»), авто-визиты, оплата за визит | Предоплаченные планы, membership с автосписанием |
| **Карта** | Слои: лиды, клиенты, сегодняшние визиты; навигация в Apple/Google Maps | Режим «Рядом», порядок объезда, бригады на карте |
| **Деньги** | Инвойсы (депозит, финальный), Stripe карта/ACH, ручные платежи (наличные, чек, Zelle), квитанции, возвраты и void с правилами, переплата → кредит клиента | Tap to Pay (если Apple не одобрит вовремя, будет QR), напоминания-цепочки сложнее одной |
| **Расходы и прибыль** | Фото чека → AI → расход на работу, перевыставление с наценкой, 5 чисел работы | Учёт труда по ставкам (позже, если не решим иначе) |
| **Заказы поставщикам** | PO из черновика и из одобренной сметы, email/PDF, «устарел», **RFQ + авто-разбор ответа**, сравнение поставщиков | Частичная приёмка (можно позже) |
| **Портал клиента** | Ссылка без установки: смета G/B/B, подпись, депозит, инвойсы, оплата, история дома, блок витрины (другие услуги, фото работ, отзыв, рефералка) | Онлайн-запись по слотам, «Мой дом» с гарантиями |
| **Публичная страница** | Одна SEO-страница компании EN (ES после перевода) | Виджет на сайт подрядчика, свой домен |
| **Коммуникации** | Email всем; SMS с телефона владельца (шаблон в Messages); 5 встроенных автоматизаций (ответ на лид, дожим сметы, напоминание о визите, напоминание об оплате, запрос отзыва) | SMS через Octo-номер (10DLC) — **Бета+**, сезонные кампании |
| **AI-помощник** | Навигация, поиск, создание и правка смет с предпросмотром и отменой, расход из чека, обновление цен по прайсу | Ответы на любые вопросы по отчётам, голосовой AI-ресепшн |
| **Отчёты** | «Сегодня», воронка, ROI по источникам (ручные затраты + стоимость лидов), дебиторка | Автоимпорт рекламных затрат, когорты |
| **Офлайн** | Чтение и правка клиентов/работ на 14 дней, черновики смет и чертежей, фото, подпись, статусы, очередь синхронизации | Офлайн-голос |
| **Платформа** | EN/ES для клиента, RU/EN/ES интерфейс, токены дизайна, журнал действий, резервные копии | Поддержка через тикеты (в MVP — email и отчёт об ошибке) |

## 2. Бета+ (перед первыми платящими клиентами)
Биллинг Octo (Stripe), пробный период, «Все компании», SMS через Octo-номер (10DLC), онлайн-запись, слияние дублей, AI-поддержка по базе знаний, Tap to Pay, сезонные кампании, спутниковая подложка (после лицензии).

## 3. Позже
Модуль Roofing, Android, финансирование (Wisetack), API Thumbtack/Angi/Yelp/LSA, call tracking и AI-ресепшн, coil-склад, membership, оптимизация маршрутов, свой домен, QuickBooks.

## 4. Порядок срезов MVP (уточнение `00-roadmap.md`)
1. Фундамент: компании, роли, вход, токены, офлайн-база
2. Клиенты, объекты, лиды (+ разбор писем)
3. Каталог, импорт/экспорт, AI-скан прайса
4. Движок смет + Gutters (форма и фото-чертёж)
5. Портал: смета, подпись, депозит (Stripe)
6. Работы, календарь, субподрядчики, чистки по графику
7. Инвойсы, платежи, возвраты; расходы и прибыль
8. Заказы поставщикам + RFQ
9. AI-помощник v1
10. Коммуникации и 5 автоматизаций, отчёты
11. Офлайн: доводка и полевые тесты

## 5. Решения в этом документе, которые нужно утвердить
- SMS через собственный номер Octo — в Бета+, а в MVP SMS отправляются с телефона владельца (бесплатно, без 10DLC).
- «Все компании» — в Бета+.
- Спутник — после лицензии; в MVP своё фото + быстрая форма.
- Онлайн-запись по слотам — в Бета+.
