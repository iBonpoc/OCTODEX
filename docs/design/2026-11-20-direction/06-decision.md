## Что принято
1. **Структура.** Нижние вкладки: Главная (Сегодня) · План · Клиенты · Деньги · Поиск. «Ещё» нет: всё остальное — по аватару справа в шапке «Главной». Модуль (Gutters) — в работе и в «＋», не во вкладках. Сообщения — в карточке клиента и колокольчике.
2. **Деньги** — одна вкладка: сметы, счета, оплаты, переключение сегментом вверху.
3. **Главное действие.** «＋» 56 справа над вкладками, меню по контексту экрана (первый пункт — для этого экрана). На экране объекта внизу одна главная кнопка «следующий шаг» по цепочке: Новая смета → Отправить → Выставить счёт → Взять оплату.
4. **Вид — «спокойный рабочий»:** системный шрифт (SF / Roboto / system-ui), непрозрачные карточки, стекло только у панелей, без фоновых пятен. Статусы — тональная плашка «значок + слово».
5. **Акцент — кобальт** (dark `#8098FF` / light `#2747E8`, текст на нём 7.3 / 6.7:1); голосовали 2 из 4, проходит AA без костылей, не путается с оранжевым warn; `info` ушёл в бирюзу. **Янтарь** (за него 2 из 4 и слово основателя 16.11 «Давай жёлтый») — переключатель «Акцент» в настройках, чтобы основатель сравнил на солнце. Жёлтый рулетки Gutters — без изменений (исключение правила 2).
6. **Читаемость:** второстепенный текст ≥ 7:1, рамка поля ≥ 3:1, текст не мельче 12, тело 16, ввод 17.
7. **Размеры:** главная кнопка 50, вторичная 44, поле 48, строка 52/64, зона нажатия 48, карточка 20, шторка 28. ⚠ Расходится с правилом 3 (видимые ≤ 36) — **нужно слово основателя**; в ветке-прототипе сделано так, чтобы он сравнил.
8. **Перетаскивание:** порядок позиций сметы — ручка сразу, строка долгим нажатием 300 мс, вибрация, автопрокрутка, «Вернуть»; у каждого жеста замена в «⋯». Канбан лидов — только 820/1280.
9. **Не трогаем:** данные, деньги, офлайн, синхронизацию.
