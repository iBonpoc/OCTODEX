# Разбор каркасов GoRix — UX-аналитик (Нильсен, задачи, нажатия)

21.11.2026 · по `wireframes.html`, `SCREENS.md`, `LAYOUT-RULES.md`, #2350 (основатель: «максимально компактно»). Номера эвристик Нильсена: Н1 видимость состояния · Н2 язык пользователя · Н3 контроль и отмена · Н4 единообразие · Н5 предотвращение ошибок · Н6 узнавание вместо припоминания · Н7 гибкость и скорость · Н8 минимализм · Н9 восстановление после ошибок · Н10 справка.

## 1. Главный путь: клиент → смета → отправка → подпись → счёт → оплата

**Главная проблема:** из 6 шагов пути в каркасах нарисованы только 3: форма клиента, редактор сметы, счёт с оплатой. Нет экрана «Смета» (просмотр после отправки), шторки «Отправить», подписи, перехода «смета принята → счёт». Поэтому считаю по SCREENS.md и по самому вероятному поведению. Это оценка, не замер.

Сценарий: новый клиент, 3 позиции из каталога (у двух меняется количество), подпись на месте, оплата наличными.

| Шаг | По каркасам: нажатий / вводов | Лишнее | Как сократить | Станет |
|---|---|---|---|---|
| Клиенты → «＋ Клиент» → форма → «Создать клиента» | 3 / 6 (имя, фамилия, телефон, почта, улица, «город, штат, ZIP») | адрес вводится двумя полями | подсказка адреса: одно поле, выбор из списка | 3 / 5 |
| Создать смету у клиента | 2 / 0 («＋» в шапке → «Смета») | у нового клиента главной кнопки «Создать смету» нет, на каркасе только «Выставить счёт» у Sarah | правило: у клиента без смет главная кнопка — «Создать смету» | 1 / 0 |
| Название работ | 0 / 1 | поле обязательно до позиций | название подставляется из первой позиции или шаблона, его можно поправить | 0 / 0 |
| 3 позиции из каталога | 7 / 2 («Из каталога», 3 выбора, «Готово», 2 нажатия, чтобы открыть строку для количества) | шторка каталога, количество правится отдельно | одно поле «＋ Позиция» с поиском по каталогу, количество кнопками − / + в строке подсказки | 5 / 2 |
| Отправка | 2 / 0 («Отправить клиенту» → «Отправить» в шторке, которой нет на каркасе) | подтверждение безопасного действия | кнопка называет канал («Отправить по SMS»), после неё тост «Отменить» 5 с; шторка только при первой отправке | 1 / 0 |
| Подпись на месте | 2 / 1 (на экране сметы, которого нет) | — | в тосте после отправки «Подписать здесь» | 2 / 1 |
| Выставить счёт | 1 / 0 | — | счёт собирается из подписанной сметы, без формы | 1 / 0 |
| Оплата | 3 / 0 («Принять оплату» стоит второй в паре с «Отправить клиенту», «Наличные», «Записать») | по умолчанию стоит «Карта»; когда клиент рядом, главной кнопкой стоит «Отправить» | при подписи на месте главная кнопка — «Принять оплату», способ — последний из использованных | 2 / 0 |
| **Итого** | **20 / 10** (было 18 / 11) | | | **15 / 8** |

Вывод: по каркасам нажатий **больше, чем сейчас** (20 > 18). Цель инвентаризации «не хуже 18» не выполнена. Причин три: нет правила «следующий шаг по состоянию» для главной кнопки, «＋» на объекте спрятан в шапку (нужно 2 нажатия вместо 1), каталог открывается отдельной шторкой. Если клиент подписывает по ссылке, у пользователя уходит ещё 2 нажатия и 1 ввод.

## 2. Тринадцать экранов

**1. Главная.** Верно: одна карточка «Дальше», одна главная кнопка под шапкой.
- Н8, П7: «Просрочено · 1 счёт» повторяет первую строку «Требует действия» (David Kim $1,840).
- Н1: на часах 9:41, выезд 8:30–12:30, а статус «Запланирован». Состояние врёт: нужно «Идёт» или «Опаздывает».
- Н6: «Ещё сегодня: 2» выглядит текстом. Не видно, что на него можно нажать и куда он ведёт.
- Улучшить: убрать ячейку «Просрочено». Деньги одной строкой из 2 чисел. Сделать «Ещё сегодня: 2 ›» ссылкой в План.

**2. План.** Верно: полоса дней и один список по времени вместо колонок мастеров.
- Н8: до первого выезда 3 служебных ряда (шапка, «День · Лента · Неделя · Месяц», полоса дней). Чем «Лента» отличается от «Дня», не ясно (Н2).
- Н4: статус есть у 2 строк из 5, у остальных его нет. В строке James «в пути» стоит на месте времени, и время пропадает (Н1).
- Н6: инициалы мастеров (AP, IS, VE) ничем не объяснены.
- Улучшить: убрать «Ленту», вид «Неделя/Месяц» перенести значком в шапку (минус ряд). Время всегда слева, статус — плашкой справа у каждой строки.

**3. Клиенты.** Верно: одна полоса чипов, на карточке один знак долга вместо трёх тегов.
- Н8, П7: подзаголовок «Клиентов: 7» повторяет чип «Все 7». Буквы групп D/E/L/R при 7 клиентах занимают 4 ряда впустую.
- Н5: в карточке 4 цели (карточка, телефон текстом, адрес текстом, «Написать»). Телефон и адрес — мелкий текст, по ним легко промахнуться и случайно позвонить.
- Н2, Н4: чип «Потенциальные» и раздел «Лиды» в меню аватара — два имени одного понятия.
- Улучшить: убрать подзаголовок, буквы показывать только при 20+ клиентах. Карточка в 2 строки (имя + долг / ближайшее событие). Звонок только смахиванием и значком, адрес — в карточке клиента.

**4. Клиент.** Верно: имя один раз, разделы полосой сразу под главной кнопкой.
- Н2: в «Сейчас» работа на $3,420, в причине у кнопки «выставить $3,078». Откуда разница (депозит $342), не сказано.
- Н8, П7: «Bathroom remodel» повторяется дважды подряд (у работы и у выезда). «CLT-0001» в шапке пользователю не нужен.
- Н1: правило выбора главной кнопки по состоянию клиента (нет смет / смета у клиента / принята / долг) не описано, нарисован только один случай.
- Улучшить: причину писать «выставить остаток $3,078 (депозит $342 оплачен)». Номер клиента убрать в «⋯ → Сведения». Добавить в SCREENS таблицу «состояние → главная кнопка».

**5. Форма клиента.** Верно: имя и фамилия в ряд, кнопка закреплена, «＋» и «удалить» значками.
- Н5: «Город, штат, ZIP» — одно свободное поле, по нему будут ошибаться в разборе адреса. Не видно, какие поля обязательны.
- Н8: у единственного телефона тоже стоит «удалить». Второй телефон «Рабочий» нарисован заранее и удлиняет форму. «Компания» и «Источник» нужны редко, но стоят в первом экране.
- Улучшить: одно поле адреса с подсказками. «Компания» и «Источник» — за «Ещё поля ˅». «Удалить» показывать, только когда телефонов 2 и больше.

**6. Работа.** Верно: «статус · сумма» одной строкой, расписание и чек-лист ушли из «Обзора».
- П3: до главной кнопки 5 рядов (номер, название, статус, клиент, адрес). Кнопка оказывается около y≈330, это вне лёгкой зоны большого пальца.
- Н4: «Начать выезд» и значок «в пути» рядом — два действия на один шаг. На Выезде тот же шаг называется «Я в пути».
- Н8: «Что сделать» дублирует такой же список на Выезде.
- Улучшить: в шапке только название, номер JOB перенести в «⋯». Клиент и адрес одной строкой. Одна кнопка «Начать выезд», без значка рядом.

**7. Выезд.** Верно: шаг цепочки закреплён внизу, одной рукой. Исключение из §3 стоит утвердить.
- Н5 (безопасность): закреплённая заметка «Gate code 4512, small dog — call before entering» видна у Клиента, но **не видна мастеру на Выезде**, где она нужнее всего.
- Н4, Н2: «Что сделать» (3 пункта) и «Чек-лист ›» — два чек-листа, непонятно, какой настоящий. Три строки «› » (чек-лист, заметка, фото) — снова мини-простыня.
- Н1: при 9:41 статус «Запланирован» (см. Главную). Строка шагов и главная кнопка дважды называют текущий шаг.
- Улучшить: закреплённую заметку показывать одной строкой над «Что сделать». Чек-лист и «Что сделать» объединить. Фото открывать внутри шага «Работа».

**8. Деньги → Сметы.** Верно: группы по тому, кто должен действовать («Нужно действие» / «Ждём клиента»).
- Н8, П7: чипы «Открытые · Закрытые · Все» повторяют группировку (закрытые уже свёрнуты в «Готово · 2»). До первой строки 4 ряда управления.
- Н1, Н6: в «Нужно действие» стоит «принята $5,180», а какое действие нужно, не сказано.
- Улучшить: убрать ряд чипов. Писать глагол в строке: «принята · выставить счёт», «6 дн · напомнить». Смахивание делает этот глагол.

**9. Смета (редактор).** Верно: позиции сразу под клиентом, «Итого» и «Отправить» закреплены.
- Н4: три способа сохранить — «Сохранить» в шапке, «Отправить», автосохранение черновика («Черновик восстановлен»).
- Н8, П9: «Варианты для клиента: один ＋ Вариант» — редкая функция занимает ряд в первом экране.
- Н7: «＋ Позиция» и «Из каталога» — две кнопки для одной задачи. Количество и цена не выглядят полями ввода (Н6).
- Улучшить: убрать «Сохранить», в подзаголовке показывать «Сохранено». «＋ Вариант» перенести в «⋯». Одно поле «＋ Позиция» с поиском по каталогу.

**10. Счёт.** Верно: сумма крупно и один раз, «Аннулировать» только в «⋯».
- Н1: счёт просрочен на 9 дней, «напоминание не отправлялось», а главная кнопка — «Принять оплату». Следующий шаг по состоянию здесь «Напомнить».
- Н6: 4 значка без слов (смс, ссылка, pdf, напомнить). «SMS» и «Напомнить» оба шлют клиенту сообщение, в чём разница — не видно.
- Н8: «Квитанции об оплате» + «Оплат пока нет» — 2 ряда ни о чём. Позиций счёта не видно, проверить, за что счёт, нельзя.
- Улучшить: главная кнопка по состоянию (просрочен и клиента рядом нет — «Напомнить»). Убрать значок SMS, оставив «Напомнить». Пустые квитанции скрыть, добавить свёрнутое «Позиции · 3 ˅».

**11. Приём оплаты.** Верно: одна шторка везде, сумма подставлена.
- П7, Н8: сумма в шторке трижды — «К оплате» крупно, поле «Сумма», кнопка. Исключение П7 касается только кнопки.
- Н8: поле «Номер чека / Zelle» видно и для карты, и для наличных.
- Н2, Н5 (деньги): по «Карта» не ясно, списывает приложение деньги или только записывает оплату.
- Улучшить: крупная сумма сама служит полем (нажал — правишь), отдельное «Сумма» убрать. «Номер» показывать только для чека и Zelle. Способ по умолчанию — последний. «Карта (записать)» отделить от «Принять картой».

**12. Задачи.** Верно: кружок-отметка и смахивание вместо трёх «Готово».
- Н8: «0 % готово» при одной задаче — пустая цифра. Чипы и фильтр «Только мои» для одной задачи.
- Н8, Н10: подсказка «Кружок слева — отметить» висит постоянно.
- Н1: срочность не видна. «Завтра» и «просрочено» выглядят одинаково.
- Улучшить: убрать процент, группы «Сегодня / Завтра / Позже» вместо чипов. Подсказку показывать один раз. Просроченное — со знаком «!».

**13. Нижнее меню и «＋».** Верно: 5 вкладок без «Ещё», поиск справа, «＋» у большого пальца.
- Н6, Н7: Задачи и Лиды — ежедневная работа (на Главной «Лид без ответа 4 мин»), а лежат в меню аватара: 2 нажатия и их надо помнить.
- Н4: один и тот же «＋» на Главной открывает шторку, на Клиентах сразу создаёт клиента, а на объекте он в шапке. Три поведения.
- Н8: «Создать» повторено в шторке 5 раз. «Работа без сметы» выпадает из ряда по форме.
- Улучшить: заголовок «Создать» и пункты «Лид · Клиент · Смета · Расход · Работа». Лиды — чипом «Лиды» в Клиентах (вместо «Потенциальные»). Задачи — в «Требует действия» на Главной.
