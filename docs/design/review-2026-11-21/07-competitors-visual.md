# 07 · Раскладка экранов у конкурентов и лучших приложений

21.11.2026 · исследователь интерфейсов · для LAYOUT-RULES.md v1.
**Как собрано.** Картинки скриншотов из App Store и справок прочитать не удалось: на страницах App Store картинки пустые, в справках alt-тексты — это имена файлов. Поэтому всё ниже взято **по описанию**: пронумерованные выноски и тексты справок (Jobber, ServiceTitan, Housecall Pro), журналы изменений (Linear, HCP) и обзоры (Things, Revolut). Справки Workiz и Tradify ответили 403, по ним есть только выдержки из поиска. Про Monzo и Apple Wallet/Contacts — **по знанию продукта**, ссылок нет. Помечено: [выноски] — порядок блоков подтверждён нумерованными выносками справки; [текст] — описан словами; [знание] — без источника.

## 1. Главная / Сегодня
**Jobber** [текст] — [Home in the Jobber app](https://help.getjobber.com/en/articles/home-in-the-jobber-app/): шапка (More слева, колокольчик и «Сообщения» справа) → **карта дня + «Up Next»** (выезды по времени, «в любое время» — в конце; админу ещё ожидаемая выручка дня) + «View all» → **To do** (заявки, одобренные сметы, просроченные счета; срочные — сверху, нажатие открывает отфильтрованный список) → **Business health** (неделя: сумма работ, число выездов, стрелки тренда) → Discover (реклама функций, закрывается ✕). «＋» — внизу справа, почти на всех экранах; на экране выезда его место занимает камера ([App basics](https://help.getjobber.com/en/articles/jobber-app-basics/)). Мастер без прав админа видит только карту и Up Next.
**ServiceTitan FMA** [текст] — [Before/after guide](https://help.servicetitan.com/docs/before-and-after-guide-fma): вместо трёх вкладок (Overview / All Jobs / History) — одна Home с текущей работой; «View all» → сегменты Today · Upcoming · Previous · Paused. Карточки работ видны раньше, чем докачаются данные ([release hub](https://help.servicetitan.com/release-hub/docs/see-your-schedule-sooner-with-a-faster-more-reliable-field-mobile-app)).
**Revolut 10** [текст] — [revolut.com/revolut10](https://www.revolut.com/revolut10): баланс крупно → ряд быстрых действий (можно настроить) → виджеты-«избранное». Пользователи ругали промо на главной и спрятанную за «See all» ленту операций.
- **Взять:** «Up Next» = наша «Дальше», «To do» = «Требует действия» со срочными сверху и переходом в отфильтрованный список, сводка недели **одной строкой** с трендом; мастеру — урезанная Главная по правам.
- **Не брать:** карту на пол-экрана (дорого по высоте и не о деньгах — максимум маленький значок «маршрут дня»), Discover и промо, четыре сегмента истории.

## 2. Список клиентов
**Jobber** [текст] — [Client information](https://help.getjobber.com/en/articles/client-information-in-the-jobber-app/): клиентов нет отдельной вкладкой, есть **общий Search** (вкладка рядом с «＋»). По умолчанию — 100 последних изменённых; поиск по имени, телефону, адресу, позициям, номеру операции; фильтр-чипы типа (клиенты / заявки / сметы / работы / счета) и статуса (Active / Lead / Archived). Строка работы: статус, тип, номер, дата, сумма, адрес.
**Apple Contacts** [знание]: большой заголовок → поиск под ним → группы по букве с указателем A–Z справа → строка в одну линию (только имя). Самый плотный образец.
**Linear** [текст] — [screensdesign](https://screensdesign.com/apps/linear-mobile/?vs=151806): группы по статусу, в строке значок статуса + заголовок + метаданные; какие свойства показывать — пользователь включает сам.
- **Взять:** указатель A–Z справа (как в Contacts) при 50+ клиентах; одну строку под именем (баланс или следующий выезд); по умолчанию — сортировку «недавние», переключатель «А–Я» внутри фильтра.
- **Не брать:** общий поиск вместо списка клиентов (подрядчику нужен список «моих людей»); строку из 6 полей, как у работ в Jobber.

## 3. Карточка клиента
**Jobber** [текст]: шапка — **имя + баланс под ним**; справа сверху значки «позвонить» и «SMS»; кнопка **Create** (заявка / смета / работа / счёт, клиент уже подставлен) → вкладки **Client · Work · Notes (· Files)**. В Work — недавние объекты, у каждого тип, номер и статус, фильтр по типу. В Client — секции с правкой стрелкой; главный контакт отмечен звёздочкой.
**Housecall Pro** [текст] — [Platform refresh changelog](https://help.housecallpro.com/en/articles/13975339-platform-refresh-changelog): street view и адрес подняты в шапку.
**Apple Contacts** [знание]: аватар → имя → ряд круглых значков (сообщение, звонок, видео, почта) → поля.
- **Взять:** «имя → баланс одной строкой» (наша «статус · сумма»), ряд значков как в Contacts, одну кнопку «Создать ▾» с подставленным клиентом, Work одной лентой с фильтром типа (у нас — полосой разделов с числами).
- **Не брать:** street view (тяжело, нужна сеть; адрес мелко + маршрут — достаточно), отдельную вкладку Client с полями — поля прячем в «Подробнее».

## 4. Смета — редактор и просмотр клиентом
**Housecall Pro** [текст] — [changelog](https://help.housecallpro.com/en/articles/13975339-platform-refresh-changelog), [Sales proposal on mobile](https://help.housecallpro.com/en/articles/7834798-sales-proposal-tool-on-mobile): шапка (номер + имя клиента, под ней действия **Present · Send · Approve · Copy to job**) → вкладки по типу данных, все варианты — во вкладке **Options**. Снизу постоянная панель (время, статус), смахиванием вверх — фото и заметка из любой вкладки. «Present» показывает варианты карточками, листаются вбок; «view option» открывает подробности (услуги, материалы, налог, скидка, депозит). У варианта может быть «as low as $/мес» (рассрочка Wisetack). Отправка — значком самолётика.
**Jobber** — клиенту [текст] [Quote approvals](https://help.getjobber.com/es/articles/quote-approvals/): у клиента одна кнопка — **Approve** или **Approve & Pay Deposit**, затем подпись (нарисовать или набрать). Подрядчику приходит пуш.
**Joist** [текст] — [deposit](https://support.joistapp.com/en/articles/9212935-how-do-i-request-a-deposit-on-my-estimate-or-invoice): редактор — одна прокручиваемая форма; ниже позиций секция Payment Option → «Request a Deposit» ($ или %); у клиента строка «Deposit Due» под итогом.
**ServiceTitan** [текст]: шаблон сметы — «From Template», подгруппы — «+ Sub-Items», варианту можно поставить отметку «Recommended».
- **Взять:** для клиента — одну кнопку «Одобрить и оплатить депозит $X» + подпись; варианты листаются вбок карточками с отметкой «Рекомендуем»; «≈ $/мес» мелко под ценой; в редакторе — итог и депозит закреплены внизу.
- **Не брать:** четыре равных действия под заголовком (у HCP Present / Send / Approve / Copy — это нарушает П2; у нас одна главная, остальное значками); вкладки в редакторе сметы.

## 5. Счёт и приём оплаты
**Jobber** [текст] — [Tap to Pay](https://help.getjobber.com/es/articles/tap-to-pay/): на счёте кнопка **Collect Payment** → способ (Tap to Pay on iPhone, карта, наличные…) → квитанция уходит на почту сама; чаевые — на экране Tap to Pay.
**Housecall Pro** [текст] — [Invoice actions](https://help.housecallpro.com/en/articles/8160826-invoice-actions-and-summary): на работе — значок счёта сверху; в таблице счетов значки ✎ и 💳 (принять оплату); Send, View, Print, PDF, Void — в «⋯».
**Workiz** [текст, справка 403, выдержка из поиска] — [Managing jobs on mobile](https://help.workiz.com/en/articles/4812389-managing-jobs-on-mobile): быстрые действия **Start · ETA · Pay · Notes**; во вкладке Finance «＋» у Payments → «Send payment link».
**Apple Wallet / Pay** [знание]: сумма крупно → кому → одно подтверждение внизу (Face ID / боковая кнопка).
- **Взять:** «Принять оплату · $X» как единственная главная → шторка способов с Tap to Pay первым → квитанция автоматически; ссылку на оплату — значком; «Аннулировать» — только в «⋯» (у нас уже так, это подтверждено рынком).
- **Не брать:** Send и PDF глубоко в «⋯» (HCP) — у нас они значками в ряд, так быстрее.

## 6. Расписание / План
**Jobber** [текст] — [App basics](https://help.getjobber.com/en/articles/jobber-app-basics/): заголовок — **месяц, нажатие открывает выбор даты**; «Today» справа сверху; виды Day · List · 3 Day · Week · Map (значок «View options») плюс короткий переключатель Day / List / Map. Цвет по типу: выезд зелёный, задача синяя, событие жёлтое, заявка бронзовая. Пользователи жалуются: чтобы увидеть занятость, надо тыкать в каждую дату (отзыв App Store).
**Housecall Pro** [текст]: нажатие на пустое окно календаря создаёт работу, смету или событие; новый календарь включается переключателем внизу вкладки Schedule.
**ServiceTitan** [текст]: Today / Upcoming для мастера, планшет — левая колонка разделов.
- **Взять:** «Ноябрь ▾» с выбором даты нажатием на месяц, «Сегодня» в шапке (возвращает в текущий день), точку «в дне есть дела» на пилюле — это лечит жалобу на Jobber; создание долгим нажатием на время; режим «Карта» как 2-й вид, а не по умолчанию.
- **Не брать:** пять видов, четыре цвета типов (цвет у нас — только статус, правило 2; тип — значком).

## 7. Выезд (у мастера)
**Jobber** [выноски, 14 шт.] — [Jobs in the Jobber app](https://help.getjobber.com/en/articles/jobs-in-the-jobber-app/): ← назад · значок звонка · значок SMS → значок типа визита · **статус** · **заголовок** · **адрес** (нажать — скопировать или открыть в картах) · значок маршрута · значок **On my way** · дата начала · окно прибытия → кнопки **Start Timer · Complete Visit · ⋯** → вкладки **Visit · Details · Notes**; в Visit по порядку: Instructions → Checklists → Line items → Schedule details → Team. Камера вместо «＋». Если чек-лист пуст при завершении — предупреждение, но завершить можно.
**ServiceTitan FMA** [текст]: **Dispatch → Arrive → Close Out закреплены внизу почти каждой вкладки**; вкладки Job · Equipment · Forms · Estimates · Invoice; в Job — Pinned Notes, Media, More. Форма прибытия открывается сама при приезде (iOS). Отзыв App Store: техникам не нравится меню.
**Housecall Pro** [текст] — [Time tracking](https://help.housecallpro.com/en/articles/5416935-tracking-time-on-jobs): **On my way → Start → Finish**, у каждого шага метка времени; OMW шлёт клиенту SMS; голосом: «I'm on my way…» (альфа).
- **Взять:** одну закреплённую кнопку-машину состояний «В пути → Начать → Завершить» (как у ST, но один шаг за раз); в шапке значки звонка, SMS, маршрута и «в пути»; порядок «Инструкции → Чек-лист → Позиции»; камеру на месте «＋»; мягкое предупреждение про пустой чек-лист.
- **Не брать:** две равные кнопки Start Timer + Complete Visit рядом (Jobber), 5+ вкладок (ST), авто-всплывающую форму.

## 8. Образцы плотности
**Linear mobile** [текст] — [redesign 10.2025](https://linear.app/changelog/2025-10-16-mobile-app-redesign), [настраиваемая навигация 01.2026](https://linear.app/changelog/2026-01-22-customize-your-navigation-in-linear-mobile), [Liquid Glass](https://linear.app/now/linear-liquid-glass): нижняя панель с порядком, который задаёт пользователь, «Create» в шапке каждого экрана, у задачи свойства — **чипами в ряд над заголовком**, внизу закреплена строка комментария, редкое — в шторке по долгому нажатию.
**Things 3** [текст] — [MacStories](https://www.macstories.net/reviews/things-3-beauty-and-delight-in-a-task-manager/), [AppAdvice](https://appadvice.com/post/things-3-from-cultured-code/747542): интерфейс «невидимый», задача в списке — просто текст без ячейки; Magic Plus — нажать для меню, перетащить для выбора места.
**Monzo** [знание]: баланс → «Сегодня потрачено» → лента по дням со вставками-заголовками дат, суммы выровнены справа моноширинными цифрами.

## 9. Топ-12 приёмов раскладки для GoRix
1. **«Имя → одна строка статус · сумма»** в шапке Объекта (Jobber: имя + баланс). Больше ничего крупного.
2. **Ряд значков связи в шапке:** звонок · SMS · маршрут · «в пути» (Jobber, выноски 2, 3, 8, 9). Подписи — только для VoiceOver.
3. **Одна закреплённая кнопка-машина состояний** для выезда: «В пути → Начать → Завершить», на каждом шаге метка времени (ST + HCP).
4. **«Требует действия»: срочное сверху**, нажатие открывает уже отфильтрованный список (Jobber To do).
5. **Сводка недели одной строкой с тренд-стрелкой**, без графиков; графики — в «Подробнее» (Jobber Business health).
6. **Камера на месте «＋»** внутри выезда и работы (Jobber); на остальных экранах «＋» один, внизу справа.
7. **«Создать ▾» с подставленным контекстом** из карточки клиента или работы (Jobber Create).
8. **Секции выезда в порядке работы мастера:** Инструкции → Чек-лист → Позиции → Время → Бригада (Jobber Visit).
9. **Клиенту — одна кнопка «Одобрить и оплатить $X»** + подпись; варианты — карточками вбок с «Рекомендуем» и «≈ $/мес» (Jobber + HCP).
10. **«Принять оплату» → шторка способов, Tap to Pay первым** → квитанция сама (Jobber); «Аннулировать» — только в «⋯».
11. **Месяц в заголовке Плана нажимается** (выбор даты), «Сегодня» справа, точка-индикатор на пилюле дня (Jobber + лечение жалобы на него).
12. **Плотность Contacts и Linear:** строка списка — одна линия + одна мелкая, свойства чипами в один ряд, A–Z справа у длинных списков, редкое — в шторку по долгому нажатию.

**Общий вывод.** Лидеры (Jobber, ST) сами ушли от «вкладок всего» к «одна Главная + закреплённые действия внизу». Перегибы, которые у них видны: 4 равных действия под шапкой сметы у HCP, 2 равные кнопки на выезде у Jobber, 5 вкладок у ST. В GoRix их закрывают правила П2 и П5. Тёмный графит с одним акцентом есть как вариант темы у Jobber, а как основа — только у Linear: опираться на Linear (стекло, приглушённые поверхности, акцент — только на главном).
