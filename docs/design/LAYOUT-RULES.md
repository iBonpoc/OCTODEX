# Правила вёрстки GoRix

Версия 1 · 21.11.2026 · руководитель №21. Основание: слова основателя (#2348, #2350 и комментарий), исследование и дебаты дизайнеров (`2026-11-20-direction/01–06`), Apple HIG, Material 3, эвристики Нильсена.
**Как пользоваться:** экран не верстается «с нуля». Сначала — какой это шаблон (§2), потом заполняется по его порядку (§3), потом сверка по чек-листу (§6). Правило нарушено — пишем исключение с причиной здесь же.

## 1. Принципы (почему так)
| # | Правило | Почему |
|---|---|---|
| П1 | **У экрана одна работа.** Перед вёрсткой — одна фраза «зачем сюда пришли и что делают чаще всего». Всё, что не служит ей, — ниже, в раздел или в «⋯». | Перегрузка — боль К6 №3; «простыня» — слово основателя. |
| П2 | **Одна главная кнопка на экран** — «следующий шаг», залита акцентом. Остальное — вторичное. | Закон Хика: меньше выбора — быстрее решение; 10 % акцента (60/30/10). |
| П3 | **Главное — под большим пальцем:** главная кнопка внизу (закреплена) или сразу под шапкой, если внизу панель вкладок. | Закон Фиттса; работа одной рукой (К5). |
| П4 | **Компакт.** Две короткие кнопки — в ряд, пара полей («дата · время», «с · по») — в ряд, если помещаются (`ButtonPair`, `FieldRow`). Кнопка 40, зона нажатия 44. | Слово основателя 21.11. |
| П5 | **Не полотна.** Чипов — не больше одного ряда; больше — горизонтальная прокрутка или «⋯». Список разделов объекта — горизонтальной полосой, не столбцом строк. | Слово основателя 21.11. |
| П6 | **Значок вместо слова** для вторичных действий (позвонить, написать, маршрут, удалить, изменить, видимость), всегда с подписью для VoiceOver. Слово — только у главной кнопки и там, где значок не ясен. | Слово основателя 21.11; меньше шума. |
| П7 | **Одно — один раз.** Имя, адрес, телефон, сумма, статус на экране не повторяются. | Слово основателя 21.11. |
| П8 | **Жест — ускоритель, не единственный путь.** Смахивание по строке (уместные действия), перетаскивание порядка; то же действие есть в «⋯». | HIG; перчатки и VoiceOver. |
| П9 | **Детали по требованию.** Подробности, графики, редкие поля — свёрнуты («Подробнее») или в разделе. | Прогрессивное раскрытие. |
| П10 | **Цвет 60/30/10:** 60 — графитовый (светло-серый) фон, 30 — карточки на тон светлее + текст, 10 — акцент: главная кнопка, активная вкладка, выбранное. Статусы — тональные плашки «значок + слово». Нигде чистого чёрного и чистого белого. | Слово основателя 21.11; правило 2. |

## 2. Шаблоны экранов
Каждый экран приложения принадлежит одному шаблону. Своих раскладок нет.

| Шаблон | Экраны | Работа экрана |
|---|---|---|
| **Обзор** | Главная | «Что мне делать сейчас» |
| **Список** | Клиенты, Сметы/Счета/Оплаты (Деньги), Лиды, Работы, Задачи, Каталог | «Найти нужное и сделать быстрое действие, не открывая» |
| **Объект** | Клиент, Работа, Выезд, Смета (просмотр), Счёт, Лид | «Понять, что с ним сейчас, и сделать следующий шаг» |
| **Редактор** | Смета (правка), Форма клиента, Событие, Выезд (создание) | «Быстро и без ошибок заполнить» |
| **Календарь** | План | «Что когда и у кого» |
| **Шторка / меню** | выбор, подтверждение, короткое действие | «Выбрать одно» |

## 3. Порядок блоков в шаблоне (сверху вниз)
**Обзор:** шапка (заголовок, справа значки: цвет-прототип, колокольчик, аватар) → «Дальше» (одна карточка + главная кнопка) → «Требует действия» (≤ 3 + «Все») → сводка одной строкой → «Подробнее» (свёрнуто).
**Список:** заголовок + «＋» → поиск значком, фильтры одной полосой с прокруткой → группы (буква / статус) → компактные карточки: аватар-инициалы, имя, одна строка главного, справа сумма/статус; быстрые действия мелко (телефон, адрес, «Написать»); смахивание.
**Объект:** шапка (имя/номер, одна строка «статус · сумма», адрес мелко — нажимается) → быстрые действия значками в ряд → главная кнопка «следующий шаг» с причиной под ней → полоса разделов «Обзор · … N» → содержимое раздела. «⋯» — редкое и опасное.
**Редактор:** поля группами в карточках, пары в ряд, подписи над полями; итог/сохранение закреплены внизу; опасное — только в «⋯» с подтверждением.
**Календарь:** полоса дней пилюлями (выбранный — акцент) → список дня по времени → пустые окна не рисуются строками.

## 7. Журнал экранов (было → стало → почему)
Заполняется по каждому пересобранному экрану.

### План (Календарь) — 21.11
- **Было:** вкладки, ряд поиска, стрелки с датой, ряд чипов «пн, 16 нояб.», блок «Не назначено» отдельной кнопкой, простыня колонок по мастерам с пустыми «Свободен».
- **Стало:** вкладки → поиск и фильтры → «Ноябрь ‹ ›» → полоса пилюль дней (выбранный залит акцентом, точка — «в дне что-то есть») → один список дня по времени (крупный час, клиент, «– конец», статус, адрес, мастер); смахивание «Открыть / Перенести · Назначить»; доска по мастерам — только 820/1280.
- **Почему:** шаблон «Календарь», образцы основателя; полоса дней вместо полотна чипов (П5), одно — один раз (П7), жест с заменой на карточке (П8).
