# Решения чата аудита по задачам с меткой «вопрос» (12.11.2026)

Основание: слова основателя 12.11.2026 (через чат «Приём замечаний»): уточнений ему не задавать, решать между чатами. Правило с этого дня: основателя спрашиваем только о том, что без него нельзя, — деньги из его кармана, право (юрист), его руки в чужих сервисах, выбор вида по снимкам. Остальное решает чат аудита по рекомендации руководителя и сообщает основателю одной строкой: «решено так, можно отменить».

Каждое решение ниже основатель может отменить одним словом; откат — отдельным PR.
