## 1. Точное воспроизведение жалобы (сценарий А)

Жалоба воспроизведена. Скорее всего основатель попал не в «Смету», а в «Новую работу». Они стоят рядом в одной шторке, и «Новая работа» стоит ПЕРВОЙ.

1. `/clients` -> карточка «Sarah Mitchell» (`A01-clients-list`, `A02-client-card`). На карточке клиента нет кнопки «Создать смету». Единственная точка входа — круглый жёлтый «+» (aria «Создать») справа внизу, он залезает на нижний край блока «Объекты» (`A02`).
2. «+» открывает шторку «Быстрые действия» с двумя строками: **«Новая работа»** (первая) и **«Смета»** (вторая) (`A03-client-create-menu`). Слова «создать смету» нигде нет; «Смета» — просто существительное.
3. «Новая работа» -> `/job/new?customerId=c1` (`A04-job-new-top`). Экран: клиент, адрес, поле «Название», **чипы «Тип работы»: Установка / Ремонт / Обслуживание / Гарантия / Другое**, описание, «Направление», расписание. **Ни блока «Позиции», ни кнопки «Добавить позицию».** Это ровно то, что описал основатель.
4. Внизу (за экраном, надо прокрутить) главная кнопка **«Создать работу»**, она серая/неактивна, пока не введено «Название» — над ней серая плашка «Напишите название работы» (`A05-job-new-chosen-type-bottom`). Выбор типа работы кнопку не включает.
5. Ввёл название -> «Создать работу» -> `/job/JOB-0009` «Ждёт даты» (`A06-job-created`). Смета не создана. На экране работы кнопки «Создать смету» нет; главная жёлтая — «Запланировать работу». Основатель так и остаётся без сметы.
6. Правильный путь: «+» -> «Смета» -> `/estimate/new?customerId=c1` (`A31-estimate-new-top`, `A32-estimate-new-bottom`). Тут **есть** блок «Позиции» и кнопка «Добавить позицию»; **выбора типа работы нет вообще**. Внизу «Сохранить и отправить» (приглушена) и «Сохранить» (неактивна) + подсказка «Добавьте хотя бы одну строку с названием».

Варианты:
- Пустой каталог и нет типов работ (подменил `catalog=[]`, `jobTypes=[]`): в «Добавить позицию» остаётся только «Своя позиция — Не из каталога», текст при вводе превращается в «Своя позиция: «…»» (`A11`, `A12`). Подсказки «каталог пуст, заполните в Ещё -> Каталог» нет. У «Новой работы» блок «Тип работы» исчезает целиком (`A13`).
- Gutters включён (Ещё -> Модули -> «Подключить»): у клиента появляется кнопка «Замер желобов» и вкладка «Замеры»; шторка «+» и конструктор сметы не меняются (`A21..A22`). «Замер желобов» -> `/module/gutters/start`: выбор адреса, дальше холст. Типа работы в смете нет и тут.
- Из «Сегодня» «+» даёт: Новый лид / Новый клиент / **Новая работа** / Смета / Расход по чеку (Фото из списка пропало). Тот же порядок.
- Из `/estimates` кнопка «Новая смета» -> `/estimate/new` без клиента (выбор клиента внутри). Из списка «Сметы» клиента есть только безымянный «+» (`A34`).
- Тип работы — это поле работы (`jobTypes`), в смете его нет; у работы, созданной из подписанной сметы, «Тип работы: Не указан» (`19`).

## 3. Проблемы

**P0**
- Нет в явном виде. Но вход в путь «Создать смету с клиента» — ловушка (см. P1-1): человек попадает в «Новую работу» и считает, что смета создана.

**P1**
1. **«Новая работа» стоит перед «Смета» в «+» клиента и «Сегодня»**, а в новой работе есть «Тип работы» и «Создать работу» без позиций и цены. Человек, хотевший смету, оказывается в форме работы (жалоба основателя). Смета не называется «Создать смету». Правильный вход — кнопка прямо на карточке клиента, жёлтая, «Создать смету».
2. **Деньги не сходятся: оплата на выезде** (`visit.pay` в `store.tsx` ~1453). В демо (локальном сторе) остаточный счёт $459 помечается оплаченным (`paidCents=45900`), но **записи платежа и квитанции нет** (`payments` без суммы 45900, квитанций 0): у клиента «Оплатил всего $51» при «Выставлено $510», нет квитанции RCT, в «Получено» на главной и в «Собрано» не попадает, в истории работы платежа нет. Счёт-остаток без номера и названия («Остаток по договору»).
3. **Главная кнопка лида после ответа — «Напомнить про смету»**, хотя сметы нет. Нажатие просто пишет «SMS клиенту» в историю (напоминание о несуществующей смете). Должно быть «Создать смету».
4. **Тупик на оплаченном счёте-задатке**: кнопок следующего шага нет (`18`).
5. **«Отчёт уйдёт клиенту»** на закрытом выезде: отчёта клиенту в приложении нет (нашёл только текст `visit.completedHint`).

**P2**
- Сырой ключ в истории лида: «Статус: st.replied» (вкладка «Переписка» показывает «Статус: На связи»).
- После отправки сметы главная остаётся «Отправить клиенту»; следующий шаг (подпись) внизу страницы, не подсвечен.
- Две подписи клиента (смета, потом выезд) с текстом «клиент подтверждает выполненную работу и сумму» уже на подписи сметы.
- Кнопка работы «Начать» открывает экран выезда, а не начинает работу; «В пути» на работе (SMS) и «Я в пути» на выезде — одно название, разные действия; «Оплата» рядом без пояснения.
- Форма «Запланировать работу» остаётся открытой после сохранения, кнопка активна — риск второго выезда.
- На карточке клиента нет кнопки сметы; «+» залезает на содержимое.
- В «Сметах» клиента единственный вход — безымянный «+».
- Клиент создаётся при открытии `/estimate/new` из лида (пустой клиент останется, если выйти).
- Шторка «Отправить клиенту» остаётся открытой после «SMS».
- Название сметы и работы = склейка имён позиций.
- Английское в русском интерфейсе: счёт «Deposit», «Good · итог…», названия позиций каталога и чек-листа.
- Двойная точка «ср, 11 нояб..».

**P3**
- Zelle выбран по умолчанию в способе оплаты.
- Карточка статуса лида показывает «Шаг» (непонятный чип) и главная «Задачи» у лида Tom Becker.
- «Прибыль по работе $510 · 100%» при нулевых расходах; «Маржа не посчитана».
- Поле «Pasadena» вместо «Город» в форме лида.
- Пустой каталог: нет подсказки заполнить каталог в «Ещё -> Каталог».
- Шторки «Нет фото до/после» дважды подряд, жёлтая кнопка «Заполнить» по умолчанию.
- «Лиды» нет в нижних вкладках (Главная/План/Чаты/Клиенты/Ещё).
- История работы: «В пути ср» раньше, чем «Выезд выполнен чт» (демо-время).
- «По направлениям: Направлений 0» на отчётах.

Консоль и pageerror: чисто.
