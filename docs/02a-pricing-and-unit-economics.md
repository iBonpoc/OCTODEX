## 2. Сколько стоит AI на одну компанию

### Что такое «AI-действие»
Одна выполненная команда пользователя. Например, «найди Юрия, сделай смету» — одно действие, даже если внутри несколько вызовов модели.

### Себестоимость одного действия
| Тип | Пример | Как считаем | Цена |
|---|---|---|---|
| **Навигация** | «Открой клиентов» | Распознаётся **на устройстве без LLM** (словарь команд) | **$0** |
| Простое | «Найди Юрия», «покажи неоплаченные инвойсы» | Haiku: ~10k input (в основном из кэша) + 300 output | **~$0.002** |
| Чек → расход | Фото чека Home Depot | Haiku vision: картинка ~1.5k + промпт ~2k + 400 output | **~$0.002–0.005** |
| Сложное | «Сделай смету на 150 ft по прошлым сметам», «удали 10-ю позицию, 5-ю поменяй на 6"» | Sonnet: 2–3 вызова × (8k cached + 3k свежих + ~1k output с размышлением) | **~$0.04–0.06** |
| Скан прайс-листа поставщика | PDF на 5 страниц | Sonnet через Batch | ~$0.03–0.10 разово |

**Средняя цена одного AI-действия при смеси 50/50 простых и сложных ≈ $0.025.**

### На компанию в месяц
| Профиль | Действий/мес | Себестоимость AI |
|---|---|---|
| Лёгкий (иногда спрашивает) | 50 | ~$1.25 |
| **Типичный** (компания из 4 человек, как у основателя) | 150–200 | **~$4–5** |
| Активный (всё делает голосом) | 500 | ~$12.5 |
| Экстремальный | 1,500+ | ~$37+ → **нужен лимит** |

**Вывод:** без лимитов AI может съесть весь тариф за $50. Нужны пакеты действий и мягкий лимит.

### Доход с платежей клиентов (главный потенциал)
- Подрядчик принимает оплату через продукт: карта или ACH через Stripe Connect.
- Мы берём **прозрачную наценку**, например **+0.5% к тарифу Stripe** (окончательно решим позже). Рынок уже недоволен скрытыми комиссиями, поэтому наценка должна быть видна.
- Пример: gutter-компания с оборотом $40k в месяц, из них $20k проходит через нас. Доход: **~$100/мес, больше подписки.** Так зарабатывают Jobber и Housecall Pro.
- ACH (0.8%, максимум $5) поощряем: подрядчику дешевле, и в Калифорнии это законно.

### С модулем Gutters (+$39)
Starter + Gutters = $109/мес при марже **~89%**.

### Защита от минуса
1. **Мягкий лимит AI:** при 80% показываем предупреждение, при 100% предлагаем пакет. Навигация и простые команды на устройстве работают и без лимита.
2. **Жёсткий потолок на компанию в сутки** (защита от злоупотреблений и багов), например 200 действий в день.
3. **Счётчик использования** виден пользователю: «использовано 63 из 100 AI-действий, 210 из 500 SMS».
4. **Технические рычаги экономии:**
   - навигация без LLM;
   - распознавание речи на устройстве;
   - Haiku для простых задач, Sonnet только для сложных;
   - prompt caching (кэшированный ввод стоит в 10 раз дешевле);
   - Batch API для несрочных задач (−50%).
5. **SMS только из пакета:** перерасход невозможен, только докупка.
6. **Ежемесячный отчёт себестоимости по каждой компании** для нас: видим, кто убыточен, и корректируем лимиты.

## 8. Что проверить
- Реальное потребление AI на бета-тесте компании основателя: сколько действий в день и какая смесь простых и сложных.
- Официальные ставки Twilio, 10DLC (ISV-модель: регистрируем бренд каждой компании), Google Maps (бесплатные лимиты), Supabase.
- Возможность принимать комиссию с платежей (Stripe Connect application fee) и юридическую формулировку.
- Нужна ли оплата через App Store: в США сейчас можно направлять на сайт без комиссии (см. `01-competitor-analysis.md` §9).
