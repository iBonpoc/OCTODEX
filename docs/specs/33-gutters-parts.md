## П18.2 Брейншторм: как описать «все крепления и расходники»
| Вариант | Плюсы | Минусы |
|---|---|---|
| А. Расширить перечисления в коде (`HangerKind` += rafter, roof_bar, wrap_around, shank…; ferrule «зашить» к spike) | просто читать | каждый новый вид у поставщика (Hangfast, Boss, своё) — правка кода и выпуск; комбинации «hidden с винтом / без» множат варианты; расход (винты к креплению) зашит |
| **Б. Наборы (kits) как данные правил.** Вид крепления = `{ id, шаг, детали на одно крепление }`; то же для креплений даунспота по типу стены, для сеток (длина куска + винты), для соединений (заклёпки, герметик или припой на соединение). Движок по умолчанию несёт полный список основателя; компания отключает, переименовывает, меняет расход, добавляет свой вид (M7) | новый вид у поставщика — запись в настройках, не код; расход виден и правится; один механизм для креплений, стен, сеток, соединений | чуть больше данных; список по умолчанию надо держать в тестах |
| В. Крепление = одна позиция прайса, расходники не считать | меньше всего работы | основатель прямо просит расходники; «забытая позиция — минус маржи» (PRD 06 §2) |
**Выбор: Б.** Движок остаётся чистой функцией «замер + правила → количества»; настройки компании (M7) только подменяют данные правил.

## П18.4 Вход движка: что добавляется (всё новое — необязательное)
- `GutterStock`: `material` (`aluminum`, `steel`, `galvalume`, `copper`, `zinc`, свои), **`gauge`** (`.027`, `.032`, `26ga`, `24ga`, `16oz`…), **`finish`** (`mill` / `painted`), `color` (только у `painted`). Ключ запаса: профиль.размер.материал.толщина.цвет.
- `MeasuredRun`: `hanger` — **id набора** (П18.6); `mount` (`fascia` / `rafter` / `roof` / `crown` / `angled`) — для выбора набора по умолчанию модулем; `hangerSpacingIn?` (снег/ветер); `wedges?` (клин под крепление на наклонной доске); `guardsIn` + `guardType` = id набора сетки.
- `MeasuredCorner.method`: `cut` / `strip` / `prefab`; `kind`: `out` / `in` / `bay`.
- `MeasuredDownspout`: `shape` `rect` / `round`; **`dsStyle`** `plain` / `corrugated`; `wall` (`wood` / `stucco` / `brick` / свои) — набор креплений к стене; `head?` `funnel` / `conductor` (leader head); `reducers?` `{to, qty}`; `diverter?`; `eaveBox?` `open` / `closed` / `sloped`; `endOutlet?` `start` / `end` (полукруглый «D» end section with outlet — вместо заглушки и выпуска); `bottom.color?` (splash block / flex — Brown, Green, Gray, White); `bottom.pipe?` (размер трубы в землю — переходник прямоуг. → круглый).
- `MeasurementInput.wyes?`: `{ id, dsIds: [a, b] }` — Y-воронка, два даунспота в один.
- `funnel?: boolean` остаётся (= `head: "funnel"`) — совместимость с `geometry.ts`.

## П18.5 Полный список деталей и правило количества
Ед.: ft — футы (дробные, точно), ea — штуки, lb — фунты. «Кому»: К — клиенту в смете, П — поставщику (закупка), К+П — обоим.

**Желоб (раздел `gutter`)**
| Деталь | Ключ | Правило | Ед. | Кому |
|---|---|---|---|---|
| Желоб установленный | `gutter.<запас>` | Σ длин линий | ft | К |
| Рулон (бесшовный) | `coil.<запас>` + `blankIn` | ⌈(Σ длин + вырезанные углы × 6″) × (1 + запас) ÷ 12⌉ | ft | П |
| Секции (секционный, полукруглый) | `section.<запас>` | ⌈(Σ длин + углы) × (1 + запас) ÷ длина секции⌉ | ea | П |

**Защита (`guards`)**: сетка — футами клиенту (`guard.<вид>…`, К) и кусками поставщику (`guardpiece.<вид>…` = ⌈покрыто на линии ÷ длина куска⌉ по каждой линии, П); винты сетки — из набора на кусок; сетка выпуска / wire strainer — `outletscreen` (1 на даунспот, галочка).

**Низ даунспота (`ds_bottom`)** — без изменений (удлинитель, splash block, flex, в землю + переходник, отбойная пластина на нижнюю крышу) + цвет блока/flex в атрибутах; в землю: переходник «прямоуг. → круглый» с размером трубы.

**Крепления даунспота к стене (`fasteners`)** — П18.7. **Расходники (`consumables`)** — П18.8. **Работа (`labor`)** — как сейчас (монтаж по этажам, даунспот по этажам, вырезка угла, демонтаж) + работа из набора крепления (tile: `labor.tile` за фут, PRD `fee.tile`).

## П18.14 После ревью (code-reviewer, 07.11.2026) — что изменилось против П18.5–П18.11
- **Вход — целые дюймы ≥ 0**, шаги — целые > 0. Иное (0, −24, 479.6, пустое поле) исправляется (округление, 0, умолчание набора/компании) с советом `input_fixed`; `Infinity` и отрицательных количеств не бывает. `purchaseQty` отказывает на отрицательном количестве.

- **Винты и анкеры** из разных наборов (сетка, хомуты, соединения даунспота) — одна строка в разделе `consumables`, раздел не зависит от порядка.

Медь и алюминий больше не сливаются в одну строку.
- **Сетка без вида** — набор компании по умолчанию `defaultGuard` (micromesh).
- **Советы:** второй «D»-выпуск на том же конце (`end_outlet_taken`, ставится обычный выпуск), полоса из рулона для размера без длины (`strip_size_unknown`), Y на одном даунспоте дважды (`wye_same_downspout`).
