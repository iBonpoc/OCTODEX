**Чем мы лучше (измеримо):** образцы — те же детали приложения (не копия в другой библиотеке, как в Storybook), обе темы на одном устройстве (поле «Тема ⌄»); «где видно» — **собирается из кода скриптом**, а не пишется руками (не устаревает: сторож); путь до любой строки — 1 нажатие от первого экрана витрины (группы — заголовками на одном экране, как Настройки iOS) или поиск; от вкладки «Ещё» — 4.

## 4. Живой образец — по виду значения (подгруппа)

У каждого листа: **образец** · **имя по-русски** · **где видно** · ключ (`caption` 13, `tone="mut"`) · значение. Тип образца задаётся **на подгруппе / по виду значения**, не на группе.

| Вид значения | Живой образец | Подгруппы |
|---|---|---|
| Цвет-текст / цвет-фон | плашка + «Аа 123» этим цветом или на нём; оценка словами «читается хорошо / плохо читается» (значок + слово, правило 2), число контраста мелко; для рамок — норма 3:1, для `glow`, градиента — заливка области | `themes.*` (по ролям: Главная кнопка · Фон и карточки · Текст · Статусы · Модуль — «Главная кнопка» первой), `accents` |
| Статус | плашка `StatusChip` (значок + слово) | `statusIcon`, `timing` (через N дн → warn/bad) |
| Размер шрифта, вес, межстрочный | фраза этим размером/весом («Bathroom remodel · $3,420.00»); межстрочный — абзац | `font.size`, `font.weight`, `font.lineHeight`, `font.tracking` |
| Множитель шрифта | та же фраза при множителе | `font.labelMaxScale`, `font.fitMinScale` |
| Отступ | полоска между двумя плашками | `space`, `spaceHalf`, `rhythm` |
| Размер | рамка этого размера; у кнопки — видимые 40 + зона 44 пунктиром | `size`, `component.*` (на экране детали) |
| Угол | прямоугольник с этим углом | `radius` |
| Слой | стопка карточек | `z` |
| Длительность + кривая | **один проигрыватель вверху экрана**: выбрал строку → «Проиграть» (одна кнопка); рядом с квадратом — настоящая мини-деталь (шторка, тост); «Медленно ×4» — токеном `motion.showcaseSlow` (только витрина, только по кнопке, исключение из потолка §14.4 — запись в §21.0); кривая — графиком | `motion.dur*`, `motion.ease*`, `motion.spring` |
| Масштаб, сдвиг | проигрыватель: нажатие/подъём с этим масштабом | `motion.pressScale`, `liftScale`, `menuScale`, `foldShift`… |
| Удержание, задержка | «нажми и держи» с кольцом | `motion.longPressMs`, `spinnerDelayMs`, `toastUndoMs`, `gesture.dragHoldMs` |
| Порог пальца | площадка «потяни» с линией порога — только телефон (правило 27); на вебе — описание | `gesture.*` |
| Ширина | полоса 390 / 820 / 1280 с отметкой «вы здесь» | `breakpoint`, `layout` |
| Печать | кусок PDF сметы/счёта в pt | `print` |
| Модуль | кусок холста / ленты / рабочего чертежа | `drawing`, `drawingPrint`, `shopSheet`, `themes.*.tape`, `component.select.swatch*` (имя `materialSwatch.*` в CLAUDE.md правиле 2 не существует — руководителю) |
| Аватар | `FigureRow` с подписью «аватар клиента» | `pastels` |
| Значок | на «Значках» | `iconMeta`, значки |

**«Уменьшить движение» включено** — проигрыватель показывает то, что видит человек (DS §14.5: шторка, окно, тост, меню — растворением `durFast`; масштаб, пружина, сдвиг — мгновенно) с подписью «у вас уменьшено движение — так это выглядит у вас» и кнопкой «Показать как без уменьшения».

**Крупный шрифт** — переключатель 1 / 1,5 / 2 только в витрине: контекст масштаба в `src/ui/primitives` (правило 29 — сначала `src/ui` + DS §21.0 + витрина); на ×2 подписи кнопок переносятся, а не режутся (DS §4.3).

**Подписи.** «Имя по-русски»: на каждый лист — для `themes` (≈ 53), `font.size` (10), длительностей `motion`; на подгруппу — для `component` и печати; ≈ 150 ключей i18n своим блоком `ds.tok.*` (общий файл — по сообщению руководителю). Лист без подписи по месту называется по месту из «где видно» («между строками»), а не по значению.

**«Где видно».** Собирается скриптом **при сборке и тесте** (`prestart`/`prebuild`, файл в `.gitignore`, **не коммитится** — иначе общий файл и конфликты у трёх исполнителей, правила 26, 30): путь к файлу → экран по маршруту `src/app/**` → заголовок экрана из i18n; деталь из `features` — к экранам, которые её подключают. Показывается строками со «›», не больше 3 и «и ещё N»; нажатие открывает настоящий экран (объекта — первый объект компании или демо; нечего открыть — серая подпись «откройте любую смету»), «Назад» — в витрину на то же место. Сторож: сборщик отрабатывает; у каждого листа есть место или пометка «не используется»; файл без экрана — красный.

**Связь в обе стороны.** На детали — «Проиграть открытие» и строка «Движение › durBase»; у токена — «Окна и шторки ›».

**Тема.** Поле «Тема ⌄» на первом экране, кнопка в шапке раздела — тот же сохранённый выбор, что Настройки → «Оформление» (шаг 1, #2748): меняется тема всего приложения — так и подписано. Одно место на экран.

## 6. Правила витрины (DS §21.0 — отдельным PR до кода, §2.3)

1. Витрина — только «как есть» (#2750).
2. Любой PR, меняющий вид, тем же PR обновляет витрину и пишет «Проверить в витрине: раздел — что сделать, что увидеть».
3. Тип образца — на подгруппе / по виду значения (§4); у каждого листа — имя, «где видно», ключ, значение. Сторож — на этом уровне.
4. Подписи — простыми словами (#2757); коды DS — серой строкой внизу.
5. Одно слово — одна вещь (#2758): название строки = заголовок экрана; «Ввод» / «Выбор» — по признаку.
6. «Медленно ×4» — `motion.showcaseSlow`, только витрина, только по кнопке; пропуск витрины в сторожах (`scripts/codemod/motionLiterals.cjs`, `SKIP = showcase`) снимается — кроме этого исключения.
7. Группа «Модули» — только при включённом модуле.

## 7. Сценарии приёмки

- **С1.** ДАНО директор в «Настройки → Дизайн-система». КОГДА открывает «Основа → Текст». ТОГДА каждый размер шрифта — фразой этим размером, с ролью по-русски и до трёх строк «где видно» со «›»; ключ — мелко серым.
- **С2.** ДАНО экран «Движение и жесты», «Уменьшить движение» выключено. КОГДА директор выбирает `motion.durBase` и нажимает «Проиграть». ТОГДА квадрат и мини-шторка проходят за 220 мс по кривой токена; «Медленно ×4» повторяет в 4 раза медленнее (`motion.showcaseSlow`).
- **С3.** ДАНО «Уменьшить движение» включено. КОГДА директор нажимает «Проиграть» у шторки. ТОГДА шторка растворяется за `durFast` (как в приложении, DS §14.5), подпись «у вас уменьшено движение — так это выглядит у вас».
- **С4.** ДАНО экран «Цвет и статусы». КОГДА открыт. ТОГДА первым — «Главная кнопка»; у каждого цвета — образец, оценка «читается хорошо / плохо» со значком, число контраста мелко; переключение «Тема ⌄» меняет все образцы.
- **С5.** ДАНО поле «Поиск». КОГДА директор пишет «шторка» (или «смета»). ТОГДА видны токены и детали шторки (или всё, что есть на смете), строками `GroupRow` с серой подписью группы; нажатие открывает экран.
- **С6.** ДАНО поиск «zzzz». КОГДА нет совпадений. ТОГДА `EmptySearch`: «Ничего не нашлось — попробуйте другое слово».
- **С7.** ДАНО новый экспорт в `src/ui/templates`. КОГДА прогоняется `designSystem.test.ts`. ТОГДА красный, пока деталь не внесена ровно в один список (#2808).
- **С8.** ДАНО у токена нет места в коде. КОГДА собирается «где видно». ТОГДА у листа пометка «не используется», он попадает в список волны Ж7.
