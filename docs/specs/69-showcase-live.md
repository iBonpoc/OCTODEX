## 2. Как делают лучшие сегодня (правило 28)

| Что | Как у лучших | Источник |
|---|---|---|
| Устройство | «Основы → Стили → Детали»; токены — по смыслу, а не по коду | Material 3, Polaris, GitLab |
| Цвет | образец + текст на этом фоне + контраст числом; роль словами («фон экрана», «текст на главной кнопке») | GitLab, Polaris |
| Шрифт | «specimen»: фраза каждым размером и весом, рядом — роль («заголовок экрана») | Storybook (Swatchbook, design-token tables) |
| Движение | «площадка»: выбрать длительность и кривую → «Проиграть»; показ замедлен, чтобы видеть форму; при «Уменьшить движение» — без движения | GoCardless, Atlassian, Telerik, JM Family |
| Где применять | «так / не так» картинками рядом | Storybook, Figma guidelines |
| Поиск | строка поиска по всем токенам и деталям | Material 3, Polaris |

**Чем мы лучше (измеримо):** образцы — те же детали приложения (не копия в другой библиотеке, как в Storybook), обе темы и три ширины на одном устройстве; «где видно» — **собирается из кода скриптом**, а не пишется руками (не устаревает: сторож); путь до любого токена — ≤ 2 нажатия (группа → экран) или поиск.

## 4. Живой образец каждой группы токенов

У каждого листа: **образец** · **имя по-русски** («Фон экрана») · **где видно** · ключ токена мелко (для разработчика) · значение.

| Группа | Живой образец | «Где видно» |
|---|---|---|
| Цвет (`themes`, `accents`, `statusIcon`) | плашка цвета + текст «Аа 123» тем цветом, где он — текст, или на нём, где он — фон; контраст числом (4.5:1); статусы — значок + слово | роль словами + 2–3 экрана |
| Текст (`font`) | фраза этим размером и весом («Bathroom remodel · $3,420.00»), роль («заголовок экрана») | экраны, где роль встречается |
| Отступы (`space`, `spaceHalf`, `rhythm`) | полоска длиной в отступ между двумя плашками | где он стоит: «между карточками», «внутри поля» |
| Размеры (`size`, `component`) | рамка детали этого размера (кнопка 40, зона нажатия 44 — пунктиром) | деталь, которой принадлежит |
| Скругления (`radius`) | прямоугольник с этим углом | деталь |
| Слои (`z`) | стопка карточек в порядке слоёв | что поверх чего |
| Движение (`motion`, `timing`, `gesture`) | **«Проиграть»**: квадрат едет/раскрывается этой длительностью и кривой; кнопка «Медленно ×4»; кривая нарисована графиком; при «Уменьшить движение» — подпись «у вас выключено» и без движения | открытие шторки, нажатие, тост… |
| Ширины (`breakpoint`, `layout`) | полоса 390 / 820 / 1280 с отметкой «вы здесь» | раскладка |
| Печать (`print`, `drawingPrint`, `shopSheet`) | кусок PDF сметы/бланка этим размером в pt | документы клиенту |
| Модуль (`drawing`, `tape`, `materialSwatch`) | кусок холста / ленты | только модуль (подпись правила 2) |

**Где хранить подписи.** «Имя по-русски» и «где видно» — в i18n (правило 7) **на уровне подгрупп** (≈ 80 подписей, а не 514), лист — по шаблону («Отступ 12»); «где видно» для каждого листа — **файл, собранный скриптом из кода** (`showcase/tokenUsage.json`: путь → экраны), сторож краснеет, если файл устарел относительно `src` (как `mirror.test.ts`). Так подпись не врёт.

## 6. Правила витрины (дописать в DS §21.0)

1. Витрина — только «как есть» (#2750): живые детали и токены приложения; предложений вида в ней нет.
2. Любой PR, меняющий вид, тем же PR обновляет витрину (сторож) и пишет «Проверить в витрине: раздел — что сделать, что увидеть».
3. У каждой группы токенов — тип живого образца (§4); у каждого листа — имя, «где видно», ключ, значение. Сторож: группа без типа образца — красный.
4. Подписи — простыми словами (#2757); коды DS — серой строкой внизу.
5. Одно слово — одна вещь (#2758): название строки меню = заголовок её экрана.
6. Обе темы — поле «Тема ⌄» и кнопка в шапке раздела (шаг 1).

## 7. Сценарии приёмки

- **С1.** ДАНО директор в «Настройки → Дизайн-система». КОГДА открывает «Основа → Текст». ТОГДА каждый размер шрифта показан фразой этим размером, с ролью по-русски и экранами, где он виден; ключ токена — мелко внизу.
- **С2.** ДАНО экран «Основа → Движение». КОГДА директор нажимает «Проиграть» у `motion.durBase`. ТОГДА квадрат проезжает за 220 мс по кривой токена; «Медленно ×4» повторяет в 4 раза медленнее; при «Уменьшить движение» в системе — подпись «у вас выключено», без движения.
- **С3.** ДАНО экран «Основа → Цвет и темы». КОГДА открыт. ТОГДА у каждого цвета — плашка, текст на ней или этим цветом и контраст числом; у статусов — значок и слово; переключение «Тема ⌄» меняет все образцы.
- **С4.** ДАНО поле поиска витрины. КОГДА директор пишет «шторка». ТОГДА видны токены и детали шторки (высоты, движение открытия, `Sheet`) — нажатие открывает их экран.
- **С5.** ДАНО в коде добавлен новый экспорт в `src/ui/templates`. КОГДА прогоняется `designSystem.test.ts`. ТОГДА сторож красный, пока деталь не внесена ровно в один список витрины (#2808).
- **С6.** ДАНО токен поменял экраны, где используется. КОГДА прогоняется сторож. ТОГДА он красный, пока не пересобран `tokenUsage.json`.
