## 2. Идеи из Estixa — почему это нужно OCTODEX (правило `CLAUDE.md`)

| Идея | Почему это нужно OCTODEX | Чем отличается от Estixa |
|---|---|---|
| Позиция раскрывается на месте, без окна (Estixa §10 п.1) | Основатель: «не надо было открывать прям каждую позицию, она должна просто раскрываться». Смета на 12 позиций — не 12 окон | Открыта одна; в свёрнутой нет полей ввода (у Estixa поля в свёрнутой ловили палец и поднимали клавиатуру) |
| Складывание списка при переносе (§6) | Работа с телефона одной рукой: длинная смета (замер Gutters даёт 20–40 позиций) при переносе требует долгой автопрокрутки; сложенная — под пальцем | Переключатель; без «зажигания» рамки до подъёма; подъём по DS (230 мс, `light`) |
| Один тост на несколько удалений (§4) | Удаление без вопроса (правило 5) делает удаление пачкой частым; второй тост не должен отнимать «Вернуть» у первого | «Вернуть» — только удалённые позиции, 5 с (у Estixa 10 с и снимок) |
| Метка «Нет цены» (§2, подсветка нуля) | Позиция за $0 уходит клиенту как «включено»; владелец должен заметить пропуск до отправки | Метка значком и словом (правило 2), не красная заливка поля |
| Удаление видно (гаснет и схлопывается) (§4) | Глаз находит, что изменилось, перед «Вернуть» | Без покраснения: DS 14.2 — `durFast` + `durBase` |
| Вспышка вернувшейся / перенесённой позиции (§4, §6) | После «Вернуть» и переноса видно, где позиция теперь | Длительность `durSlow`, рамка `ink` (у Estixa 1,3 с и акцент) |
| Каталог без автофокуса и постоянной высоты (§3) | Клавиатура не прыгает до касания; окно не меняет высоту при наборе (DS А3) | Шторка `large`, поиск закреплён (DS А3) |
| Смахивание: влево «Заменить / Удалить», вправо «Скрыть» (§5) | Слова основателя #1100; уже решено DS Б13 | Без полного смахивания; без «подглядывания» первой строки |

Не взято из Estixa: клавиатура (§8 разбора), поля в свёрнутой строке, несколько раскрытых строк, полное смахивание = удалить, жёлтая заливка скрытой строки, цвета видов, шесть кнопок в прокручиваемой панели, автосохранение с запросами к серверу в обход очереди.

## 3. Исправлено в v2 по сверке аудита (13.11.2026)
- «Вернуть» удаления — только удалённые позиции (п.5).
- Зоны нажатия всех кнопок, сегментов, «≡» — 44 (правило 3).
- Компьютер 1280: колонка позиций не шире `formMax` 560, справа `panelW` 360 (спека 2.4).
- Шапка: «Новая смета» до первого сохранения, потом «Смета EST-0012»; «‹ откуда пришли» — имя клиента (#878).
- Вибрация при переносе: `selection` только при переходе через границу раздела (Р5, DS 15.6); `light` — подъём, `medium` — бросок.
- «Сохранить» проверяет ставку при включённом налоге (Р10); пустое количество — «Впишите число, например 12.5».
- «Сохранить в каталог» по Р1: подбор наценки (m0−1, m0, m0+1), отказы «нет себестоимости», «цена ниже себестоимости», «точная наценка не получается»; видна владельцу, офису и продажам (Р9), не мастеру. В настройках прототипа — роль «Продажи».
- Плашка-подсказка над списком убрана.
- Вспышка — `durSlow`; флажок каталога — `component.checkbox`.
- Числа жестов, которых нет в токенах, — в одном месте (`T` в прототипе): порог распознавания «вбок» 1,2, отпускание сдвига на половине кнопки и при скорости 0,5 пикс/мс, резина 0,2, автопрокрутка до 18 пикс/кадр, гистерезис места 6. При переносе в приложение — новые токены `gesture.*` или константы `SortableList`/`SwipeRow`.

## 8. v6 (13.11.2026, решения руководителя по v4–v5)
- **п.16 корзина** — принято (решение основателя): правка DS 8.3 / Б13. Корзина — значок-кнопка, зона 44. Не рядом с «≡» и суммой: между корзиной и «≡» зазор `space[6]` (центры 64 пикс, зоны 44 не касаются); в «Кратко» между суммой и корзиной `space[4]`; в «Подробно» сумма — строкой ниже. **Смахивание влево → «Удалить» остаётся вторым путём** (и «⋯ → Удалить» — третьим, для диктора и мыши).
- **п.19 расход скрытой позиции — ПРАВИЛО** (руководитель 13.11): «расход $X» в свёрнутой строке скрытой позиции видит только тот, у кого есть право видеть себестоимость (`costsVisible`); остальным — «$0.00». В режиме «Показать клиенту» (⋯ шапки) его не видно никому, как и прибыль, себестоимость и блок «Только для вас». В прототипе режим есть: «⋯ → Показать клиенту», выход — кнопкой под заголовком.
