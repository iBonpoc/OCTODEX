# 28. Нижняя панель на всех экранах телефона; «Звонки» с «‹ Ещё»

«Каркас приложения» №8, 07.11.2026. Жалоба основателя (телефон): нижняя панель пропадает на Работах, Задачах, Звонках, Счетах, Каталоге, Команде, Настройках компании, Моих настройках и на карточках; в «Звонках» нет «Назад» и не работает жест назад. Аудит — чат правок основателя; решение руководителя №4 — правило А.

## 1. Причина
- Панель была `tabBar` навигатора вкладок (`app/(tabs)/_layout.tsx`): видна только на экранах из папки `(tabs)`. Всё остальное открывается в корневом стеке (`app/_layout.tsx`) поверх вкладок и закрывает её. Правило выходило «по папке файла», а не по виду экрана: список «Клиенты» с панелью, карточка клиента — без.
- «Звонки» лежали в `(tabs)`: плитка «Ещё» (`router.navigate`) переключала вкладку без истории — назад некуда; у `calls` не было раздела в `nav/hierarchy.ts`, и «‹ Ещё» не рисовался.

## 2. Варианты
| | Плюсы | Минусы |
|---|---|---|
| **А. Панель на телефоне везде, кроме форм и полноэкранных** (выбрано) | как iOS HIG, Jobber, HCP; одна точка правды | список «без панели» нужно вести |
| Б. Только 5 вкладок с панелью, остальное без | ничего не менять | основатель жалуется именно на это |
| В. Свой стек у каждой вкладки | «родная» модель | большая перестройка навигации |

## 3. Решение
- `nav/tabBarRule.ts`: `showsTabBar(route)` и два явных списка — `NO_TAB_BAR` (формы создания и правки, подпись, вход, `/p/`, юр. тексты, удаление аккаунта, импорт) и `WITH_TAB_BAR` (всё остальное). Каждый маршрут `src/app` — ровно в одном списке, иначе падает `test/tabBarRule.test.ts`.
- Панель рисует каркас (`app/_layout.tsx`, над стеком, рядом с `SideNav`); у навигатора вкладок `tabBar={() => null}`. `TabBar` без `BottomTabBarProps`: переход `router.navigate(sectionHref)` — снимает карточки над вкладками и переключает вкладку. 820/1280 — без изменений (панели нет, `SideNav`). При клавиатуре — скрыта, как раньше.
- «Звонки»: `app/(tabs)/calls.tsx` → `app/calls.tsx` (адрес тот же), убраны из `TAB_SCREENS` и `Tabs.Screen`; в `hierarchy.ts` — корень «Ещё» (как Работы, Команда): «‹ Ещё», жест и системное «назад» ведут на «Ещё».
- Отступ «＋» (`ui/surfaces.tsx`, файл «Лидов», одна строка) — по `showsTabBar`, а не по `isTabScreen`: «＋» над панелью на любом экране с панелью.
- Место под панель внизу экрана уже было на каждом экране телефона (`useNavInsets().bottom`); тост «Отменить» и раньше стоял выше места панели — проверено e2e.

- **Сверка с обходом чата правок** (Playwright, 390, директор и мастер, 07.11): список «без панели» совпал; `+not-found` — без панели (по обходу). Спорные решены, как рекомендовано: `estimate/new` — без, `visit/[id]` — с панелью (главный экран мастера; последняя кнопка шага при прокрутке поднимается над панелью — место внизу уже есть), `company` — с, `company/[section]`, `company/schedule` — без. Тост «Отменить» стоит на высоте над местом панели на всех экранах (`overlays.tsx`, не меняется): на экранах без панели он немного выше, чем нужно, — не мешает; чат правок отступ тоста не меняет.
- **Иерархия (аудит руководителя, `docs/ai/LOG.md` п.15–17):** `/estimate/signature` — под «Мои настройки», не смета с id «signature»; `/messages/[key]` — под «Сообщения» (назад и после перезагрузки); «Задачи» и «Помощь» — корни «Ещё» («‹ Ещё» и панель — /tasks больше не тупик); `/settings/delete-account` — под «Мои настройки»; `/legal/[doc]` — под «Помощь».

**Не сделано (отдельно):** «Лиды» остаются вкладкой: это главная роли «Продажи» (`roleHome.sales = leads`), перенос в стек ломает её «Главную». У офиса плитка «Лиды» пока переключает вкладку (без «‹ Ещё»). Решение — вместе с руководителем: либо главная продаж открывает `/leads` из стека, либо «‹ Ещё» на вкладке по происхождению.

## 4. Тесты
- unit `tabBarRule.test.ts`: каждый маршрут отнесён ровно к одному списку; списки — только существующие экраны; экраны жалобы с панелью, формы и подпись без; имена маршрутов и сегменты читаются одинаково.
- e2e **122** (6 видов): панель есть на `/jobs`, `/tasks`, `/calls`, `/invoice`, `/catalog`, `/team`, `/company`, `/settings`, карточке клиента и работы, `/clients`; нет на `/lead/new`, `/estimate/signature`, `/client/edit`; на 820/1280 — нигде; карточка клиента зажигает «Клиенты», Работы — «Ещё»; вкладка с карточки → вкладка, одна панель.
- e2e **123** (6 видов): «Ещё» → «Звонки» → «‹ Ещё» → «Ещё»; системное «назад» со «Звонков» → «Ещё»; на `/tasks` «＋» над панелью и над последней карточкой; тост «Отменить» над панелью; переписка по адресу после перезагрузки — «Назад: Сообщения» → `/messages`.
- unit `hierarchy.test.ts`: по тесту на каждый пункт LOG п.15, п.16, п.17; «Звонки», «Задачи», «Помощь» — корни «Ещё».
- Прежние спеки навигации (07, 14, 19, 20, 28, 56, 57, 59, 61, 75, 90–93, 119) — зелёные.
