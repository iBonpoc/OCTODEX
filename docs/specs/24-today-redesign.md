## A. Главная «Сегодня»

### A1. Что не так (BUILD 238)
1. Повторы: «Подписано $5,180» = «Сметы подписаны 1 · $5,180»; «Получено $1,020» = «Деньги получены $1,020» — две из четырёх строк воронки повторяют плитки.
2. Нет главной цифры: три равные плитки ≈114pt на 390; владелец первым спрашивает «сколько пришло денег».
3. Тесно: подписи «Ждёт оплаты», «Все открытые счета» переносятся; под подпись зарезервированы 2 строки.
4. «0% 0» — процент без слова рядом с числом; шаги считаются отдельно за период, процент бывает > 100%.
5. Воронка — 4 строки меню без формы; в одной колонке штуки и деньги.
6. Нет движения и сравнения с прошлым периодом; «Ждёт оплаты» не говорит о просрочке.

### A2. Варианты
- **A «Главная цифра + столбцы» — выбран (рекомендация).** Большая карточка «Получено» со столбцами по дням/неделям; две плитки (Подписано / Ждёт оплаты); воронка — 3 шага в штуках полосами. + ясная иерархия, нет повторов, всё есть в «Наряде» (revCard + bars + funnel). − выше на ≈80pt, новые функции данных.
- B «Одна сводка рядами» (как мобильный прототип). + минимум работы. − без графика, просьбу не закрывает.
- C «Карусель со спарклайнами». − половина цифр за краем, хуже VoiceOver/e2e, на 1280 не нужна.

### A3. Раскладка (вариант A)
Порядок: Сегодня/Неделя/Месяц → **«Получено»** → **2 плитки** → **Воронка** → «Настройка компании» и остальное без изменений.
- **«Получено»** (Card, `space[4]`, `radius.card`; нажатие → `/figures/received`): подпись + справа «▲ $420 к прошлой неделе» (стрелка и слово, без цвета — рост не статус; если прошлый период 0 — не показывать); сумма `font.size.display` tabular, одна строка; «2 платежа».
  Столбцы `component.chart.h`: Сегодня — последние 7 дней (сегодня справа); Неделя — Пн…Вс; Месяц — по неделям (4–6). Текущий — `acc`, остальные `mut` с `chart.mutedOpacity`; будущие — только дорожка `track`; подпись значения только у текущего; сетки и осей нет. Пусто — дорожки + «Появятся после первой оплаты». a11y: `image` + «Получено по дням: Пн $0, Вт $420 …».
- **Две плитки** по половине ширины, подпись в одну строку: «Подписано» (сумма `font.size.title`, «1 смета») → `/figures/signed`; «Ждёт оплаты» (сумма, «3 счёта»; при просрочке `StatusChip` bad «N просрочено», значок + слово) → `/invoice?f=owed`.
- **Воронка** «Воронка · Неделя»: только штуки — «Новые лиды», «Сметы отправлены», «Сметы подписаны» (метки сохраняются, на них e2e 23). Под строкой — полоса на дорожке `chart.track`, заливка `mut` (не статус), ширина `n / max`. Конверсия строкой «33% от лидов», только если база > 0 и ≤ 100%. Строка денег из воронки убрана.
- **820**: Grid 2 колонки — слева «Получено», справа плитки и воронка. **1280**: 3 колонки — «Получено» | воронка | плитки + «Настройка компании».

### A4. Движение
- Столбцы и полосы растут при первом показе: transform `scaleY/scaleX` от 0, `motion.durChart` (900), `motion.easeOut`, лесенка `motion.chartStagger` (40 мс).
- Смена периода: значения перетекают за `motion.durSlow`, без повторного роста от нуля.
- Карточки появляются один раз за сессию (FadeInDown 8, `durSlow`). Счётчик сумм — не в v1.
- «Уменьшить движение»: `useReducedMotion()` (Reanimated, как TabBar/overlays) → значения сразу.
- График — View + Reanimated (без SVG): надёжнее на вебе; анимировать только transform. Новых зависимостей нет.

### A5. Данные и деньги
`features/metrics.ts`, чистые функции: `receivedBuckets(db, period, now, tz)` (платежи по дням компании), `prevReceivedCents`, `awaitingCount`, `overdueCount`. Суммы — целые центы через `@octo/estimating-engine` (правило 8); дни — пояс компании (`zone.ts`).

### A6. Токены
Добавить app-only в `packages/design-tokens`: `component.chart = { h: 120, barRadius: 8, barMin: 4, track: 8, mutedOpacity: 0.55 }` (значения прототипа «Наряда»; высота 130 → 120 под телефон), `motion.chartStagger: 40`. Записать в `design/naryad-ds/BACKLOG.md` для переноса в CSS.

## B. «План»: пустые дни (решение; код — «Работы» №6 с 6-3)

### B1. Что не так
1. Пустой день весит как полный: в «Ленте» 5 пустых дней ≈ 320pt — пол-экрана «ничего».
2. «Неделя»: пустой день — крупный заголовок + кнопка «Свободен» (читается как статус; «свободен» — про человека, не про день).
3. Нет сводки недели; навигация недели стоит под «Не назначено» и уезжает на середину.
4. Ошибка: «3:00 PM · —» — WeekView ищет клиента через работу, у осмотра её нет. Лента уже берёт `visitWho` (клиент → лид).
5. Обрезки «Sarah Mitch…», «JOB…» — длинный значок статуса справа съедает заголовок.

### B2. Решение
- **Лента:** подряд идущие пустые дни → одна тонкая строка «Вс, 8 – Чт, 12 нояб. · свободно» (`rowCompact` 32, зона 44, caption mut, без Card). Справа у планировщика «＋» (не `acc` — жёлтый один, FAB) → `PlanAddSheet` с первым днём отрезка; у мастера кнопки нет. «Сегодня» не схлопывается никогда («На сегодня ничего нет» + «＋ Выезд»).
- **Неделя:** порядок — «Чей план» → навигация недели → **полоса из 7 дней** (день, число, метка числа выездов как ячейка «Месяца»; warn — если есть «Не назначено»; сегодня — `surf2`; нажатие → «День») → «Не назначено» → дни с делами + схлопнутые пустые отрезки. Справа у дня — «Выездов: N» вместо кнопки «Свободен». «Свободен» остаётся только в «Дне» у человека.
- Ширины: 820 — строки «свободно» и полоса на всю ширину вне Grid; 1280 — как 820 (7 колонок по дням — позже).
- Одна ячейка дня для полосы «Недели», ряда дней «Дня» и «Месяца» — общий компонент.
- Логика `collapseEmpty(groups, today)` → `{kind:"day"} | {kind:"free", from, to}` — модульный тест.
- Тексты: `plan5.freeRun` «{from} – {to} · свободно» / «{from} – {to} · Nothing scheduled» / «{from} – {to} · Nada programado»; `plan5.freeDay`; `plan5.freeToday` «На сегодня ничего нет» / «Nothing today» / «Nada para hoy».
- «—» → `visitWho(db, v).client`, иначе адрес или «Осмотр»; тест, который падал до исправления.
- Обрезки: заголовок в 2 строки на телефоне, номер работы в конец подписи, короткое слово на значке — карточка в `src/ui`, чат «Дизайн системы карточек списков».
