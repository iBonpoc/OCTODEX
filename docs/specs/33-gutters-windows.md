# 33. Gutters: окна свойств, шапка холста, «Привязать» с черновиком, вкладка Gutters (этап 0, прототип)

> **Основатель 16.11 ~01:50 UTC** (передал руководитель №13): недоволен Gutters — «какую-то херню понаделал, необдуманную». Его слова по пунктам:
> (а) окна свойств водостока (двойное нажатие), желоба, угла — «толщину даунспота убери»; выбор формы значками **на виду**, не в свёрнутом блоке; «нормальная красивая вёрстка, что там столько свободного места… все окна настроек нужно организовать»;
> (б) шапка холста — «фотоаппарат не в единой системе дизайна»; «кнопка Готово другого размера, не такая, как остальные»;
> (в) окно «Привязать» — лиды, клиенты **и черновик**; у черновика поле названия, и оно сохраняется;
> (г) вкладка «Gutters» — списки «черновики» и «все замеры, привязанные к клиентам или лидам»; «?» — у заголовка Gutters, а не возле «＋»;
> (д) колена (A, B, офсеты, градусы) — ресёрч ведёт аудит; в прототипе только место.
>
> Класс: К2 (вид), кроме (в) — К1-лёгкий (данные: название черновика; миграции нет, см. 4). **Только спека и прототип; код (Gutters №22) — после «да» основателя.**
> Прототип: `docs/prototypes/gutters-windows/index.html` (`?f=ds|run|corner|canvas|link|draft|tab&t=light|dark`). Снимки: «стало» — `after-*-390-{light,dark}.png`; «было» — `before/*.png` (живой предпросмотр текущего `main`).

## 3. Решения (как в прототипе)
### 3.1. Общий вид окон свойств (водосток, желоб, угол)
- Шторка Б1: ручка, заголовок «Водосток» + подзаголовок «D1 · желоб 1-2» (номер и к чему), «✕» 36 справа.
- Порядок: **выбор формы/профиля/вида — плитками со значком на виду, первым** → **сегменты** (А1) для коротких выборов из 2–4 (размер, этаж, «Вниз», способ угла) → **группа строк** 44 «название · значение ›» для длинных выборов (цвет, длина, материал, монтаж, кронштейны, низ, стена; выбор открывается страницей шторки, DS Б1 «Вложенный шаг») → переключатели строкой → «Удалить …» внизу закреплённой панелью (вторичная, не главная).
- Заголовки групп — подпись `caption` прописными над группой; отступ между группами `space[4]`; внутри группы — разделитель `hairline`, без отступов.
- Выбранная плитка — «Заливка» + `check` (DS «Выделение выбранного», #1306); значки — те же, что у инструментов и знаков на холсте (`dsRect`, `dsRectRibbed`, `dsRound`, `dsRoundRibbed`; `xsK`, `xsHalf`, `xsFascia`, `xsBox`, `xsEuro`; `cornerOut`, `cornerIn`).
- Свёрнутого блока «Ещё» нет. Редкое (переход, сверху, отвод в бочку, сетка выпуска) — последней группой, видно сразу.
- 820/1280: то же содержимое в боковой панели (как сейчас `attr-panel`).

### 3.2. Водосток (`after-ds-390-*`)
Форма (4 плитки) · Размер (сегмент по форме: прямоуг. 2×3 / 3×4 / 4×5, круглый 3″ / 4″) · группа: Цвет, Длина, Материал · Вниз (сегмент Труба / В желоб / Цепь — спека 33-ds-auto §9.3) · **Колена и офсеты** (группа строк со степперами; под ней место под ресёрч) · группа: Низ, Стена (с креплением) · группа редкого. **Толщины нет** (основатель: «толщину даунспота убери»): у водостока толщина берётся из материала по умолчанию компании; в смете/заказе — как сейчас (поле `gauge` в данных остаётся, правило 16; окно его не показывает).

### 3.3. Желоб (`after-run-390-*`)
Профиль (5 плиток) · Размер (сегмент по профилю) · Этаж (сегмент 1–4) · группа: Длина (рулетка, «·рулетка/нарисовано»), Цвет, Материал · толщина (у желоба остаётся — основатель убрал только у водостока) · группа «Крепление»: Монтаж, Кронштейны. **Углы из окна желоба убраны** — они в окне угла (одно место).

### 3.4. Угол (`after-corner-390-*`)
Вид (2 плитки со значками) · Как делаем (сегмент Готовый / Резать / Полоса — перенесено из окна желоба) · таблица реза (кусок, по стене, по лицу, угол реза) · Брызговик (переключатель строкой) · «Разъединить угол» внизу.

### 3.5. Шапка холста (`after-canvas-390-*`, было — `before/before-canvas.png`)
Все элементы шапки — **одной высоты 36 и одной формы** (`IconButton`/кнопка-пилюля на `surf2` с `hairline`): «‹», кнопка-имя («Привязать» / имя лида / адрес), фотоаппарат (`IconButton` со значком `camera`, число фото — меткой на кнопке, как счётчик), «⋯», «Готово». «Готово» — та же высота 36, единственная жёлтая (`acc`, правило 2), справа. Сейчас: фотоаппарат — голый значок без подложки, «Готово» — `size="sm"` ниже соседей.

### 3.6. «Привязать» (`after-link-390-*`, `after-draft-390-*`)
Сегмент из трёх: **Лиды · Клиенты · Черновик**. Лиды и клиенты — как сейчас (поиск, строки, «Новый лид»). **Черновик** — поле «Название черновика» (1–120 символов; пусто → «Без названия») и главная кнопка «Сохранить черновик». Название пишется в `gutter_measurements.label` — колонка, проверка длины и чтение/запись уже есть (`data.ts`), **миграции нет**. Название видно в шапке холста вместо «Привязать» и в списке «Черновики». Привязанный замер название сохраняет (видно мелко под именем клиента/лида). Офлайн — через очередь, как остальные поля замера.

### 3.7. Вкладка Gutters (`after-tab-390-*`)
Заголовок **«Gutters»** и **«?» сразу справа от заголовка** (основатель), «＋ Замер» справа в шапке. Поиск. Две секции: **«Черновики»** (замеры без лида и клиента: название или «Без названия», что нарисовано, дата) и **«Привязанные к клиентам и лидам»** (как сейчас: имя, адрес, что нарисовано, статус значком+словом). Фильтр-чипы убираются (секции заменяют «Черновики»/«Остальные»; статус виден на карточке). Карточки — `ListCard` (правило 12).
**Расхождение с DS:** §12.2 «Подсказка „?“ — справа в шапке, первой». Основатель хочет «?» у заголовка. По DS §2.3 сначала правится DS: «„?“ раздела — сразу после заголовка (как у `SectionTitle`)»; это меняет все списки, поэтому — **вопрос основателю через руководителя:** только Gutters или везде? Рекомендую везде (одно правило), отдельным PR дизайн-системы.

### 3.8. Колена (`after-ds` — пунктирное место)
Пока — группа строк со степперами «Колено A», «Колено B», «Офсет» (как в данных сейчас). Конкретный список (виды, градусы, двойные офсеты) — после ресёрча аудита, отдельным дополнением этой спеки.

## 4. Данные и правило 16
- Название черновика — `gutter_measurements.label` (есть). Миграции нет. Старые версии приложения поле не трогают (`ownFields` копирует `label`) — не затирают.
- Толщина водостока — поле `gauge` остаётся в данных и движке; окно его не показывает; новый водосток берёт толщину по умолчанию материала (как сейчас).
- Способ угла — переносится из окна желоба в окно угла: данные те же (`corners` на желобе), меняется только место в интерфейсе.

## 5. Тесты (для кода)
- Модульные: секции вкладки (черновик = нет лида и клиента; привязанный — иначе); заголовок карточки черновика (`label` или «Без названия»); длина названия 1–120, пробелы по краям обрезаются.
- e2e (номера даст руководитель; правка существующих 148, 145, 146, 173 и поиск старых слов по `e2e/specs` и `e2e/cloud` — правило 19): водосток — форма плитками видна без «Ещё», поля толщины нет; желоб — профиль виден сразу; угол — способ в окне угла; шапка — у «Готово», фотоаппарата и «⋯» одна высота (замер `boundingBox`); «Привязать» → «Черновик» → название → после перезагрузки в списке «Черновики» и в шапке; вкладка — две секции, «?» рядом с заголовком. Все — 6 видов.
- Снимки «было/стало» 390 светлая в PR (CHECKS §10 п.8а).
- Правило 27: жестов и анимаций нового нет (страница шторки — общий `SheetPage`).
