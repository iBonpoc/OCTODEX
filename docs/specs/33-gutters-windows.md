# 33. Gutters: окна свойств, шапка холста, «Привязать» с черновиком, вкладка Gutters (этап 0, прототип)

> **Основатель 16.11 ~01:50 UTC** (передал руководитель №13): недоволен Gutters — «какую-то херню понаделал, необдуманную». Его слова по пунктам:
> (а) окна свойств водостока (двойное нажатие), желоба, угла — «толщину даунспота убери»; выбор формы значками **на виду**, не в свёрнутом блоке; «нормальная красивая вёрстка, что там столько свободного места… все окна настроек нужно организовать»;

> (в) окно «Привязать» — лиды, клиенты **и черновик**; у черновика поле названия, и оно сохраняется;
> (г) вкладка «Gutters» — списки «черновики» и «все замеры, привязанные к клиентам или лидам»; «?» — у заголовка Gutters, а не возле «＋»;

>
> Класс: К2 (вид), кроме (в) — К1-лёгкий (данные: название черновика; миграции нет, см. 4). **Только спека и прототип; код (Gutters №22) — после «да» основателя.**

## 3. Решения (как в прототипе)
### 3.1. Общий вид окон свойств (водосток, желоб, угол)
- Шторка Б1: ручка, заголовок «Водосток» + подзаголовок «D1 · желоб 1-2» (номер и к чему), «✕» 36 справа.
- Порядок: **выбор формы/профиля/вида — плитками со значком на виду, первым** → **сегменты** (А1) для коротких выборов из 2–4 (размер, этаж, «Вниз», способ угла) → **группа строк** 44 «название · значение ›» для длинных выборов (цвет, длина, материал, монтаж, кронштейны, низ, стена; выбор открывается страницей шторки, DS Б1 «Вложенный шаг») → переключатели строкой (`Toggle`, «вкл» — `acc`, А5) → «Фото элемента» строкой → **«Удалить …» последней строкой списка** (красным словом, с тостом «Отменить»), не закреплённой кнопкой на месте главного действия.
- Заголовки групп — подпись `caption` прописными над группой; отступ между группами `space[4]`; внутри группы — разделитель `hairline`, без отступов.
- Выбранная плитка — «Заливка» + `check` (DS «Выделение выбранного», #1306); значки — те же, что у инструментов и знаков на холсте (`dsRect`, `dsRectRibbed`, `dsRound`, `dsRoundRibbed`; `xsK`, `xsHalf`, `xsFascia`, `xsBox`, `xsEuro`; `cornerOut`, `cornerIn`).
- Свёрнутого блока «Ещё» нет. Редкое (переход, сверху, отвод в бочку, сетка выпуска) — группой «Редко», видно сразу. У каждой группы — подпись.
- Счётчики — общий `Stepper` (А6: «−» 36, значение 56, «+» 36; «−» тусклый на нуле).
- 820/1280: то же содержимое в боковой панели (как сейчас `attr-panel`).

### 3.2. Водосток (`after-ds-390-*`)
Форма (4 плитки) · Размер (сегмент по форме: прямоуг. 2×3 / 3×4 / 4×5, круглый 3″ / 4″) · группа: Цвет, Длина, Материал · Вниз (сегмент Труба / В желоб / Цепь — спека 33-ds-auto §9.3) · **Колена**, **Офсеты** (3.8) · группа: Низ, Стена (с креплением) · группа редкого. **Толщины нет** (основатель: «толщину даунспота убери»): у водостока толщина берётся из материала по умолчанию компании; в смете/заказе — как сейчас (поле `gauge` в данных остаётся, правило 16; окно его не показывает).

### 3.3. Желоб (`after-run-390-*`)
Профиль (5 плиток, короткие подписи: K, Полукр., Fascia, Box, Euro) · Размер (сегмент по профилю) · Этаж (сегмент 1–4) · **Длина на виду** — поля фут/дюйм и кнопка «Рулетка» (рулетка `Tape.tsx` как сейчас; самое частое действие замера — не прятать в строку) · группа: Цвет, Материал · толщина (у желоба остаётся — основатель убрал только у водостока) · группа «Крепление»: Монтаж, Кронштейны. **Углы из окна желоба убраны** — они в окне угла (одно место).

### 3.4. Угол (`after-corner-390-*`)
**Всё из DS §19б остаётся** (вид угла — два выбора 36 со значком и словом, «Сменится сторона всей линии», чертёж угла, «Раскрой» карточками по кускам, «замер примерный»). Добавлено: **Как делаем** (сегмент Готовый / Резать / Полоса — перенесено из окна желоба), Брызговик строкой, «Угол по замеру» (A, B, C → угол) — строкой «›» со страницей вместо длинного блока внизу, «Разъединить угол» — последней строкой.

### 3.5. Шапка холста (`after-canvas-390-*`, было — `before/before-canvas.png`)
Панель инструментов и плашка-сводка — **как сейчас** (DS §19а: только значки, выбранный — круг `ink`). Все элементы шапки — **одной высоты 36 и одной формы** (`IconButton`/кнопка-пилюля на `surf2` с `hairline`): «‹», кнопка-имя («Привязать» / имя лида / адрес), фотоаппарат (`IconButton` со значком `camera`, число фото — меткой на кнопке, как счётчик), «⋯», «Готово». «Готово» — та же высота 36, единственная жёлтая (`acc`, правило 2), справа. Сейчас: фотоаппарат — голый значок без подложки, «Готово» — `size="sm"` ниже соседей.

### 3.6. «Привязать» (`after-link-390-*`, `after-draft-390-*`)
Сегмент из трёх: **Лиды · Клиенты · Черновик**. Лиды и клиенты — поиск, строки выбора с `check` у выбранной; кнопка «Привязать к <имя>» выключена, пока строка не выбрана; «Новый лид» — отдельной группой. **Черновик** — поле «Название черновика» (1–120 символов; пусто → «Без названия») и главная кнопка «Сохранить черновик». Название пишется в `gutter_measurements.label` — колонка, проверка длины и чтение/запись уже есть (`data.ts`), **миграции нет**. Название видно в шапке холста вместо «Привязать» и в списке «Черновики». Привязанный замер название сохраняет (видно мелко под именем клиента/лида). Офлайн — через очередь, как остальные поля замера.

### 3.7. Вкладка Gutters (`after-tab-390-*`)
Заголовок **«Gutters»** (решение основателя 16.11; было «Замеры» + подзаголовок «Водостоки (Gutters)»; подзаголовок убирается, вкладка внизу — тоже «Gutters») и **«?» сразу справа от заголовка** (основатель), «＋ Замер» справа в шапке. Поиск. Две секции: **«Черновики»** (замеры без лида и клиента: название или «Без названия», что нарисовано, дата) и **«Привязанные к клиентам и лидам»** (у каждой карточки значок и слово «Лид · имя» / «Клиент · имя», адрес, что нарисовано, статус значком+словом: «⚠ Без сметы», «◷ Смета отправлена», «✓ Подписана»). Строка версии, плашка «Демо» и нижняя панель — как сейчас; пустое состояние — как сейчас («Замеров пока нет» + «＋ Новый замер»). Фильтр-чипы убираются (секции заменяют «Черновики»/«Остальные»; статус виден на карточке). Карточки — `ListCard` (правило 12).
**Расхождение с DS:** §12.2 «Подсказка „?“ — справа в шапке, первой». Основатель хочет «?» у заголовка. По DS §2.3 сначала правится DS: «„?“ раздела — сразу после заголовка (как у `SectionTitle`)»; это меняет все списки, поэтому — **вопрос основателю через руководителя:** только Gutters или везде? Рекомендую везде (одно правило), отдельным PR дизайн-системы.

### 3.8. Колена и офсеты (ресёрч аудита 16.11 — **ждёт сверки основателя**)
- **Формы и размеры трубы:** прямоугольная гладкая и гофрированная 2×3, 3×4, 4×5; круглая гладкая и гофрированная 3″, 4″ (бывает до 6″). Подбор к желобу: 5″ K → 2×3 или 3×4; 6″ K → 3×4; half-round 5″ → круглая 3″; 6″ → круглая 4″.
- **Колена:** A (front) — вперёд/назад от стены; B (side) — влево/вправо. **У круглых A/B нет** — только угол. Градусы: стандарт **75°**; бывают 30, 45, 60, 90 (K&M/Riverside: №0 = 30°, №1 = 45°, №2 = 60°, №3 = 75°, №4 = 90°).
- **Офсеты:** готовые — Englert Zig Zag 2×3 (смещение 1½″ и 3″), GutterAll Double A / Double B / Single (смещение 2–6″; A — от стены, B — вбок). У Amerimax офсет собирают из двух колен с отрезком.
- **Сколько колен:** обычно 2 вверху и 1 внизу — практика, не стандарт (подсказка под списком, не правило расчёта).
- **Толщина трубы:** своя, не как у желоба (обычно .019, у 4×5 — .024). В окне поля нет; значение — из позиции каталога или настроек, по умолчанию .019.
- **Как выглядит выбор** (`after-ds` — группы «Колена» и «Офсеты»; `after-elbow` — страница «Колено»): строка = вид и угол («Колено A · 75°», подпись «вперёд/назад от стены») + счётчик; «＋ Добавить колено». Нажатие на строку — страница шторки «Колено»: вид A/B (плитки; у круглой трубы — нет), угол (сегмент 30/45/60/75/90, по умолчанию 75), сколько; офсет — Нет / Double A / Double B / Single и смещение.
- **Модель данных** (градус у колена, вид офсета A/B со смещением) — **отдельная задача К1** после «да» основателя; сейчас в данных `elbows: {style, qty}[]` (стиль rect A/B, round — по градусу) и `offsets: {lengthIn, qty}[]` — по правилу 16 новое добавляется рядом, старое читается.
- Источники: ресёрч аудита (передал руководитель №13 16.11); [gutterworks.com — A vs B](https://www.gutterworks.com/tips-and-resources/a-vs-b-styles), [gutterall.com — колена](https://gutterall.com/collections/gutter-elbows-downspout-elbows).

## 4. Данные и правило 16
- Название черновика — `gutter_measurements.label` (есть). Миграции нет. Старые версии приложения поле не трогают (`ownFields` копирует `label`) — не затирают.
- Толщина водостока — поле `gauge` остаётся в данных и движке; окно его не показывает; новый водосток берёт толщину по умолчанию материала (как сейчас).
- Способ угла — переносится из окна желоба в окно угла: данные те же (`corners` на желобе), меняется только место в интерфейсе.
