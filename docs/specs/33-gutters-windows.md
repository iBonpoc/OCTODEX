## 3. Решения (как в прототипе)
### 3.1. Общий вид окон свойств (водосток, желоб, угол)
- Шторка Б1: ручка, заголовок «Водосток» + подзаголовок «D1 · желоб 1-2» (номер и к чему), «✕» 36 справа.
- Порядок: **выбор формы/профиля/вида — плитками со значком на виду, первым** → **сегменты** (А1) для коротких выборов из 2–4 (размер, этаж, «Вниз», способ угла) → **группа строк** 44 «название · значение ›» для длинных выборов (цвет, длина, материал, монтаж, кронштейны, низ, стена; выбор открывается страницей шторки, DS Б1 «Вложенный шаг») → переключатели строкой (`Toggle`, «вкл» — `acc`, А5) → «Фото элемента» строкой → **«Удалить …» последней строкой списка** (красным словом, с тостом «Отменить»), не закреплённой кнопкой на месте главного действия.
- Заголовки групп — подпись `caption` прописными над группой; отступ между группами `space[4]`; внутри группы — разделитель `hairline`, без отступов.
- Выбранная плитка — «Заливка» + `check` (DS «Выделение выбранного», #1306); значки — те же, что у инструментов и знаков на холсте (`dsRect`, `dsRectRibbed`, `dsRound`, `dsRoundRibbed`; `xsK`, `xsHalf`, `xsFascia`, `xsBox`, `xsEuro`; `cornerOut`, `cornerIn`).
- Свёрнутого блока «Ещё» нет. Редкое (переход, сверху, отвод в бочку, сетка выпуска) — группой «Редко», видно сразу. У каждой группы — подпись.
- Счётчики — общий `Stepper` (А6: «−» 36, значение 56, «+» 36; «−» тусклый на нуле).
- **«?» у каждого неочевидного поля** (основатель: «знаки вопроса я просил везде расставлять… с пояснениями»): по нажатию — подсказка DS Б7 одной-двумя фразами; тексты — в i18n блоком `mod.gutters.help.*`.
- 820/1280: то же содержимое в боковой панели (как сейчас `attr-panel`).

### 3.2. Водосток (`after-ds-390-*`, `after-ds-copper`, `after-ds-deg`, `after-ds-bottom`) — #1750
**Версия 2 — по замечаниям основателя 16.11 ~02:40** (передал руководитель №13). Сверху вниз:
1. **Форма** (4 плитки, «?»). Значки ребристых — **рёбра внутри** (вид трубы в разрезе), не снаружи — по слову основателя (на фото торца — плавная волна по всем сторонам; показываем основателю): новые `dsRectRibbed`, `dsRoundRibbed` (правка значков — в PR дизайн-системы, они же на холсте и в панели).
2. **Размер** — сегмент по форме: прямоуг. 2×3 / 3×4 / 4×5 / **«Другой…»** (ввод: 4×4, 4×6, 5×5, 5×6, 6×6 — коммерческие и под заказ); круглый 3″ / 4″ / 5″ / 6″ (5″, 6″ серийно у K&M/SAF). Ресёрч аудита №2, 16.11.
3. **Материал** («?») — строка «›» со списком (их 6, А2): алюминий (труба .019 / .024 у 4×5; желоб .027 / .032), медь 16 / 20 oz, оцинковка 26 ga, Galvalume 24 ga, цинк, нержавейка. **Медь, цинк, нержавейка → цвет выключается сам** (медь не красят; поле цвета тускнеет с пояснением, `finish: mill`), как сейчас `MILL_ONLY` в коде.
4. **Цвет — палитра:** кружок-образец + название под ним («Как у желоба» первым, затем цвета компании; по умолчанию — общие у 3+ производителей: White, Black, Dark Bronze, Musket Brown, Royal Brown, Clay, Almond, Light Maple, Savannah Wicker, Pearl/Light Gray; **образцы — примерный цвет**, hex у производителей нет), листается вбок; выбранный — рамка `ink` вокруг кружка + жирное название (DS: правило для выбора цвета — дописать, ближайшее — А15).
5. **Где на желобе** (новое, «?»): сегмент «От левой заглушки / От правой» + число ft / in. Данные: место уже хранится (`atIn` от начала желоба); сторона и отступ — пересчёт в интерфейсе, не новое поле.
6. **Куда уходит вода** («?», вместо «Вниз: Труба / В желоб / Цепь»): три плитки со значками и словами — «По трубе вниз», «По цепи», «В другой желоб». Цепь — на виду (основатель: «в списке нет цепи»). Пояснение по «?»: «Труба — обычный водосток; цепь — вода стекает по цепи вместо трубы; в другой желоб — выпуск без трубы, вода переливается в желоб ниже».
7. **Колена и офсеты** («?»): **всегда четыре строки** — Колено A, Колено B, Офсет A, Офсет B; у каждой справа количество (`Stepper`). У колен — градус кнопкой «75° ⌄» (по нажатию меню 30 / 45 / 60 / **75** / 90; 75 — стандарт; 40/72/85 — только у бесшовных, в меню нет). У офсетов — смещение «2″ ⌄» (1, 1½, 2, 3, 4, 5, 6″). **Без** подписей «вперёд/назад от стены», без «Добавить колено/офсет» и без отдельного экрана колена (основатель: «других не бывает»). У круглой трубы A/B нет (ресёрч) — строки «Колено» и «Офсет» с градусом/смещением (**ждёт сверки основателя**).
8. **Низ трубы** («?»): строка «Низ трубы · Ничего ›» → страница со списком и пояснением к каждому: Ничего (по умолчанию), Удлинитель (жёсткий), Гибкий рукав, Откидной (flip-up), Отбойная плита (splash block), Ввод в дренаж (drain adapter), Pop-up emitter, Бочка, Чугунный boot (коммерческий), На нижнюю крышу (в каталогах нет — в коде остаётся).
9. **Редкие детали** («?»), строка «›» → страница (`after-ds-rare`): переходное колено A→B, Y-тройник, воронка (funnel), редуктор, cleanout, отвод в бочку (diverter), сито в выпуск (strainer), conductor head — у каждой пояснение и число; там же **Стена** (дерево / кирпич-блок / другое) и **число креплений** (правило: 2 хомута на 10 ft трубы). Ресёрч аудита №2: «ставятся по случаю, всё в блок «Редко»». **Фото этого места** («?»: «снимок места водостока — приложится к замеру, видно бригаде»).
10. **Удаление — два действия** последними строками: «Удалить водосток, оставить выпуск» (элемент → `pipe:false`, спека 33-ds-auto §9.3) и «Удалить водосток и выпуск»; оба с тостом «Отменить».
**Убрано из окна:** толщина (берётся из позиции каталога / настроек, по умолчанию .019, у 4×5 — .024). Стена, переход (редуктор), сверху (воронка, conductor head), сито — **на странице «Редкие детали»** с пояснениями (основатель: «непонятно» — теперь каждое с объяснением). Данные этих полей остаются (правило 16), движок считает как раньше; вернуть в окно — только по ресёрчу и с «?».

### 3.3. Желоб (`after-run-390-*`) — #1750
Профиль — 4 плитки, **значки по сечениям** (чертежи Riverside, ресёрч аудита №2): K-style — плоская задняя стенка, плоское дно, передняя S-ступень с валиком сверху; полукруглый — полукруг с закатанным валиком; box — прямоугольный; fascia — высокая плоская передняя грань. **Euro — определения не нашли: вопрос основателю** (убрать или что это). Размер — сегмент: K 5 / 6 / 7 / 8″, полукруглый 5 / 6″ · Этаж (сегмент 1–4) · **Длина на виду**: ft, in и **дробь** («½ ⌄»: 0, ⅛, ¼, ⅜, ½, ⅝, ¾, ⅞ — как `FracPicker`), рядом кнопка **«Шкала»** вместо непонятного «Рулетка» (прокрутить длину пальцем; «?» объясняет) · группа: Цвет, Материал («?»: алюминий .027 / .032, медь 16 / 20 oz, оцинковка 26 ga, Galvalume 24 ga, цинк, нержавейка) · группа «Крепление»: **«Крепится к»** («?»; вместо «Монтаж на фасад» / «Край крыши») → страница (`after-run-mount`): лобовая доска (fascia mount), стропила (rafter tail), под кровлю (roof strap — нет лобовой доски), карниз (crown moulding), наклонная доска (angled fascia, wedge). В коде сейчас ещё «черепица» и «обрешётка» — сверить при коде, Кронштейны · Фото этого места («?») · «Удалить желоб». **Углы из окна желоба убраны** — они в окне угла.

### 3.7. Вкладка Gutters (`after-tab-390-*`) — #1753
Заголовок **«Gutters»** (решение основателя 16.11; было «Замеры» + подзаголовок «Водостоки (Gutters)»; подзаголовок убирается, вкладка внизу — тоже «Gutters») и **«?» сразу справа от заголовка**. **Сверху (v2, основатель):** поиск и рядом **жёлтая кнопка «＋ Новый замер»**, под ними **фильтры-чипы** (Все · Черновики · Без сметы · Смета · Подписана, с числами). Ниже две секции: **«Черновики»** (название или «Без названия», что нарисовано, дата) и **«Привязанные к клиентам и лидам»** (значок и слово «Лид · имя» / «Клиент · имя», адрес, что нарисовано, статус значком+словом). ### 3.8. Колена и офсеты (ресёрч аудита 16.11 — **ждёт сверки основателя**) — #1749

- **Толщина трубы:** своя, не как у желоба (обычно .019, у 4×5 — .024). В окне поля нет; значение — из позиции каталога или настроек, по умолчанию .019.
