Карточка клиента — прототип к #2176

Статичный прототип для утверждения. Токены — packages/design-tokens/src/index.ts, формы — только то, что есть в «Наряде»: Card, ListRow, ViewTabs, Chip, Button, SelectField, ActionRow. Приложение не менялось.

1. Язык клиента виденПоле «Язык клиента · English ⌄» (SelectField, DS А16) под «Контактами клиента»: на 390 и 820 внизу «Обзора», на 1280 — в правой колонке. Один язык на клиента.
2. «Телефон» — не отдельная строкаКнопка «＋ Телефон» / «＋ Email» стоит в одной строке с названием группы, как «＋ Объект» в «Объектах». Строки значений идут подряд, лишней строки нет.
3. Три вида, не растянутый планшетОдни и те же блоки на всех ширинах (ждёт действия, последние сметы и счета — если есть данные). 390 — одна колонка; 820 — две; 1280 — центр и правая колонка 360, в ней теперь данные клиента.

Б. «Контакты клиента» — редактирование

Было: «⊕ Добавить телефон» и «⊕ Добавить email» — отдельные строки во всю ширину. Стало: кнопка в строке названия группы. «⊕ Добавить контакт» остаётся строкой — это действие над целым блоком, не над значением. Язык один на клиента — поле только у основного контакта. Пунктиром на 390 (светлая) показана зона нажатия 44 у «＋ Телефон» / «＋ Email» (кнопка 28 + невидимая зона).
