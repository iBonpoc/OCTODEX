Документ поставщика → «Что сделать»

Прототип спеки 53 §8а.13 (редакция 2 — после независимого дизайн-ревью). Один распознаватель чеков, прайсов и счетов поставщика: снимок системным сканером документов или PDF/документ → распознавание → «Что сделать» (несколько действий за раз) → возврат туда, откуда пришли, с тостом «Вернуть». Данные вымышлены, числа тестовые.

Тема

1. Вход: «＋ Документ»

Кнопки — в закреплённой панели (DS §8.9): «Снять документ» — главная, системный сканер документов (края, выравнивание, несколько страниц).

2. Распознавание

Миниатюра снятого и «Переснять». Без сети — «Документ ждёт сети · 1», распознается сам.

Каталог

Можно уйти — пришлём «Документ распознан — проверьте».

3. «Что сделать»

Действия — строками одной карточки (меню выбора, правило 12). Строки с деталями — «›». Кнопка называет, что запишет; ничего не отмечено — подсказка.

4. После «Записать»

Колонка формы до formMax по центру; кнопка — в конце колонки, не в панели (DS §8.9: от 820 панели нет).
