Ряд 1. Поиск есть на каждом списке, у смет и работ он новый. Справа кнопка «Фильтр». Когда что-то выбрано, на ней рамка и число.
Ряд 2. Одна лента статусов с числами, на новые строки не переносится. Чипа с нулём нет, кроме выбранного. Цвета у чипов нет, жёлтый на экране только «＋».
Шторка. Группы строками: источник, ответственный, мастер, сортировка. Строка с нулём остаётся, но серая. Внизу кнопки «Сбросить» и «Готово».
Память. Статус и фильтры запоминаются на устройстве для каждого списка отдельно. Поиск не запоминается. Ссылка с Главной ставит фильтр только на этот заход.
1280. Всё в один ряд: поиск шириной 360, лента целиком, справа «Источник ▾» и «Ответственный ▾». Меню показывает те же строки, что шторка.
