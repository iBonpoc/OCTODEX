**Шаги у образца.** Удалить 5 черновиков в Housecall Pro на телефоне: на каждый — открыть, «⋯», «Delete», «Confirm», назад = 5 × 5 = **25 нажатий** и 5 подтверждений. В Jobber на телефоне массового нет.

**Наш вариант (измеримо):**
- одна карточка: смахнуть + «Удалить» = **1 жест + 1 нажатие**, без диалога, «Вернуть» 5 с;
- пять: «Выбрать» + 5 отметок + «Удалить (5)» = **7 нажатий**, одно «Вернуть» на все (против 25 у HCP);
- неудаляемое (подписанное) не прячет действие молча: смахивание не едет, в пачке — «1 нельзя: смета подписана».

**Чем лучше «Почты» сознательно:** влево полного смахивания нет (удаление только нажатием — слово основателя; в машине и в перчатках длинное движение срабатывает случайно); полное — только вправо и только обратимое («Готово», «Прочитано»). Отметка в режиме выбора — как в «Фото», без кружков (флажков в «Наряде» нет).

**Что самое современное и почему не взято сейчас:** выбор протягиванием двумя пальцами («Почта», «Заметки») — в React Native нет без своего нативного списка → задача «после-1.0». Контекстное меню долгим нажатием с пунктом «Выбрать» (как «Файлы») — вместе с Б5 после выпуска.

**Чем проверим:** модульный `swipeDecide` (каждая граница таблицы «Числа жеста» ±1), `useListSelection`; e2e на 6 видах через режим выбора и `accessibilityActions`; на iPhone — список ниже.

## Проверка на iPhone (правило 27, строка «Натив:» в PR кода)
1. Медленно влево до половины кнопки и отпустить — закрылась; чуть дальше половины — открылась.
2. Быстрый короткий щелчок влево (меньше половины) — открылась (скорость ≥ 0,5 пикс/мс).
3. Прокрутка вертикально с небольшим уходом вбок — список едет, карточка нет.
4. Начать жест у самого левого края экрана — системный «назад», карточка не едет.
5. Протянуть влево далеко — резина, «Удалить» сам не срабатывает.
6. Задача: протянуть вправо за 0,6 ширины — один щелчок вибрации, кнопка во всю ширину; вернуть палец чуть назад и снова вперёд — снова щелчок, без дребезга; отпустить — «Сделано · Вернуть».
7. Открыть одну, смахнуть другую — первая закрылась; нажать карточку при открытой — только закрылась.
8. «Уменьшить движение» включено — доводка без пружины, карточка за пальцем едет.
9. VoiceOver: на карточке «Действия» — «Удалить»; в режиме выбора — «выбран», «Выбрано: 3».
10. Режим выбора: вкладки сменились панелью, «Удалить (3)», «Вернуть» возвращает все три.
