## Как вести документацию

- **Одно знание — одно место.** Правило — в `CLAUDE.md` или правиле области; решение основателя — в журнале; несделанное и вопросы — только в задачах GitHub (правило 21), не строкой в документе; урок из ошибки — `ai/CHECKS.md` §9.
- **Шапка документа** — в первых строках: что это, `Статус:` (действует / черновик / заменён на …), дата последней сверки. Старые документы получают шапку при первой правке.
- **Новый документ** — сразу строка в `README.md` своей папки и шапка со `Статус:`. Следит сторож `apps/mobile/test/docsLibrary.test.ts`: документ без строки в оглавлении или без шапки — красный. Старые документы без шапки перечислены в `apps/mobile/test/docsHeaderLeft.json`; список только сокращается.
- **Устаревший документ не удаляется**: шапка «заменён на …», затем переезд в `archive/`. Файл уходит в архив, только когда у каждого его куска есть записанное место назначения (замысел §16.5). Удаление из архива — только по слову основателя (вопрос #2680).
- **Перенос** — небольшими PR, в каждом строка «откуда → куда»; ссылки на перемещённый файл правятся в том же PR.
