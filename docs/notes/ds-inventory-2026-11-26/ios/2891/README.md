# PR #2891 — защита ухода из редактора, проверка жеста на iPhone (правило 27)

main `4aa366cc5` (после влития #2891). Симулятор iPhone 17, iOS 27.2, RU, демо.

- Новый лид без правок, свайп «назад» от края — экран уходит сразу.
- Новый лид с именем: свайп от края → «Выйти без сохранения?» (`2891-01`); «Отмена» — форма и имя на месте; свайп с середины экрана → то же окно (`2891-02`); «Выйти» — форма закрыта.
- Новый клиент с именем: свайп от края → то же окно (`2891-03`); «Выйти» — к списку клиентов, клиент не создан.
- «Данные клиента» (правка клиента из меню «···» → «Изменить»): без правок свайп уводит сразу; с правкой в поле «Компания» — то же окно (`2891-04`); «Выйти» — к карточке, клиент не изменён.
- Замечание: при открытой клавиатуре первый свайп три раза из четырёх только убрал клавиатуру, окно появилось со второго свайпа. Форма и набранное при этом на месте, правки не теряются.
- Шаг 5 (сохранение лида без окна) в симуляторе не делал, чтобы не добавлять запись в демо-данные стенда; он покрыт спекой 552.
