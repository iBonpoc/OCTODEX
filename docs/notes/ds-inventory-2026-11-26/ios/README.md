## Что видно на снимках
- Ширина 402 pt, а не 390: iPhone с шириной 390 pt в этой версии Xcode нет.
- 04: первая строка списка клиентов «Еуые ТщФввкуыы» — мусор прошлых проверок на этом симуляторе, не демо-данные.
- 06: панель «Итого» лежит поверх строк позиций.
- 15–17 (AX5): заголовки и имена обрезаны до 3–6 букв, инициалы в аватаре срезаны, у значка на вкладке «Лиды» не видно числа, подписи вкладок «Клиен…».
- При открытом меню «···» переход на другой экран по ссылке меню не закрывает: оно остаётся поверх нового экрана.
