Руководитель не принимает решения по виду/порядку экранов («Решил сам» по дизайну) и не дорабатывает чужие макеты. Брейншторм, ресёрч и решения по вёрстке делает чат-исполнитель вместе с design-reviewer/crm-reviewer; руководитель только собирает страницу и присылает основателю ссылку, когда всё готово.
**Why:** 23.11 основатель отклонил шторку Gutters v2 и решения №24: «Почему ты занимаешься, руководитель? Ты мне только ссылку присылаешь, когда всё готово… Всё остальное делают подчинённые».
**How to apply:** перед страницей проверить, что исполнитель сверил КАЖДОЕ слово основателя из журнала (в v2 пропали Колено A/B и Offset A/B). «Мелкие решения — сами» — это про исполнителя, не про руководителя. См. [[feedback-one-answer-place]].
