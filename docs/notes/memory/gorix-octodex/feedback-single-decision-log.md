Основатель отвечает и руководителю, и дизайн-исполнителю напрямую. Каждый, кто получил ответ, сразу дописывает его в общий журнал `~/GoRix/notes/review-v2/founder-answers-1.md`. Перед вопросом основателю — сверка с журналом; есть ответ — не спрашивать. Исполнители вопросы основателю не задают сами: пишут в журнал «Открытые вопросы», руководитель показывает.

**Why:** 21.11.2026 основатель: «я много вопросов отвечаю тебе дважды… веди с чатом Design V2 один документ».
**How to apply:** в каждом брифе дизайн-исполнителю; перед каждым вопросом основателю. См. [[feedback-one-answer-place]], [[feedback-questions-notify]].
