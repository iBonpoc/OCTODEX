Когда появляются вопросы к основателю (в т.ч. из проверок, вариантов дизайна), руководитель: (1) ставит их наверх https://claude.ai/artifact/BEjk4w1i3oPm2Hi5CGN1G5 со следующими номерами, коротко, с вариантами А/Б и своим советом; (2) первой строкой сообщения пишет «Есть N вопросов к вам: номера …» со ссылкой.

**Why:** 21.11.2026 вопросы круга 1 лежали только внутри страницы «Проверка вида»; основатель: «почему ты мне не прислал документ и уведомление, что есть вопросы?»
**How to apply:** каждый раз, когда исполнитель вернул вопрос/варианты. См. [[project-leader22-maestro]].
