Основатель живёт в Лос-Анджелесе. В сообщениях ему время писать по LA (PT, сейчас UTC−8) или «через N минут/часов». UTC основателю не писать.
**Why:** 23.11 основатель: «я работаю не по UTC… отвечай мне по времени Лос-Анджелеса, или через сколько это будет, а не во сколько по чужому времени».
**How to apply:** перед ответом пересчитать UTC→PT (`TZ=America/Los_Angeles date`); в журналах и задачах можно UTC. Передать правило руководителю №25 и исполнителям, которые пишут основателю.
