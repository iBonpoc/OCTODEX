Одно место для ответов — https://claude.ai/artifact/BEjk4w1i3oPm2Hi5CGN1G5. Страницы с картинками (проверка вида и т.п.) — без кнопок ответа, со ссылкой на страницу вопросов. Порядок: открытые сверху, новые первыми; отвеченный вопрос сразу переносится вниз в «Получено» (новые первыми) с «Как я понял». Исполнители своих страниц для основателя не публикуют — файлы в `~/GoRix/notes/`, страницы собирает руководитель.

**Why:** 21.11.2026 основатель запутался: ответы пересекались между «Вопросы основателю», «Проверка вида» и страницей дизайн-исполнителя; «отвеченные должны уходить вниз, иерархия, сортировка по времени».
**How to apply:** каждое обновление страницы вопросов; в брифах исполнителям — «страницы не публиковать». См. [[feedback-questions-notify]].
