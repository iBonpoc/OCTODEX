Один агент-«фотограф» снимает набор (все экраны × 2 темы × состояния, кадры анимации шапки) в `~/GoRix/notes/screens/<короткий-хэш-коммита>/` + `index.json` (экран, тема, состояние, ширина, коммит, кто снял) + `notes.md` (общие находки). Разборщики (вёрстка против макета, цвет/контраст, тексты/обрезки, доступность) работают параллельно по этим снимкам, сервер не запускают и не переснимают, находки — в `notes.md`. Перед съёмкой — проверить, есть ли набор для текущего коммита; код новее — новый набор. Цель — визуальный сторож `e2e/visual/visual.cjs` сам сохраняет такой набор при прогоне (задача).

**Why:** основатель 21.11 спросил «нельзя ли, чтобы снимки одного агента смотрели другие, а не переснимали?» — экономит время запуска сервера/съёмки и токены; согласен по смыслу.
Фотограф — сервис `npm run shot` (не LLM), штамп «ветка · хэш · время · тема · ширина» под снимком (#2360).
**How to apply:** в каждом брифе агенту, которому нужны снимки, — сначала папка набора; правило внести в `docs/ai/WORKER.md` (зона руководителя) отдельным docs-PR. См. [[project-leader22-maestro]].
