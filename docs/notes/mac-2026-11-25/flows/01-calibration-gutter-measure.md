# Сценарий 01. «Замер gutter» с карточки клиента (калибровка)

Цель: увидеть, есть ли пустой экран / мелькание / второй рывок при переходе «карточка клиента → холст замера» и обратно.
Подготовка один раз: стенд поднят по ~/GoRix/STAND.md; в приложении модуль Gutters включён (Ещё → Настройки компании → Модули → «Водостоки (Gutters)» → «Подключить»). Клиент «только с городом» CLT-0008 уже есть в демо-данных симулятора; если симулятор стёрт — создать: Клиенты → «＋ Клиент», имя любое, телефон любой, улица пусто, город любой.

Координаты — в пунктах симулятора iPhone 17 (402×874).

## Шаги

1. Запустить запись:
   `cd ~/GoRix/shots && xcrun simctl io booted recordVideo --codec h264 --force NAME.mp4 & echo $! > ~/GoRix/tools/rec.pid`
2. Нижняя вкладка «Клиенты» (271, 813).
3. Открыть David Kim (нажать на имя в списке).
4. Нажать «Замер gutter» (кнопка под жёлтой «Создать смету», ~ (93, 507) при непрокрученной карточке).
5. Подождать 2 с. Нажать стрелку «назад» в левом верхнем углу холста (30, 87).
6. Вкладка «Клиенты» → открыть клиента без улицы (CLT-0008).
7. «Замер gutter». Подождать 2 с. «Назад».
8. Остановить запись: `kill -INT $(cat ~/GoRix/tools/rec.pid)`

## Разбор видео

- Кадры раз в секунду, найти переходы:
  `swift ~/GoRix/tools/frames.swift NAME.mp4 out1s 1 0 999 300` — переход виден по скачку размера файлов кадров.
- Кадры через 0,05 с вокруг перехода:
  `swift ~/GoRix/tools/frames.swift NAME.mp4 fine 0.05 <начало> <конец> 300`
- Смотреть: есть ли кадры с пустым экраном «Замер gutter / имя клиента» без содержимого и второй въезд холста.

## Ожидаемое после правки #2278

- Клиент с одним адресом → сразу холст, один плавный переход, «назад» на карточку клиента.
- Клиент с двумя адресами (Sarah Mitchell) → шторка выбора адреса, один плавный переход.
- Клиент без адреса → строка «У клиента нет адреса…».
