# Ответы основателя из локальных чатов Mac

- Что это: таблицы ответов основателя GoRix на вопросы ассистентов и их сверка с журналом решений `docs/notes/review-v2/founder-answers-1.md`.
- Откуда: ленты локальных чатов на Mac за 20–25.11.2026 (255 записей, 18 чатов). Облачные чаты сюда не попали.
- `chat-<id>.md` — по файлу на чат: номер записи в выгрузке, дата (UTC), тема, вопрос коротко, ответ дословно, есть ли в журнале.
- `MISSING.md` — только ответы, которых в журнале нет или они там частично, по темам, с файлом-источником.
- Ответы надиктованы голосом и приведены как есть; «[…]» — сокращение или вырезанное личное, квадратные скобки — пояснения составителя.
- В таблицы не вошли «продолжай», «ок» без предмета, технические реплики и задания от чатов-руководителей.
- «Нет в журнале» не значит «нигде не записано»: часть решений есть в `CLAUDE.md` и памятках руководителей.
