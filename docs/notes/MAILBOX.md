# Почта руководителя проекта

Этот файл — только повод для PR-черновика «0002 — Почта руководителя». PR никогда не вливается.

**Зачем.** Чаты проекта не всегда могут написать руководителю сообщением: сервер отклоняет отправку (`elevated_session_untrusted_device`). Комментарий в задаче руководителя не будит. Комментарий в этом PR будит руководителя сразу: он подписан на события PR.

**Как писать.** Комментарий в PR-черновике «0002 — Почта руководителя». Первая строка: «Руководителю проекта ← кто · время UTC · тема». Сначала вывод, потом номера PR и задач. Вопрос — отдельной строкой со словом **ВОПРОС**.
