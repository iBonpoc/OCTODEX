# Замечания владельца по вёрстке (20.11.2026) — для «Чата аудита №2»

Владелец раздражён вёрсткой. Просит главный чат ответить: кто этим занимается, кто может редактировать вёрстку, будет ли это в плане (этап). И просит провести брейншторм, исследование и аудит вёрстки и всё сделать.

1. **Экран объекта**: внизу огромное количество кнопок-разделов: Люди, Объекты, Лиды, Работы, Сметы, Счета, Выезды, Задачи, Заметки, Файлы, История. Нужно оптимизировать.
2. **Карточка клиента**: объекты вынесены отдельно. Почему они разделены? Почему всё занимает так много места?
3. **Шапка (хедер)** не нравится: одна и та же информация повторяется на экране несколько раз. Пример со снимков стенда: «GoRix v1.0.0 · dev» + плашка «Демо» + хлебные крошки «Клиенты > Клиент» + большой заголовок с именем; на холсте замера адрес ещё и в шапке.
4. **Принцип владельца**: строки не должны быть полупустыми. Если в одну строку помещаются и дата, и время, ставить в одну строку, а не на разные.
5. **Вопросы**: кто занимается вёрсткой, кто может её редактировать (владелец говорит, что уже говорил об этом), будет ли это в плане.

Ответ для владельца — через испытателя на Mac или напрямую владельцу.
Снимки экранов с симулятора (объект, клиент, шапка) испытатель может снять серией по запросу.
