# Совет: дизайнер дизайн-систем — витрина GoRix (23.11.2026)

Опора: inventory.md, research.md, снимки menu/proto/graphite (390 dark), DESIGN-SYSTEM.md (оглавление). Код не правил.

Главное: сейчас в меню смешаны четыре слоя (основа, компоненты, шаблоны, прототип-кладовка) и один умерший пилот. Чинится не косметикой, а тремя вещами: группы по назначению, один экран = одно понятие, пилот и скрытое — в конец с меткой.

## 1. Новое дерево меню

Глубина 3: Витрина → Группа → Страница. На главной 5 строк-групп с числом страниц внутри (правило: в группе ≤ 10–12 строк). Одна строка поиска вверху (по названию и по «что делает»). Подписи — одна короткая фраза; «§N» убрать из подписи в меню и перенести на страницу.

## 3. Шаблон страницы раздела (телефон)

1. Заголовок + одна строка «зачем» + метка статуса (только «Бета», «Черновик», «Архив», «Не используется»; «Стабильно» не показывать).
2. Живой образец в рамке до первой прокрутки. Над ним ничего, кроме строки описания.
3. Один переключатель над образцом: Вид (Главная / Вторичная / …) и Состояние (Обычное / Нажато / Выключено / Загрузка / Ошибка) — вместо стопки копий. Рядом переключатель 390/820/1280 для страницы, тема — из настроек.
4. «Когда да / когда нет»: 2–3 пары (свёрнуто).
5. «Где используется»: 3–5 ссылок на реальные экраны (свёрнуто) — наше преимущество над Carbon/M3.
6. «Размеры и доступность»: зона 44, контраст, значок+слово (свёрнуто).
7. «Правило и токены»: ссылка «DESIGN-SYSTEM.md §N» + ключи токенов (свёрнуто). Блоки 4–7 свёрнуты, чтобы первый экран был образцом.
8. Длинные страницы (Выбор, Списки, Сообщения) — якорная полоса-чипы наверху (как липкая у Графита, но без вариантов).

## 4. Порядок дальше: правило для сторожа registry

Сторож `designSystem.test.ts` уже знает `UI_PENDING`, `UI_NOT_SHOWN`; добавить:
1. Каждая запись реестра имеет `group` (основа / компоненты / шаблоны / модули / пилоты), `status` (стабильно / бета / черновик / архив / не используется), `ds` (§N). Нет поля — красный.

5. Группа ≤ 12 строк, глубина 3; пилотная группа и `status: архив` всегда последние.
6. Скрытых экранов (`hidden: true`) нет — всё достижимо из меню без тумблера (кроме «Для разработчиков», которое достижимо из Основы).
