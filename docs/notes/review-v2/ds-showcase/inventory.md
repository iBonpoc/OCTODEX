## 1б. «Графит» внутри (`graphite/**`, 19 файлов в main)

Два входа в коде. Живой — `GraphiteSheet` (лист #2292, роут `[section]` для id=graphite); старый — `GraphiteSection` + `GraphiteScreen` (пилот #2254: полноэкранное окно «Прожектор», шторка ½, тост «Вернуть», стекло, свой переключатель темы) — теперь внутри листа как раздел «Пилот-экран целиком» с кнопкой «Открыть „Графит“».

Лист: заголовок экрана «Графит (пилот)», подпись «Правило … §25 · Только витрина: остальное приложение не меняется», вступление: «Один лист: листайте вниз и нажимайте всё подряд. В каждом блоке сразу видно „Как сейчас“… и „Вариант 1“, „Вариант 2“ (как может стать). Нажатие ничего не меняет в приложении: просто назовите номер варианта.» Шрифт Jost, фон «Рельеф» (две картинки), колонка ≤ 560 по центру на 820/1280. Сверху липкая полоса-прыжки (чипы): Основа · Кнопки · Вибрация · Пилот-экран целиком · Готовятся · Для разработчиков.

Разделы листа по порядку:
1. **Основа** (6 блоков, «Как сейчас» + варианты): Тема (переключатель светлая/тёмная — 1 вариант), Цвет: статус (значок+слово; серого «Черновик» в Графите нет, пометка), Цвет: главное действие (1 вариант), Фон и карточка (1 вариант), Отступы (плотно/средне/свободно), Углы (угол 1/2/3).
2. **Кнопки** (8 блоков): Главная, Вторичная, Текстовая (1 вариант), Опасная, Со значком, Круглая, Панель действий внизу, «Создать» (＋). У каждой — переключатели «Загрузка», «Выключено»; счётчик «Нажато: N».
3. **Вибрация** — тот же `HapticsSection`, что на экране «Вибрация» (дубль).
4. **Пилот-экран целиком** — карточка с текстом пилота и кнопкой «Открыть „Графит“» (полноэкранное окно).
5. **Готовятся** — список без ссылок: Поля ввода, Выбор из списка, Переключатели/чипы/сегменты, Шторки и окна, Уведомления и тосты, Нижнее меню и шапка, Списки и карточки, «Остальное: значки, статусы, загрузка, шаблоны экранов». Все 8 так и не сделаны с 20.11.
6. **Для разработчиков** — свёрнутый блок: служебные токены (три скрытых экрана Основа/Отступы/Движение).

Блоки листа (`Block.tsx`) = «Как сейчас» + «Вариант N» + пометка «Сейчас в приложении». Свёрнутые таблицы токенов — только п. 6.

## 4. Главные проблемы текущего меню (коротко)

1. **Порядок не по смыслу.** Основа/Движение/Отступы убраны из списка; остальное идёт «как накопилось»: Кнопки → Селекторы → Окна → Уведомления → Выбор → Поля → Строки сметы → Вибрация → Бренд → Значки → Прототип. Нет логики «основа → мелкие детали → составные части → экраны».
2. **Смешаны четыре слоя.** Основы (токены, значки, бренд, вибрация) — компоненты (кнопки, поля) — шаблоны экранов и прототипы («Прототип v2» из 4 разных тем: объект, списки, визуальный язык, 5 шаблонов) — «Строки сметы» (кусок конкретного экрана).
3. **Три экрана про выбор/ввод, один §9.** «Селекторы», «Выбор», «Поля ввода»: границы между ними не видны человеку (чипы, строки с галочкой, плитки и меню лежат в разных местах), подписи в списке почти одинаковые.
4. **«Прототип v2» — кладовка.** Один экран с четырьмя вложенными разделами, под «Объект» ещё прячется «Шаблоны экранов»; нет оглавления, нет якорей, экран самый длинный. Название «прототип» устарело (v2 утверждён).
5. **Названия неоднородные:** «Окна: шторки» (двоеточие), «Бренд GoRix» (с названием продукта), «Строки и списки сметы» (про одну экранную часть), «Выбор» (без пояснения), «Прототип v2». Подписи мелким шрифтом перегружены цифрами «§».
6. **Дубли:** три набора кнопок (Наряд, Графит, v2), Вибрация два раза, NowCard/StatTile/ListGroup в двух разделах, Segmented и ViewTabs в разных местах.
7. **Пробелы:** нет «Меню ⋯», «Статусов и меток», «Списка/карточки/ListCard», «Аватара», «Stepper», «Каркаса экрана»; зато показаны вещи, которыми приложение не пользуется (ConfirmDialog, OptionTiles, ColorField, FracKeys, Meter).
8. **Заглушки «⬜» и старые метки** в «Строки и списки сметы» и «Кнопки»: человек думает, что сделано не всё.
9. **Скрытая Основа.** Токены и цвета теперь доступны только адресом или через «Графит → Для разработчиков»: при выключенном тумблере из UI до них дойти нельзя.
10. **Графит как постоянная строка и тумблер на первом экране** при том, что v2 утвердили основной: пилот подаётся как будущее приложения, хотя работа по нему стоит.
11. **Длина:** самые длинные экраны — «Прототип v2» (≈ 40+ образцов подряд), «Уведомления» (12 карточек), «Окна» (около 12 кнопок-шторок), лист Графит (≈ 20 блоков по три образца). Нет якорей, поиска, сворачивания; на 390 это десятки экранов прокрутки.
