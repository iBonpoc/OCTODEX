# Блоки внизу экранов витрины и листа «Графит»

Для кого они: почти все — для разработчиков и дизайнера, чтобы сверять значения в коде с дизайн-системой; основателю выбирать по ним не нужно.

- «Для разработчиков» (Графит) — свёрнутый раздел с техническими цифрами; нужен разработчику, закрыт по умолчанию, чтобы не мешать выбору вида.
- «Показать служебные значения» (Графит) — кнопка, раскрывающая этот раздел: названия цветов, числа отступов, радиусов и движения.
- «Готовятся» (Графит) — список разделов (поля, выбор, переключатели, шторки, уведомления), которые добавят на лист следующими выпусками; показывает, чего ещё нет для сравнения.
- «Вибрация» — раздел с кнопками, по которым можно почувствовать виброотклик на телефоне.
- themes — все цвета тёмной и светлой темы по названиям (фон, текст, карточка, акцент, тени); справочник для разработчика.
- statusIcon — какой значок стоит у каждого статуса (ок, инфо, внимание, ошибка, серый), чтобы цвет всегда шёл со значком.
- drawing — цвета чертежа Gutters: узлы и этажи; нужны только модулю рисования.
- font — шрифт Manrope: семейства, размеры, межстрочные, насыщенность; для сверки текста.
- print — размеры и значения для печатных документов (смета, счёт, PDF).
- drawingPrint — то же для печати чертежа Gutters.
- shopSheet — значения листа заказа материалов поставщику.
- space (и spaceHalf) — шкала отступов 4–32 и тонкие полуотступы.
- radius — шкала скруглений углов (поле, чип, карточка, шторка).
- size — размеры кнопок, полей, значков, панели вкладок, минимальной зоны нажатия.
- breakpoint — ширины телефона, планшета и десктопа, при которых меняется раскладка.
- layout — максимальная ширина содержимого и число колонок сетки.
- z — порядок слоёв: что рисуется поверх чего (меню, шторка, тост).
- component — готовые размеры конкретных деталей (кнопка, поле, чип, переключатель, вкладка).
- motion — скорости и кривые анимаций; для разработчика (ещё есть отдельный экран «Анимации»).
- timing — длительности в миллисекундах (тост, подсказки, переходы).
- rhythm — расстояния между блоками и заголовками на экране; задаёт «воздух» страницы.
