# Карта «имя → новое место» для витрины «Дизайн-система» (23.11.2026)
Основа: `proposal.md` §2 (новое дерево), `recheck-1.md` (потерянные имена, блокирующие 1–4, 16), `inventory.md`, `registry.ts` на `fix/2426-line-expand-grid`. Код не правился.
Правило карты: у каждого имени ровно одно основное место. Токены: основное место — живой образец; таблица hex/чисел той же группы — зеркало в «Для разработчиков → Таблицы токенов» (не второе место, сторожу достаточно имени в реестре). Файлов использования — вне `src/ui` и витрины, свой подсчёт по `<Имя` / импорту (где опись дала число — взято из описи: Button 99, Card 61, RowView 62, Screen 63, Empty 58 и т.д.); «0 напрямую, внутри ui» — приложение зовёт только через другой компонент.
Метки: нет / Устарело / Не используется в приложении / Только на iPhone. Метка ставится рядом с образцом внутри логичного раздела; в «Устаревшее» уходит только ListCard (recheck п.10).
