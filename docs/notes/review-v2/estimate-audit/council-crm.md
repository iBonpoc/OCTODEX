# Совет по смете — записка специалиста CRM/FSM (23.11.2026)

Роль: нужна ли каждая кнопка, следующий шаг, workflow, сравнение с Jobber/HCP/ST/Joist. Читал: council-brief, inventory, scenarios, research, shots/index (снимки глазами не смотрел, опирался на инвентарь с файл:строка). Чужих записок не читал.

Формат: `id · голос · что: где, слова RU / EN / ES · довод`.

Сквозные принципы, по которым голосую
1. Один статус — одна главная кнопка; всё, что у конкурентов лежит в «⋯», у нас тоже в «⋯».
2. Не показывать действие, которого у роли нет (скрыть, а не писать «нет права»).
3. Нет тупиков: у каждого статуса есть «вперёд» и «убрать с глаз» (архив/дубль).
4. «Отправлено клиенту» — всегда одним путём, всегда с 5-секундным «Не отправлять».
5. Деньги и подпись клиента не должны меняться молча.
