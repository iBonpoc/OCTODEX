## Решения основателя — НЕ пересматривать (можно только предложить слова/место, если прямо противоречит здравому смыслу — тогда отдельной строкой «спорю с решением: …» с доводом)
1. Автосохранение: правки сразу хранятся на телефоне, закрытое приложение ничего не теряет. Внизу редактора — «Отменить» (видно только когда есть правки, с подтверждением; откатывает всё с момента открытия) и «Готово» (принять). Вопрос основателя открыт: «почему не „Сохранить“ вместо „Готово“?» — ответьте.
2. «Отправить» — круг ➤ вверху редактора; внизу редактора отправки нет. Внутреннего согласования не делаем.
3. Итог — капсула «Итого» при прокрутке, в конце прокрутки полная карточка «Итого».
4. Позиция раскрывается на месте (не шторка); при раскрытии ничего не дёргается — слова на местах, карточка «раздвигается»; надписи «Свернуть» сверху не нужно.
5. Корзина и ручка ⠿ у свёрнутой позиции — всегда. Перенос — удержание ~0,5 с.
6. Над списком позиций — отдельные кнопки «＋ Позиция», «Каталог», «Шаблон», без селектора «˅». Разделы — частое действие («кровля → материал, работа»), на виду; раздел внутри раздела бывает. Раздел — «папка».
7. Налог, скидка, депозит — у каждого маленький тройной переключатель (влево %, центр выкл., вправо $), по умолчанию выключены; сумма вводится тут же, без отдельного окна. (Налог суммой — изменение движка, К1.)
8. Notes и Terms пишет сам, у каждого кнопка «Шаблон» → список сохранённых; нужна страница шаблонов (сметы, notes, terms, договоры).
9. Смену клиента — только у черновика (не отправленного).
10. Смету создают в лиде или клиенте (не из выезда).
11. После отправки смету «просто можно исправить и отправить». Конец пути: в работу / архив / удалить / отозвать — да.
12. Непонятные основателю слова прошлых кругов: «долгое нажатие» (куда нажать?), «Как видит клиент», «В шаблоны» (может «Сделать шаблоном»), «Закрыть ссылку» (может «Отозвать ссылку»), «Варианты на выбор», «Экран для клиента», «Строки подробно», «Разложить по видам», «Несохранённые правки» (нужен «?»). «?» с пояснением — почти везде, где слово может быть неясно.

## Вопросы для голосования (по каждому — ваш голос)
Формат ответа на каждый: `id · голос (оставить / убрать / изменить / добавить) · что именно: где лежит (на экране / «⋯» / смахивание / долгое нажатие) и точные слова RU / EN / ES · довод одной строкой (сценарий №, источник или правило)`. Не знаете — «воздерживаюсь».

**Список смет (вкладка «Сметы» и группа у клиента/лида)**
- L1 что в строке (клиент, название, сумма, статус, дата / «открыл»)
- L2 смахивание влево — какое действие по статусу (D/S/AC/A/X)
- L3 долгое нажатие — меню (то же, что «⋯» карточки?) и как человек узнаёт, что оно есть
- L4 фильтры по статусу; где архив
- L5 удаление: тост «Отменить» 5 с или «Недавно удалённые» 30 дней (сервер корзину уже умеет)

**Карточка сметы (просмотр)**
- C1 главная кнопка по каждому статусу D/S(не открыта)/S(открыта)/S(истекла)/AC/A/A(есть счёт/оплата)/X
- C2 ряд значков SMS / Почта / Ссылка под шапкой (шлют сразу) — дубль главной? оставить/убрать
- C3 состав «⋯» по каждому статусу, порядок, группы
- C4 «Отозвать»: смету (новый статус) или только ссылку; слова
- C5 «Клиент отказался»: отметка в приложении + кнопка «Отказаться» у клиента на `/p/`; X сейчас тупик — что из X можно
- C6 «Истекла»: чип, «Продлить срок»
- C7 «Дублировать» / «Копия для другого клиента»
- C8 «Переименовать»
- C9 «Сохранить как шаблон» — слово
- C10 «Как видит клиент» — нужен ли, где, слово
- C11 правка отправленной (S): сейчас «Готово» молча делает её черновиком, клиент видит «Смета обновляется». Как правильно (S остаётся S + «изменения не отправлены» + «Отправить изменения»? предупреждение?)
- C12 правка подписанной (AC/A): копия, новая версия, снятие подписи?
- C13 «Депозит» / «Задаток» — одно слово
- C14 пять названий подписи — свести
- C15 вкладка «Подпись на месте» для того, у кого нет права
- C16 после A: «Запланировать работу» / «Счёт» / «Записать депозит» — что главное, что в «⋯»
