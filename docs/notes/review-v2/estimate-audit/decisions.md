# Решения по спорным пунктам референдума (исполнитель аудита, 23.11.2026)

Главный принцип, из которого выведены решения: **у сметы одна понятная жизнь** — черновик → отправлена → подписана → в работе; из любой точки есть честный выход (исправить, отозвать, отказ, в архив), удаляется только то, что клиент никогда не видел. Слово кнопки = что она сделает.

- **C1 главная у отправленной:** «Отправить ещё раз» / Resend / Reenviar (честно: та же ссылка ещё раз; «Напомнить» новичок понял неверно, в DS «Напомнить» — про оплату). Рядом второй кнопкой — «Позвонить» / Call / Llamar (если у клиента есть телефон). Истекла — главная «Продлить и отправить» / Extend & resend / Extender y reenviar. Каждая повторная отправка записывается в историю («Отправлена ещё раз 23.11»).
- **C4 «Отозвать смету»:** без нового статуса. «⋯ → Отозвать смету…» (подтверждение): ссылка у клиента закрывается («Смета отозвана — свяжитесь с компанией»), смета возвращается в **Черновик** с пометкой «Отозвана 23.11». Дальше её можно исправить и отправить заново или убрать в архив. Отдельного «Отозвать ссылку» нет. (Расходится со спекой 38 §9.2 `voided` → map-keeper правит спеку и §5 тем же К1, #2419.)
- **C5 из отказа (X):** «Вернуть в черновик» / Reopen as draft / Reabrir como borrador в «⋯» (новый ход declined→draft, К1) + «Дублировать». Отказ бывает от клиента (кнопка на `/p/` и отметка в приложении, причина списком) и от компании (как сейчас).
- **C7:** один пункт «Дублировать» / Duplicate / Duplicar: создаёт черновик-копию и сразу открывает его; в черновике клиента можно сменить (E17). Отдельной «Копии для другого клиента» нет.
- **C11 правка отправленной:** статус остаётся «Отправлена»; под заголовком «Изменения не отправлены клиенту ?»; главная — «Отправить изменения». Клиент до этого видит и **может подписать прежнюю отправленную версию** (как Jobber); если подпишет — владельцу уведомление «Клиент подписал версию от 21.11, ваши правки не вошли», правки остаются отдельным черновиком изменений. Нужен снимок отправленной версии (в базе `sent_version_id` уже есть — проверить в этапе 0 К1).
- **C13:** «Депозит» / Deposit / Depósito — везде (основатель сам говорит «депозит»; слово договоров США). «Задаток» удалить из i18n.
- **E1:** сетка 2×2 над позициями: [«＋ Позиция» · «＋ Раздел»] / [«Каталог» · «Шаблон»] — `secondary` 40, половинами, влезает на 390 в RU/EN/ES; тот же блок в пустой смете. Окончательно — прототипом на 390 (дизайн).
- **E3:** «Экран для клиента» убрать. Вместо трёх понятий («Как видит клиент», «Экран для клиента», «Подпись на месте») — **одно: «Показать клиенту» / Show to client / Mostrar al cliente** — полноэкранный документ ровно как на `/p/` (без себестоимости и прибыли), снизу «Одобрить и подписать» для подписи на месте и «Закрыть». Есть в шапке карточки (значок «глаз» + слово в «⋯») и в «⋯» редактора.
- **E19:** переключатель «Сохранить в каталог» из раскрытой позиции убрать (скрытое действие при сворачивании). В «⋯» позиции — «Добавить в каталог» / Add to price book / Agregar al catálogo → тост «Добавлено в каталог · Вернуть». У позиции, взятой из каталога, пункта нет.
- **W2:** отмена отправки в шторке — «Не отправлять · 5» / Don't send · 5 / No enviar · 5. Тост — «Вернуть» / Undo / Deshacer (DS; правило 5 CLAUDE.md «Отменить» → поправить руководителю). Низ редактора: совет предлагал «Сбросить правки» (2:1:1), но «Отменить / Готово» утвердил основатель — **оставляем «Отменить»**; тост переименован в «Вернуть», отправка — «Не отправлять», и «Отменить» остаётся с одним смыслом: откатить правки с момента открытия.
- **E4 «Готово» или «Сохранить» (вопрос основателя):** «Готово» (единогласно): при автосохранении всё уже сохранено, «Сохранить» обманывает — человек решит, что без нажатия потеряет правки. Под заголовком — «Сохранено на телефоне» / «Сохранено» (с «?»).
- **Налог суммой (спор CRM с решением 7):** делаем по решению основателя (%·выкл·$); при «$» под строкой показываем «≈ 9,5 %» — пересчёт для отчёта. Движок — К1.
