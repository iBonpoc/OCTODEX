# Значки — разбор круга 1 (21.11.2026, задача #2363)

## Откуда путаница
- **В приложении** — утверждённый набор «Тонкие острые» (основатель 20–21.11: «такие нравятся тонкие и острые»; страница выбора https://claude.ai/artifact/UnVD2GjvR4FKQj6uBg16AL; перенесён коммитом `fa622df2d`). Словарь — `design/naryad-ds/tokens/icons.json` (144 значка), правила — DS §18.1 «Смыслы не делят значок».
- **В макете v2** (`docs/design/visual-v2.html`, строки 272–307) — **свой временный набор из 36 значков** (обычные скруглённые, линия 1,75, похожи на Lucide). Его рисовали до выбора набора; он **не утверждался** и подменяет смысл в нескольких местах.
- Вывод: **форму** значков берём только из приложения («Тонкие острые»); у макета берём только **где** стоит значок. Где макет поставил значок другого смысла — макет неправ.
