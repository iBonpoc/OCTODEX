# Раздел «деньги» на телефоне: как делают лучшие (ресёрч 22.11.2026)

Правило: каждое утверждение — с URL; не подтвердилось — «не подтверждено». Страницы читались 22.11.2026 через веб-выжимку, не в самих приложениях.

## Jobber (iOS/Android)

1. Нижняя панель: Home, Schedule, Timesheet, Search, Messages, More; плюс «+» справа внизу. Отдельных вкладок Quotes/Invoices/Payments НЕТ. — https://help.getjobber.com/en/articles/jobber-app-basics/
   (Более старая статья про Home называет только Home и More — https://help.getjobber.com/en/articles/home-in-the-jobber-app/ ; в январе 2023 «Clients» был вкладкой с фильтрами по статусу — https://productupdates.getjobber.com/8156-find-your-work-more-easily-with-filters-in-the-updated-mobile-app, страница отдала 403, содержимое известно только из поисковой выжимки — слабо.)
2. Документы живут во вкладке Search: тап по типу сверху (Clients, Requests, Quotes, Jobs, Invoices) → фильтр по статусу. По умолчанию — 100 последних обновлённых клиентов/работ. Поиск по имени, телефону, адресу, номеру квоты/работы/счёта. Вкладки типов видны только при праве. — https://help.getjobber.com/en/articles/jobber-app-basics/ ; https://help.getjobber.com/en/articles/invoices-in-the-jobber-app/
3. Общей ленты «Все документы» в приложении не найдено — не подтверждено. Есть общая лента активности: колокольчик на Home. — https://help.getjobber.com/en/articles/home-in-the-jobber-app/
4. Сводка сверху — это список дел на Home (только админ), каждая строка ведёт в список с уже выставленным фильтром: «Changes requested» (квоты), «Approved quotes», «Require invoicing jobs», «Awaiting payment invoices», «Past due invoices», плюс «Connect your bank account» (сумма ожидающих выплат). Срочное подсвечено и поднято наверх. — https://help.getjobber.com/en/articles/home-in-the-jobber-app/
   Плитки с метриками (Overview по статусам, Issued, Average invoice price, Average time to get paid) описаны для веб-списков; на телефоне не подтверждены. — https://help.getjobber.com/en/articles/invoices-in-the-jobber-app/ не про них; веб: https://help.getjobber.com/en/articles/invoices-list-page-and-key-metrics/
   Веб-метрики: Quotes — Overview, Conversion rate, Sent quotes, Converted quotes (https://help.getjobber.com/en/articles/quote-list-page-and-key-metrics/); Payments — вкладки Overview и Payouts; Overview: Available funds, Invoice payment time, Invoices paid on time; Payouts: Processing, On the Way, Deposited (https://help.getjobber.com/en/articles/list-pages-and-key-metrics-basics/).
5. Фильтры: на телефоне — выбор типа + повторный тап по типу раскрывает статусы (меню), в Invoices: Draft, Awaiting Payment, Past Due, Paid, Bad Debt. Веб-фильтры: Status, дата выставления/срока (All, This month, Last month, This year, Custom range). — https://help.getjobber.com/en/articles/invoices-in-the-jobber-app/ ; https://help.getjobber.com/en/articles/invoices-list-page-and-key-metrics/
   Статусы Quotes: Draft, Awaiting response, Changes Requested, Approved, Converted, Archived. — https://help.getjobber.com/en/articles/quote-list-page-and-key-metrics/
   Статусы счёта в вебе: Draft, Awaiting Payment, Past Due, Paid, Bad Debt, Voided (там же, invoices-list-page).
6. «+» (Quick create): Client, Expense, Invoice, Job, Quote, Request, Task — в зависимости от прав; одинаков на любом экране. На визите/оценке «+» заменяется кнопкой «Camera». Счёт из «+» не привязан к работе; обычный путь — Complete Visit → Invoice now, или Generate Invoice у работы в Requires Invoicing. — https://help.getjobber.com/en/articles/jobber-app-basics/ ; https://help.getjobber.com/en/articles/invoices-in-the-jobber-app/
7. Приём оплаты: у счёта кнопка «Collect Payment» (по умолчанию полный остаток, можно частично), офлайн — Cash / Check / Bank transfer, «Details» для даты и номера чека; «Payments» поле с «+». Раздел Payments (Jobber Payments, выплаты) — в «More». — https://help.getjobber.com/en/articles/invoices-in-the-jobber-app/ ; https://apps.apple.com/us/app/jobber/id1014146758 (релиз 6.99.0)
   Веб-меню Jobber: Clients, Requests, Quotes, Jobs, Invoices, Payments без разделов «Work»/«Money» — https://help.getjobber.com/en/articles/list-pages-and-key-metrics-basics/ (группировка «Work»/«Financial» в меню не подтверждена).

## Invoice2go

- Нижнее меню с иконками: Home, Clients, Invoices, Estimates, More (по статье точные подписи не заданы, «more» раскрывает полный список). Overview при открытии: pending estimates, paid и overdue invoices, продажи за налоговый год. «+» = начать счёт; в справке — синий «+» справа внизу и выбор типа документа. Сортировка (drop-down «Sorted by»): дата, номер, срок оплаты (только счета), клиент; фильтр по налоговому году; поиск (лупа) по клиентам, документам, позициям. Фильтров по статусу не найдено. — https://invoice.2go.com/blog/welcome-to-the-new-invoice2go-overview-and-navigation/ ; https://z3n-invoice2go.zendesk.com/hc/en-us/articles/24171076930452 (по поисковой выжимке; сам текст не открывался)

## QuickBooks mobile (Sales → Estimates/Invoices/Payments)

- iOS FAQ (старая версия 4.3): всё через меню ☰: Customers, Vendors, Estimates, Invoices, Sales Receipts, Payments…; «+» внизу страницы создаёт транзакцию; лупа = поиск и фильтры; Filter By: Status (счета), Date, Group By. — https://http-download.intuit.com/http.intuit/CMO/QBM2/ios/v4_3/iphone/en_US/apple_phone_qbo_faq.html
- Актуальный путь: Menu → «Sales & Get Paid» → Invoices / Estimates / Sales Receipts / Invoice Payments (Android); на iPad типы переключаются выпадающим фильтром. Статус под именем клиента; у неоплаченного — срок или «N days overdue». Статусы: Open, Not sent, Sent, Viewed, Partially paid, Paid, Deposited, Not deposited, Voided, Overdue. — https://quickbooks.intuit.com/learn-support/en-us/help-article/mobile-apps/track-status-invoices-quickbooks-online-mobile-app/L94Lx4kcz_US_en_US ; https://http-download.intuit.com/http.intuit/CMO/QBM/android/qbo/v3_8/en_US/android_qbo_faq.html
- Нижняя панель (по сообщению пользователя, 2025): три пункта dashboard / sales / menu, не настраивается — слабый источник. — https://quickbooks.intuit.com/community/do-more-with-quickbooks-6/with-the-new-update-why-is-the-checking-account-harder-to-access-and-not-have-a-shortcut-at-the-bottom-like-there-used-to-be-284006

## Stripe Dashboard app (образец «денег» без документов)

- Вкладки: Home (графики, «Reports overview» + Edit), Payments, Balances, Customers (иконка в панели). «+» справа сверху на любой вкладке: «Charge a card or send an invoice», «Create a payment link», «Pay out funds», «Create a customer». Внутри Payments — подразделы Payment Links, Subscriptions. Действия над платежом — панель внизу: Refund, ⋯ → View receipt / Send receipt. Push: Daily summary, New payments, New customers, Disputed payments, Deposited transfers. Поиск по всему бизнесу. — https://docs.stripe.com/dashboard/mobile
- Счета в Stripe — только «basic creation», отдельной вкладки нет (там же).

## Ответы на 7 вопросов

1. Верхняя навигация: ни один подтверждённый лидер не выносит Estimates/Invoices/Payments тремя вкладками нижней панели. Jobber — общий Search + выбор типа; QuickBooks — меню ☰ «Sales & Get Paid» → тип; Invoice2go — вкладки Invoices и Estimates отдельно; Stripe — Payments отдельной вкладкой. Сегмента «Estimates · Invoices · Payments» с дефолтом не найдено ни у кого (на iPad QuickBooks — выпадающий фильтр типа). Дефолт у Jobber Search — недавно обновлённое.
2. «Все»: общей ленты документов не подтверждено ни у кого; ближайшее — Search у Jobber (смесь клиентов и работ, 100 последних) и Activity у QuickBooks.
3. Сводка: у Jobber на телефоне — строки-дела на Home, каждая ведёт в отфильтрованный список; веб-метрики — Overview по статусам (тап = фильтр), Issued, Avg time to get paid, Available funds. У Invoice2go — Overview. У HCP сводных плиток нет.
4. Фильтры по статусу: Jobber — тап типа → тап ещё раз → список статусов (меню); HCP — быстрые чипы All/Unsent/Due/Past Due + кнопка Filter; QuickBooks — Filter By: Status.
5. Поиск: Jobber — вкладка Search (имя, телефон, адрес, номер, строка позиции); QuickBooks — лупа; Invoice2go — лупа; HCP — Search по любому полю (веб); Stripe — поиск по всему бизнесу.
6. «+»: Jobber — один «+» на всех экранах, меню типов (Invoice, Quote, …), не зависит от сегмента; Invoice2go — «+» создаёт документ нужного типа; Stripe — «+» на любой вкладке, меню действий. Контекстное «+ в зависимости от сегмента» не подтверждено.
7. EN-слова: Quotes (Jobber) / Estimates (HCP, QuickBooks, Invoice2go, Joist); Invoices; Payments; статусы Jobber: Draft, Awaiting response, Changes Requested, Approved, Converted, Archived (квоты); Draft, Awaiting Payment, Past Due, Paid, Bad Debt, Voided (счета); действия: Collect Payment, Invoice now, Generate Invoice, Send receipt, Refund; More; Search.
