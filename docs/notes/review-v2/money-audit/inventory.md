# Экран «Деньги» — инвентаризация (origin/main 14fcdbe, 22.11.2026)

Жалоба основателя: «нажимаю „Деньги“ — нет переключателей Сметы/Счета/Оплаты; сначала надо нажать „Все“». Подтверждается, и это не сбой, а заложенный дизайн: обзор и списки — два разных экрана.

## 1. Где что (файл:строка)
- Вкладка «Деньги» нижней панели → `/finance`: `apps/mobile/src/nav/sections.ts:68` (id `finance`, tab, phoneOnly, roles OFFICE), `:107` (`sectionHref`: tech → `/estimates`, остальные → `/finance`). Порядок вкладок `TAB_ORDER` (`sections.ts`, «Главная · План · Клиенты · Деньги · Лиды»).
- Обзор: `src/app/finance.tsx` (весь экран, 147 строк). Никакого Segmented/chips там нет.
- Сегмент «Сметы · Счета · Оплаты»: хук `useMoneyChips` — `src/features/moneyTabs.tsx:24-38`; рисуется только в `ListScreen` (`src/ui/templates/ListScreen.tsx:64-74`, `chipsAs="segment"` → `Segmented full equal`, testID `<screen>-chips`).
- Три экрана списков, у каждого свой маршрут и свой сегмент: `src/app/estimates.tsx:23,49-50`, `src/app/invoice/index.tsx:51,131-132`, `src/app/payments/index.tsx:39,84-85`.
- Расходы — отдельный экран `src/app/money.tsx` (title «Расходы», с «назад», без сегмента).

## 2. Почему переключатель только после «Все» (корень жалобы)
1. `finance.tsx:61-70` собирает экран на `Screen`, а не на `ListScreen`: в нём нет параметра `chips`; `useMoneyChips` в `finance.tsx` не вызывается (импортируется только `useMoneyCreate`, строка 9).
2. Это зафиксировано решением и тестом: комментарий `finance.tsx:24-29` («The lists «Сметы · Счета · Оплаты» (their segment) are behind the tiles and «Все ›»») и e2e `e2e/specs/521-money-overview.cjs`: `no segment on the overview` (проверка `est-list-chips` count === 0). То есть «исправление» = смена решения + правка спеки 521, а не баг.
3. «Все ›» (`finance.tsx:85`, testID `money-topay-all`) → `/invoice` — сегмент появляется потому, что `/invoice` — `ListScreen` с `chips` (`invoice/index.tsx:131`).
4. Сегмент переключает экраны через `router.replace` (`moneyTabs.tsx:35`), т.е. «Сметы/Счета/Оплаты» — три страницы с одним заголовком «Деньги», а не одна страница с вкладками; поэтому у каждого свой набор плиток и своя прокрутка/состояние (поиск `q`, `?f`, `?g` не переносятся).

## 3. Что видно сразу при открытии вкладки (390, директор), сверху вниз
1. Круглая аватарка слева; справа иконки: поиск (`money-search`), ползунки «Списки денег» (`money-lists`), «＋» (`money-create`).
2. Строка «Ноябрь 2026 · Демо», заголовок «Деньги».
3. Плитки 2 в ряд (`money-tiles`): «Должны · счета» `$2,800` + «1 просрочен · 2 счёта» (`money-tile-owed` → `/invoice`); «Сметы открыты» `$6,392` + «3 ждут ответа» (`money-tile-estimates` → `/estimates`).
4. Плитки 3 в ряд (`money-tiles-small`): «Сегодня» (`money-tile-today` → `/payments`), «Расходы, нед.» (`money-tile-spent` → `/money`, только pay-роли), «Задатки» (`money-tile-deposits` → `/payments`). Нулевая плитка не рисуется.
5. Группа «К оплате» (`money-topay`, строки `money-topay-<invId>`, максимум 3, `finance.tsx:22`), справа «Все ›» (`money-topay-all`) → `/invoice` БЕЗ фильтра. Колонки «Срок / Сумма», просрочка «−9 дн» красным словом + значок.
6. Группа «Оплачены сегодня · N» (`money-paid`, строки `money-paid-<payId>`, только pay-роли), колонки «Способ / Сумма»; строка → `/receipt/<id>`. Ссылки «Все ›» у этой группы НЕТ.
7. Нижняя панель, «Деньги» подсвечена.
Скрытые пути к спискам: шторка «Списки денег» (`finance.tsx:128-144`, ListRow `money-list-estimates|invoices|payments|expenses`) — три из четырёх пунктов дублируют плитки и «Все».

## 9. Находки: дубли, тупики, странности
1. **Главное (жалоба):** «Деньги» — обзор без сегмента; сегмент живёт на трёх других экранах. Решение осознанное, закреплённое e2e 521. Пользователь не видит, что внутри три списка, пока не нажмёт плитку/«Все».
2. «Все ›» одна: только у «К оплате» (→ счета). У «Оплачены сегодня» ссылки нет — оплаты открываются плиткой «Сегодня»/«Задатки» или шторкой. Для «Сметы открыты» путь только плитка.
3. Две разные раскладки плиток в одной вкладке: на обзоре — «Должны · Сметы открыты · Сегодня · Расходы · Задатки», на списках — «Ждёт оплаты · Просрочено · Получено · Ещё выставить». Названия, состав, акцент разные («Должны · счета» нейтральная — решение #2363 q77 Б; на списках «Ждёт оплаты» ЖЁЛТАЯ заливка — прямо противоречит тому решению).
4. Заголовок «Деньги» на списках не говорит, где ты (Сметы/Счета/Оплаты) — только активный сегмент; kicker «Ноябрь 2026» пропадает.
5. Дубли путей: плитка «Должны» = «Все ›» = шторка «Счета» (три пути в один экран); плитки «Сегодня» и «Задатки» оба ведут на `/payments` без фильтра (не на «Сегодня» / «Задатки»).
6. «Ещё выставить» ведёт на сметы (путаница смыслов), «Получено» для sales не нажимается молча.
7. Сегмент = `router.replace` (не вкладка): поиск и фильтры сбрасываются, back-стек не растёт — OK, но плитки-ссылки между списками (`push`) наращивают стек.
8. Расходы (`/money`) — отдельный экран «Расходы» с «назад»; в сегмент не входит, достижим только плиткой, шторкой, «＋».
9. sales видит суммы «Сегодня/Задатки» (платежи) при закрытых для него Оплатах — несоответствие правилу доступа 13 §4 (проверить, намеренно ли).
10. Иконка-ползунки «Списки денег» в шапке — ещё один скрытый список; если вернуть сегмент на обзор, шторка и плитки «Сметы/Должны» станут дублями.
11. Устаревший комментарий в `moneyTabs.tsx:19-23` («Деньги: one tab, its parts …») описывает сегмент как часть вкладки, а обзор его не рисует.
12. На 1280 «Деньги» не видны в рейке (phoneOnly) — десктоп-пользователь доходит иначе.
13. Сборка снимков: служба фотографа на моём worktree собрала битый бандл («No routes found» при рендере) — пересобрал руками `expo export`; к дизайну не относится.
