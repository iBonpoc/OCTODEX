# Совет по «Деньги» — дизайнер (23.11.2026)

Смотрел: finance__open (390/820/1280, обе темы), invoice__direct, estimates/payments direct, finance__sales, DS §8.13 по описанию инвентаря. Формат: `id · выбор · слова RU/EN/ES · довод`.

Диагноз. Вкладка нижней панели «Деньги» — раздел верхнего уровня; три вида внутри — это сегмент (HIG: segmented control переключает виды ОДНОГО содержимого внутри вкладки). Сейчас сегмент живёт на трёх других экранах, а вход — на четвёртом, непохожем. Основатель попал ровно в это. Дополнительно (было до правки): на «Счета» плитка «Ждёт оплаты» залита жёлтым акцентом — акцент `acc` только для главного действия, цвет только статус + значок + слово (правила 2, DS); решение #2363 q77 Б это уже запрещало.

- M1 · (б), с поправкой: «Деньги» открывает сразу сегмент «Сметы · Счета · Оплаты» (Estimates · Invoices · Payments / Presupuestos · Facturas · Pagos), под ним плитки текущего сегмента, потом список. Отдельного «Обзора» нет — его роль берут плитки и группы «Нужно действие» внутри каждого сегмента. Довод: слово основателя дословно; (а) делает 4 сегмента и «Обзор» без собственного списка — лишний уровень, (в) — то же, что (б), но с ложной «шапкой». Сегмент под заголовком, на всю ширину, высота 36/зона 44; на 390 три слова влезают (ES «Presupuestos» — проверить на 390, иначе сокращать шрифт нельзя — тогда «Presup.»? нет: оставить, три равные доли ~110 px хватает).
- M2 · Выбран последний открытый, хранится на устройстве (на пользователя). Первый запуск: «Счета» для director/dispatcher, «Сметы» для sales. Довод: деньги — это «кто мне должен»; iOS так запоминает вид (Mail, Files). Запоминание — только сегмента, не фильтра и не поиска.
- M3 · Одна раскладка на все сегменты: ряд из 2–3 плиток-фильтров ПО текущему сегменту, нажатие = фильтр списка в том же экране (повторное снимает, `selected` — рамка + галочка, не цвет). Состав:
  - Сметы: «Ждут ответа» (число + $), «Подписаны» (в работу), «Черновики».
  - Счета: «Должны» (сумма, нейтральная; просрочка внутри строкой «1 просрочен» красным со значком), «Просрочено», «Ещё выставить» (договоры минус счета — это про счета, а не сметы; нажатие → список «Нужно выставить» внутри Счетов, а не уход на /estimates).
  - Оплаты: «Сегодня», «Неделя», «Задатки» (ведут на фильтр, а не на общий список).
  «Получено» убрать (дубль «Оплачено за неделю» и «Оплат»). «Расходы» — не плитка (см. M5). Все плитки нейтральные; жёлтую заливку убрать. Довод: Jobber — каждая строка сводки ведёт в уже отфильтрованный список; сейчас две разные раскладки в одной вкладке.
- M4 · Чипы-фильтры не нужны: плитки уже и есть быстрые фильтры (3 на сегмент). Подробный фильтр (статус/даты/клиент) — одна иконка в шапке рядом с поиском, шторка строками `ListRow` (как у Jobber/QuickBooks «Filter By»). Чипы поверх плиток дали бы три ряда управления над первой строкой на 390 — пустая шапка, список уезжает под сгиб.
- M5 · Вне сегмента. Расходы — исходящие деньги, другая модель (поставщик, категория), смешивать с входящими нельзя. Вход: пункт «Расходы» в меню «＋» (создать) и строка-ссылка «Расходы · $1,375 нед. ›» в конце сегмента «Оплаты» для pay-ролей; экран `/money` остаётся со «назад». Иконка-ползунки «Списки денег» и шторка удаляются (три из четырёх пунктов — дубли; HIG: скрытый второй путь к тому же — шум); её слот занимает фильтр (M4).
- M6 · «＋» — меню, не зависит от сегмента (как Jobber/Stripe), но сегмент подсвечивает первый пункт: на «Сметы» первым идёт «Смета», на «Счета» — «Счёт», на «Оплаты» — «Принять оплату»; остальные ниже, затем «Расход». Довод: контекстное «＋» без меню непредсказуемо (на Оплатах «＋» создаёт что?), меню с умным порядком — одно действие `acc` и всё достижимо. «＋» в шапке справа сверху — было до правки; на телефоне досягаемость хуже нижней половины, но это общий паттерн DS для всех вкладок — «правила нет, предлагаю» вынести «＋» вниз отдельным решением, здесь не трогать.
- M7 · Поиск один, в шапке, переносится при переключении сегмента (поле остаётся, результаты — по новому сегменту, счётчик в плейсхолдере «Поиск по счетам»). Довод: человек ищет клиента «Kim» и хочет увидеть его смету, счёт, оплату подряд; QuickBooks/Jobber ищут по номеру, имени, сумме.
- M8 · Роли.
  - sales: сегмент из двух частей «Сметы · Счета» (уже так), плитки только по доступным; суммы «Сегодня/Задатки» (оплаты) sales не показывать — иначе показываем сумму и не даём открыть (нашёл на finance__sales; правило доступа 13 §4 — проверить, намеренно ли). Нажимаемое не имитировать: ненажимаемых плиток нет.
  - tech: вкладки нет, «Сметы» из «Ещё» — один вид без сегмента; без изменений.
  - 1280: «Деньги» в рейке должны быть (phoneOnly убрать). Десктоп без пункта раздела — пользователь не находит экран; на 820/1280 рейка = вкладки телефона. На 1280 список в одной колонке и панель объекта справа (как сейчас у Счетов); плитки в одну строку, не растягивать на пол-экрана (max-width плитки), колонки «Срок/Сумма» держать у названия (ограничить ширину группы).
- M9 · Один экран, три представления: переключение без перезагрузки, анимации нет кроме кросс-фейда списка; поиск и положение прокрутки каждого сегмента сохраняются в памяти экрана, пока открыта вкладка. Адрес меняется через `setParams` (глубокие ссылки `/invoice?f=…` остаются и открывают нужный сегмент). Не три страницы с `router.replace` — теряется состояние и «назад» ведёт непредсказуемо. Свайп между сегментами жестом НЕ делать (спорит со смахиванием строк «Напомнить/Принять оплату» и системным «назад»).
- M10 · Слова:
  - «Деньги» / Money / Dinero — оставить: раздел и вкладка.
  - «Должны» → «К оплате» (To collect / Por cobrar): «должны» неясно, кто кому; «К оплате» уже стоит как группа и читается как «мне заплатят». Но в ЭТОЙ группе у плитки Счетов не путать с «Ждёт оплаты» — объединить: плитка «К оплате $2,800» (всё неоплаченное), «Просрочено» отдельно.
  - «Ещё выставить» → «Не выставлено» (To invoice / Sin facturar): без «ещё», совпадает с Jobber «Requires invoicing».
  - «Задатки» → «Депозиты» (Deposits / Depósitos): в смете уже решено «Депозит» — одно слово на всё приложение.
  - «Списки денег» — удаляется вместе со шторкой.
  - Заголовок экрана оставить «Деньги» + kicker месяца всегда (сейчас пропадает на списках; значит «где я» говорит сегмент).

## Своё
1. Убрать жёлтую заливку плитки «Ждёт оплаты» (нарушение правила цвета, было до правки); выбранная плитка — рамка + галочка.
2. Нулевые плитки: сейчас не рисуются — на сегменте это скачок. Рисовать со значением «$0 / 0» и нейтрально (кроме «Просрочено»: 0 не рисовать).
3. Сгиб на 390: сегмент + плитки (2 ряда) съедают ~330 px из 844; плитки сделать одним рядом 3 в ряд (как нижний ряд сейчас) — первая строка списка видна без прокрутки. Сейчас на «Счета» видна одна группа и край второй.
4. Пустой сегмент («Все оплатили») показывает пустую простыню — добавить «Создать счёт» кнопкой `acc` (одно главное действие).
5. Сегмент не должен исчезать при открытии списка клиента (`?customer=`): там заголовок — имя, «назад», сегмента нет — это правильно, не менять.

## Топ-3
1. M1: «Деньги» открывает сразу сегмент «Сметы · Счета · Оплаты»; «Обзор» упраздняется (его роль — плитки сегмента). Правка e2e 521/78/80/133, DS §8.13, #2363.
2. M3 + M9: одна раскладка плиток-фильтров на сегмент, один экран с сохранением поиска/прокрутки; жёлтую заливку убрать; Расходы и шторку «Списки денег» вывести из плиток/шапки.
3. M8/M10: «Деньги» вернуть в рейку 820/1280; слова «К оплате», «Не выставлено», «Депозиты»; sales не видит сумм оплат, которые не может открыть.
