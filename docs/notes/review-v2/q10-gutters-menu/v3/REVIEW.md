## Чек-лист слов основателя 23.11
Колено A/B 30–90°+кол-во — да (подпись «вдоль стены» обрезана; меню углов не снято). Offset A/B 1/2/4″+кол-во — частично (меню 1/2/4/Свой не снято; при кол-ве 0 «2″» выглядит выбранным). Вид·размер·этаж одной строкой — структура да, значения режутся («Выбра…», «Прям. гл…», «Кругл. …»). Круглый без A/B — да. Гладкий «по месту/готовые» — частично (в «Ещё» не показан; подпись «по месту» при пустом виде). Клиентские поля пустые — частично (цвет/материал downspout «как у gutter»; материал/толщина/край gutter в «Ещё» без «⚠ Выберите»). «Закрыть|Сохранить» без ✕ — нет (✕ есть, нужен проп). Gutter: длина с лентой + [размер·цвет·этаж] — частично (лента-заглушка; нет ft/in и ряда дробей). Чипов нет — да.
## Блокирует (оба)
1. 3 поля в ряд режут значения → ряд 2+1 (Вид|Размер, этаж ниже/с профилем) или этаж в шапку. 2. Подпись колена B обрезана → подпись строкой выше, угол+степпер ниже. 3. ✕ → проп Sheet. 4. Пустые клиентские поля прячутся в «Ещё»: «Ещё» раскрывать само при пустом (не «≠умолчанию компании»), счётчик «3 не выбрано», «⚠ Выберите …», рамка bad. 5. Цвет/материал downspout «как у gutter» — либо «Выберите», либо записать: «как у gutter» = выбор. 6. Модель закрытия: «правка сразу» и «Закрыть|Сохранить» в MAP смешаны — выбрать одно (§3.17 е: форма с диалогом «Сохранить изменения?»). 7. g: нет подписей ft/in и ряда дробей.
## Желательно
«Как в прошлый раз» не видно (строка-подсказка под пустым полем / «как у gutter №1»); дублирование «Как этот, ещё один» и зеркало (левая сторона) отсутствуют; «Фото для бригады» не в MAP; свернуть нулевые B и Offset A/B в одну строку; единое «Выберите»; значок разреза у профиля; «Splash block/Удлинитель/Downspout/Offset» — смесь языков (правило: слова детали); offset при 0 — значение mut; «Без покраски» — строка, не заголовок; подпись «меняет все gutters (N)» у цвета; «Ещё» — строка 44; контраст мелких подписей; medium вместо large.
## Расхождения MAP↔снимки
