# MAP — карта окон Gutters (#2412), по WORKFLOW.md + DECISIONS.md + слова основателя 23.11
Основа: порядок «семейство раз на объект → отрезок → слив»; окно = инспектор объекта на чертеже: форма: «Закрыть | Сохранить», «Назад» на холсте откатывает сохранённое, внизу «Закрыть | Сохранить» без «✕» (слово основателя 16.11, spec 33-gutters-windows §3.17 е, DS §7.3; «Закрыть» с несохранённым → диалог «Сохранить изменения?»). Клиентские поля (профиль, размер, цвет, вид, материал, толщина, край крыши) в новом замере ПУСТО «Выберите» (#1858), затем «как в прошлый раз» из этого замера; умолчания компании — только колена (75°×3), низ, способ колен, толщина водостока. Чипов нет; значений ≤12 — меню у строки (SelectField), >12 — PickerSheet (цвет с образцами). Окно открывается `large`.

| Событие | Окно | Заметка |

| Нижняя панель, 2× тап на инструмент | «Новые» → Gutter / Downspout | те же поля без длины/этажа конкретного слива |

## Окно Gutter (сверху вниз)
0. Шапка «Gutter № N», подзаголовок «линия · длина».
1. Длина: ft, in, дробь + лента-шкала (spec §3.17 б).
2. [Размер | Цвет | Этаж] одной строкой, три меню (spec §3.17 в); профиль — меню со значком разреза. Цвет один на замер (подпись «смена меняет все gutters (N)»). Цвет открывает PickerSheet с образцами.
4. «Ещё»: профиль, материал, толщина, край крыши, крепление, хомут, углы (названием перечисляет содержимое; раскрывается сам, пока есть пустые клиентские поля (счётчик «N не выбрано»)).

## Окно Downspout — прямоугольный (сверху вниз)
1. [Вид | Размер | Этаж] одной строкой (три поля).
2. Колено A (от стены): угол 30/45/60/75/90° ⌄ · − n + (умолч. 75° × 3).
3. Колено B (вдоль стены): то же (умолч. 0).
4. Offset A: вылет 1/2/4″/Свой… ⌄ · − n +. 5. Offset B: то же (умолч. 0).
6. Низ ⌄.
7. «Ещё»: верх (воронка/leader head), цвет и материал («как у gutter»), толщина водостока (свой список, .019), стена и крепёж, способ колен (готовые/гнём сами), своя высота, переход в размер, бочка, сетка.
## Окно Downspout — круглый
Колено A/B нет: одна строка «Колено» (угол × кол-во, умолч. 75° × 3); одна строка «Offset». Остальное как выше.

## Элементы (для кода, правило 29 — всё до экрана в DS и витрину)
CountChoiceRow (подпись · меню значения · Stepper; ≈296 из 326 px на 390; «+ ещё угол» под строкой); ряд из 3 полей (FieldRow долями, токен component.pair.*); Sheet без «✕» и с «Готово»; PickerSheet со слотом образца; materialSwatch; ToggleRow; иконки профилей. Сегментов и чипов нет.
## Подписи (RU/EN/ES): «Колено A · от стены», «Колено B · вдоль стены», «Offset A/B», «Ещё» + список.

## Из спек, что остаётся в силе (§3.17): «Фото для бригады» внизу; без «✕»; пустое «Выберите» `mut` обычным весом; под пустой строкой «⚠ Выберите …»; «Сохранить» не гаснет.

## Способ колен (слово основателя 23.11)
Прямой гладкий: «Способ колен: По месту | Готовые», умолч. «по месту» (в «Ещё»; у колен подпись «по месту» mut). Ребристый: 3×A готовые, выбора нет. Круглый: только готовые, строки «Колено» и «Offset» без A/B, выбора способа нет.


## КРУГ 3 — действует вместо противоречащего выше (см. DECISIONS п.21–24)
Gutter: длина = ft | in | дробь в одной строке + рулетка шире (до 1/32); [Размер|Цвет|Этаж]; профиль K стандартный; Крепление обязательное; «Ещё»: материал/толщина (стандарт), край крыши. Названия деталей по-английски.
