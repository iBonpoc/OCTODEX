## 1. Шаги на объекте
## 1. Шаги замера на объекте (порядок)
0. До приезда: адрес, что хочет клиент, этажи по спутнику (вне окон чертежа).
1. У входа, 2-3 мин с клиентом: что оставляем/меняем, цвет (образцы), HOA. Решения «на весь объект»: профиль, размер, цвет, материал/толщина. Это один раз и сразу, умолчания компании уже стоят. -> экран «Новые» (объект).
2. Обход без замеров: фото сторон, решаю, сколько отрезков, где углы, где сливы.
3. У стены: фасция/край крыши, тип стены, препятствия. Влияет на крепление и стену водостока. Один раз на сторону, редко.
4. Замер отрезков по кругу: на каждом длина, этаж, концы (внутр./внешн. угол/заглушка). Это 90% времени на лестнице. Окно: «новый gutter».
5. Сливы: ставлю по кругу. На каждом: вид+размер+этаж (одна строка), колена, офсеты, низ. Значения по умолчанию, правлю только нетипичное.
6. Клиенту в конце: цвет водостоков если иначе, сетка (guards), что делать со старым.
7. Фото к отрезку/сливу, голосовая заметка (идёт сквозь шаги 4-5).
8. Проверка «что забыл» (угол без типа, слив > 40 ft, этаж не задан), потом цена.
Вывод: порядок в окнах должен повторять 1 -> 4 -> 5: сначала семейство (раз), потом отрезок (длина, этаж, концы), потом слив (колена, офсеты, низ).

Окна повторяют порядок: семейство (раз на объект) → отрезок (длина, этаж, концы) → слив (колена, offset, низ).

## 3. Лишнее в окне (убрать/вывести)
финиш (из материала), outlet (авто), цвет/материал слива (по умолчанию «как у желоба», одной строкой), размер слива (следует за видом, в строке «вид·размер·этаж»), профиль/материал/крепление на отрезке (только подпись-итог), длина слива (из этажа; «своя высота» — редкое), дубли этажа/размера, 5 степперов круглых колен подряд.

## 4. Окна и что в них (порядок сверху вниз, подробности и компоненты — council-design.md)
- Новый/двойной тап по gutter: Длина (рулетка) → Этаж + Размер → Цвет → «Ещё» (профиль, материал, крепление, хомут, углы). Открывается сам после рисования.
- Новый/готовый downspout: [Вид · Размер · Этаж] одной строкой → Колено A, Колено B (угол + кол-во, «стандартный набор» одним тапом) → Offset A, Offset B (1/2/4″ + кол-во) → Низ → Ещё (цвет/материал «как у gutter», стена, редкое). «Готовый» = то же окно, значения заполнены.
- «Новые» (объект): строки Gutter и Downspout → страницы с теми же полями без длины/этажа/колен.
- Живое окно (правка сразу, «Назад» откатывает) против «Закрыть | Сохранить» — решение основателя ещё не принято по этому пункту (№24 решал «Готово», основатель отменил) — вынести в вопрос.

## 5. Новое для DS/кода (правило 29, до кода)
`CountChoiceRow` (подпись · меню значения · Stepper, ~296 из 326 px на 390; DS А6.4 + §20 + витрина + сторож); расширение `FieldRow` долями 1,6:1:0,7 и токен `component.pair.*` для «вид·размер·этаж»; Sheet без ✕ ; PickerSheet со слотом образца; токен materialSwatch; новые иконки профилей; переключатель «Гнём по месту/Готовые» (спека 33 §2.1 п.6 обещает, в окне нет).

## 6. Вопросы основателю — только продукт (сведены из обоих советов)
1. A/B колена — что это? Модель: прямой водосток имеет A/B без угла, круглый — только углы. Монтажник: A/B = плоскость изгиба (от стены / вдоль стены). Основатель просит A и B с углами у обоих — подтвердить: у какого вида что, и подпись «от стены/вдоль стены».
2. Offset A/B: в модели offset один (длина×кол-во). Что такое B, меняет ли смету?
3. Стандартный набор колен по умолчанию (монтажник: 2×A сверху + 1×A снизу; модель: по виду) — какой показывать?
4. Показывать ли «Гнём по месту / Готовые»?
5. Этаж у слива: свой или от отрезка?
6. Виды водостока: 4 (круглый/прямой × гладкий/ребристый) или меньше?
7. Колено: один угол на строку (A: 75° × 2) или несколько углов сразу?
8. Умолчания компании подставлять в окно (подпись «из настроек») или «Выберите»?
9. «Свой…» у offset оставить?
10. Толщина водостока: убрать или отдельный список (реальная тоньше жёлоба)?
