## 0. Допущения (проверить; если нет — сказать)
- «Новый gutter» = окно только что нарисованной линии (поля пустые или из умолчаний). «Двойной тап по gutter» = правка существующей. «По downspout» = только что поставленный (метка → окно сразу). «По готовому» = уже заполненный.
- Модель колен: у каждого колена (A, B) один угол из 30/45/60/75/90 и количество; у offset (A, B) один размер 1/2/4″ и количество. Если движок хранит счёт по каждому углу сразу (`ELBOW_STYLES`, пять счётчиков) — см. вопрос В1.
- Закрепление окна — по DS §7.3 без изменений: внизу «Закрыть | Сохранить», «✕» нет, «?» у заголовка. Решения №24 («Готово», автосохранение) основатель отменил — не опираюсь.

## 1. Общий каркас (все пять окон)
- **Шапка:** ручка, заголовок слева («Gutter 3», «Downspout 2»), справа «?» (Б7) и «⋯» (`ActionMenu`, Б4) только у готового объекта: «Дублировать», «Зеркально на другую сторону» (workflow п.5), «Удалить» (опасное, первым; тост «Вернуть», правило 5). «✕» нет.
- **Тело:** `ListGroup` со строками (правило 12). Одна группа = один смысл; заголовок группы caption `mut`. Выбор значения — `SelectField` (А2, до 12) и `PickerSheet` (цвет, >12). Чипов, сегментов, чекбоксов нет (А1в; сегмент — только вид окна). Этаж 1–4 и «Низ» (6) — `SelectField`, не чипы.
- **Подвал:** «Закрыть | Сохранить» 44, видимые, как ActionBar. Пустое обязательное: «Сохранить» не гаснет, «Выберите …» под строкой, прокрутка к ней (§11 п.3).
- **Высота на 390:** gutter — `medium`, downspout — открывается на `large` (в medium не влезает «Низ»). На 820/1280 — колонка справа 360, тот же порядок, тот же подвал внизу колонки.
- **Один «Ещё»** (`Collapsible`), подпись называет содержимое и показывает текущие значения: «Ещё · профиль K · алюминий .032 · крепление fascia». Открывается сам, если внутри есть ошибка «Выберите» или значение не равно умолчанию компании. Второго раскрытия нет (HIG Disclosure).
- **Порядок = частота:** сверху то, что меняют на каждом объекте (длина, этаж, колена, низ); семейство (профиль, материал, калибр, стена, комплекты) — в «Ещё» и строкой значения, а не россыпью.

## 2. Окно «Gutter» (новый и существующий — одна раскладка)
Сверху вниз (≈ 5 строк, влезает в medium на 390):
1. **Длина** — строка `ListRow`: «Длина · 23′ 11″ ›», главное; нажатие — рулетка (`Tape`, исключение §3.4). Пусто у нового: «Выберите» и акцент не нужен (главное действие — «Сохранить»).
2. **Этаж | Размер** — `FieldRow` из двух `SelectField labelAbove` (150+150 помещаются на 358; DS §9 «пара полей»). Этаж — 1…4; у нового по умолчанию этаж инструмента.
3. **Цвет** — строка со значением «образец + название» (исключение `materialSwatch`, только здесь) → `PickerSheet` с поиском. Если цвета дома два — это в шторке, не в окне.
4. **Ещё · …** (`Collapsible`): группа «Как сделан» — Профиль, Материал/калибр, Крепление, Хомут (`SelectField`), строка «Углы › …» (`CornerSheet`). Сегмент «Гнём по месту / Готовые» к колену — не здесь, он у downspout (§3).
- **Новый:** то же, поля без значений показывают «Выберите ⌄» там, где DS А2 требует выбор без умолчания; значения из настроек компании — только если основатель разрешит (В2).
- **Существующий:** значения заполнены; в подвале то же. «⋯» с действиями.

## 3. Окно «Downspout» (новый, затем готовый — отличается только заполненностью)
Сверху вниз:
1. **Вид · Размер · Этаж — одна строка**, три `SelectField labelAbove` рядом: «Вид ⌄ | Размер ⌄ | Этаж ⌄». Ширина на 390 (внутри ≈ 326, зазоры `space[2]`): доли 1,6 : 1 : 0,7 ≈ 150 / 95 / 65; в триггере короткие значения («Круглый», «2×3», «2»), полные названия — в меню. Меньше 11 шрифт не уменьшаем; не влезло — триггер показывает короткую форму (i18n-ключ `short`). Ширина 820+: тот же ряд, доли те же.
2. **Колена и offset** — одна `ListGroup` из 4 строк (§4, новый компонент): «Колено A», «Колено B», «Offset A», «Offset B». Под подписью caption `mut` «от стены» / «вдоль стены» — A/B без подписи путают (workflow п.3). Для гладкого прямоугольного над группой строка-переключатель «Гнём по месту» (`ToggleRow`, А5; вкл = труд «гиб», выкл = готовые детали) — спека 33 §2.1 п.6, сейчас окно её не показывает.
3. **Низ и высота** — группа из двух строк: «Низ ⌄» (`SelectField`, 6 значений) и «Высота · по этажу 18 ft ›» (`LengthField`; «своя» — `InputDialog`, 32а).
4. **Ещё · цвет, материал, стена, крепёж, редкое:** Цвет («как у gutter» значением), Материал/калибр, Стена, Крепёж стены (`SelectField`); группа «Редкое» — редуктор, оголовок, диверсор, сетка выхода как `ToggleRow` (А5; сейчас 2–5 чипов и «редкое» — чипы, нарушение А1в, было до правки).
- Высота: п.1+2+3 ≈ 64+4×44+2×44 = 328 + шапка 56 + подвал 72 ≈ 456 → окно открывается на `large`; в `medium` видны п.1–2, строка «Низ» выглядывает наполовину (подсказка прокрутки).
- **Готовый downspout:** то же, значения видны; колена с умолчанием движка подписаны «стандарт» (`mut`), изменённые — без подписи; «Ещё» раскрыт, если там не умолчание. «⋯» — Дублировать/Зеркально/Удалить.
- Метка с холста открывает окно сразу; «двойной тап» — только выбор→открытие, как сейчас (тест `tapRule`).

## 4. Один компонент «угол + количество» (нужен новый)
`CountChoiceRow` в `src/ui` (строка внутри `ListGroup`, 44): **подпись · меню значения · `Stepper`** в одну строку.
- Устройство: слева подпись «Колено A» (+ caption), посередине триггер `Menu` (А2: «75° ⌄», пункты 30/45/60/75/90; у offset «2″ ⌄», пункты 1/2/4″), справа `Stepper` «− 2 +» (36 видимые, зона 44, `stepperValueW` 56, 0–12).
- Ширина на 390: подпись ≈ 88 + меню 64 + степпер 128 + 2 зазора 16 = 296 ≤ 326; на 375 влезает (311). Если подпись + caption не влезают — caption переносится на вторую строку (строка до 52, `rowMax`), величины не мельчают.
- Это не «двойной элемент»: одна строка, одна пара «что + сколько», подпись одна. 4 строки вместо 10 степперов (5 углов × 2).
- Состояния: 0 — степпер «0», меню доступно (угол выбран заранее — умолчание 75° / 2″), строка не гаснет; предел — `Warning`; выключено — `dimOpacity`. Доступность: строка — `adjustable` для степпера, меню — `button` с `expanded`. Вибрация — `selection` на шаг.
- Нужно записать: DS (§9 новая карточка «А6.4 Значение и количество» + строка в §20 «11а»), токен, витрина (Настройки → «Дизайн-система»), правка `designSystem.test.ts`; в PR «Проверить в витрине: раздел — что сделать, что увидеть». Без этого строка — «своё» (правило 29).
- Другой вариант без нового компонента: `SelectField` угла и `Stepper` двумя строками (8 строк, простыня — отклонён).

## 6. §20 и правила — как не нарушено
| Что | Компонент | Строка §20 |
|---|---|---|
| Этаж, размер, вид, низ, профиль, материал, стена, крепёж | `SelectField` (≤12) | 4 |
| Цвет | `PickerSheet` | 5 |
| Колено/offset: что + сколько | `CountChoiceRow` (Menu + `Stepper`) — **нужен** | 11 + 4 |
| Длина gutter / высота downspout | `LengthField` / рулетка / `InputDialog` | 15, 32а |
| Редкое, «Гнём по месту» | `ToggleRow` | 10 |
| Действия (дублировать, удалить) | `ActionMenu` «⋯» | 37 |
| Вид+размер+этаж в ряд | расширенный `FieldRow` (доли, `fieldMin` ниже) — **править** | 4 |
- Правило 1: новые числа (доли ряда, минимум поля 65) — токены `component.pair.*`, не литералы. Правило 3: видимые 36 / 40, зона 44, перекрытий между меню и степпером нет. Правило 12: группы строк, `ListGroup`. Правило 29: только `src/ui`; два места «нужен новый» (п.4 и расширение `FieldRow`) — сперва DS + витрина.
- Цвет — только статус: подписи «стандарт», «по умолчанию» — текстом `mut`, без цвета; образец цвета — только в выборе цвета (исключение 3).

## 7. Вопросы основателю/руководителю (отдельно, по делу)
- **В1.** Колено A: один угол + количество, или несколько углов сразу («30° ×1 и 75° ×2» на одном колене)? Предложение — один угол на колено; редкое смешение — второй угол сменой строки не поддерживается, ставят два колена (A и B).
- **В2.** DS А2 и §8.1: цвет, размер, форма, профиль Gutters — «обязательный выбор без умолчаний», а workflow монтажника и движок берут умолчания компании. Правила нет — предлагаю: значения из настроек компании подставляются и подписаны «из настроек», пустое — только если в настройках не задано (нужно слово основателя, правка DS).
- **В3.** Offset «Свой» (размер не 1/2/4″) — оставить пункт «Свой…» в меню (есть в коде) или убрать (в словах основателя его нет).
- **В4.** Применимость углов к прямоугольному: у него сейчас стили A/B (без углов). Слова основателя дают углы обоим коленам — подтвердить, что это для круглого и прямоугольного одинаково.
