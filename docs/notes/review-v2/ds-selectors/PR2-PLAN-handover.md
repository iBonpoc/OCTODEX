## 2. Развилки — решить ДО кода (этап 0, К1: данные)
1. **Сохранение:** макет — «Закрыть / Сохранить» (черновик окна), код — живое сохранение с «Отменить». Вариант А: оставить живое, убрать «Сохранить», «Закрыть» = «Готово» (меньше кода, нет риска потерь, как iOS Настройки). Вариант Б: черновик + `Sheet dirty` (§9б.7). Совет crm-reviewer: «каждое поле сразу сохраняется, внизу одна „Готово“» — **рекомендую А**; основатель видел «Закрыть/Сохранить» в макете — сказать ему «было/стало».
2. **Elbow A/B с углом каждый, Offset A/B:** новая модель `elbows[{style:"A"|"B", angle, qty}]`, `offsets[{style:"A"|"B", lengthIn, qty}]` — правило 16 (два шага, старые телефоны), нормализация старых записей, тесты движка (цена колена по углу? — спросить, есть ли разница в прайсе; если нет — угол только в заказ поставщику).
3. **«Верх» — 5–6 названных голов** вместо none/funnel/conductor: новый список в `Choices` + миграция значений; «Y» Funnel — только ребристый.
4. **Этаж у downspout:** свой `ds.story` или этаж линии gutter. Макет — своё поле. Рекомендую своё поле с умолчанием «как у линии».
5. **Крепление к стене по форме, не по стене:** макет даёт список по форме (7 квадр., 5 кругл.), код — по стене × форме. «Стена» + «Сайдинг» — новое значение. Решить, фильтрует ли стена список (crm: «поднимать подходящие наверх»).
6. **Рулетка 1/32:** макет — шаг 1/32, код — 1/16 везде (`DENOM=16`, `canvas/format.ts`). Основатель 23.11 05:10 «деления до 1/16 с подписями»; 1/32 — только в поле «Дробь» (#2414?). Рекомендую оставить 1/16 (меньше риска), уточнить по журналу.
7. **Миниатюры деталей:** нет поля картинки у деталей каталога → пока плитка со значком (§9б.5 это разрешает).
8. Reducer (в макете нет) и `Corners` (в макете нет) — оставить в «Ещё» или убрать: по журналу основателя (Reducer убран — «на стенде нет»).
