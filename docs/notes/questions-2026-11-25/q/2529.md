## Ресёрч
- Флажок, который держит второй вариант кода, — долг: его снимают сразу после решения. Чем дольше два вида живут рядом, тем дороже каждая правка, потому что её приходится делать дважды (Martin Fowler, «Feature Toggles», https://martinfowler.com/articles/feature-toggles.html — по памяти, не перепроверено).
- Apple HIG (по памяти): одно приложение — один визуальный язык. Привычки человека держатся на том, что одинаковые вещи выглядят одинаково везде.
- Дизайн-системы лидеров (Apple, Material, Shopify Polaris; по памяти): у них один действующий документ. Новые идеи проходят через предложение → проверку → запись в тот же документ, а вторая параллельная система не живёт.
- У нас уже есть такой порядок: ДС §2.3 «сначала дописать правило в ДС, потом делать» и §0 «этот документ — единственный источник правил вида».
