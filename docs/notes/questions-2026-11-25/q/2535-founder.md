# Вопросы первой недели (5–8 ноября): как сделано

Тогда эти вопросы остались без вашего ответа. Ниже — как приложение работает сейчас. Напишите только то, с чем не согласны, например «не согласен с 21». Остальное считаем принятым.

## Главное
- Дату выезда назначает только офис: владелец, админ, диспетчер. Продажи выезды не назначают. (№21)
- Своя комиссия GoRix с каждого платежа предусмотрена, но сейчас она ноль. Размер решаете вы. (№4)
- Комиссию Stripe платит подрядчик. Надбавки для клиента за оплату картой нет нигде — в Калифорнии она запрещена. (№2)
- Клиент заплатил больше остатка (пока шёл его перевод, офис записал наличные): платёж всё равно записываем и помечаем «проверить», чтобы владелец вернул лишнее. (№5)
- Аванс без счёта не входит в «Собрано», пока его не зачли в счёт. (№9)
- Проигранный спор по карте только отмечается. Сумма «оплачено» по счёту не меняется. (№6)
- Мастер никогда не видит себестоимость и прибыль. Продажи не видят расходы. (№19)

## Деньги и оплаты
- Оплата картой и банковским переводом (ACH) идёт прямо на счёт подрядчика в Stripe. У подрядчика полный кабинет Stripe. Потери по спорам — на Stripe и подрядчике, не на нас. (№1)
- При счёте от $1,000 первым предлагаем банковский перевод — он дешевле карты. (№3)
- Пока работаем только в тестовом режиме Stripe. Перед настоящими деньгами включим защиту от мошенников и лимит попыток оплаты. (так записано, ещё не сделано) (№7)
- Чтение чеков с помощью ИИ не сделано. Ждёт вашего «да». (№8)

## Поставщики и заказы
- Заказ поставщику уже есть. Его делают вручную из работы. Автозаказа и запроса цен нет. (№10)
- Заказ уходит поставщику файлом PDF на английском через «Поделиться». Это решаем отдельным вопросом. (№11)
- Продавец не видит поставщиков и список заказов. Мастер видит только заказ своей работы. (№12)
- В заказе поставщику цены по умолчанию не печатаются. Офис может включить их галочкой. (№13)
- У поставщика один адрес, без филиалов. (№14)

## Заявки с сайта
- В форме заявки сразу есть галочка «согласен на SMS». (№15)
- Капчи от ботов пока нет. Заявки без неё не теряются, а попадают «на проверку». (№16)
- Форма заявки открывается по адресу gorix.expo.app, а не gorix.app. (№17)

## Роли: кто что видит
- Мастер принимает оплату на месте и открывает счёт своей работы. Общего списка счетов у него нет. (№18)
- У человека одна роль в компании. Владелец, который сам ездит, видит свои выезды на Главной. (№20)
- Продажам закрыты «Оплаты» и «Отчёты». (№22)
- Субподрядчик в задании видит свою сумму оплаты, цены клиента — никогда. До «Принять» видит только город и индекс. (так записано, ещё не сделано) (№23)

## Работы, выезды, чек-листы
- Всю работу можно отменить. Сначала спрашиваем подтверждение. «Вернуть» нет — отмена окончательная. (№24)
- Работа дороже $500 на жилом доме в Калифорнии без сметы — только предупреждение, не запрет. (№25)
- Пункт чек-листа — один текст для всех языков, как его ввели. У осмотра тоже есть чек-лист. (№26)
- Просьбу об отзыве шлём клиенту не чаще раза в 12 месяцев. (так записано, ещё не сделано) (№27)

## Хранение и удаление
- Данные храним 7 лет. Удалять по сроку не начинаем, пока не скажет юрист. Это решаем отдельным вопросом. (№28)
- Сотрудник отозвал согласие на геопозицию — все его точки удаляются. (№29)
- «Закрыть компанию» работает без выгрузки данных на почту. Выгрузку сделаем позже. (№30)
- Единственный владелец удаляет свой аккаунт — сначала предлагаем передать компанию другому. (№31)

## Почта клиенту
