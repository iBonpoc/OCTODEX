## Как ведём
1. Исполнитель сдал готовый PR → руководитель ставит ярлык `копим` и строку в #3002 → архивариус переносит строку сюда.
2. Раз в день архивариус сверяет: открытые PR с ярлыком `копим` ↔ строки #3002 ↔ этот файл. Расхождение — сообщением руководителю.
3. PR из копилки держат без конфликтов с `main`: автор сливает `main` в ветку, при отказе — архивариус (документы) или руководитель.

## Как вливать по слову основателя
1. Слово основателя «вливаем» — дословно комментарием в #3002.
2. Вливаем **по списку ниже, сверху вниз, по одному**: перед каждым — `main` слит в ветку PR; после каждого — полная матрица на `main` (правило 13), красная — стоп и разбор (правила 26, 30).
3. Влитый PR — галочка в #3002 и здесь; ярлык `копим` снимается.
4. После последнего PR кода — перегенерировать токены (`npm run gen -w @octo/design-tokens`, сторож `generated.test.ts`).
5. Когда список пуст — стенд #2977 закрыть с пометкой «всё влито», этот файл — в `archive/` с итогом.
