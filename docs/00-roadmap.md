# 00. Дорожная карта: как мы строим продукт

> Это главный документ процесса. Мы идём по фазам и не переходим к следующей, пока не закрыт «шлюз» (gate) текущей.
> Каждое решение записывается в `docs/`, каждая фаза заканчивается артефактом, который утверждает основатель.

---

## Главные правила

1. **Сначала «что и зачем», потом «как».** Код не пишем, пока для этой части нет спецификации, модели данных и утверждённого дизайна.
2. **Одна правда.** Все решения лежат в git (`docs/`). Устная договорённость, не записанная в документ, не считается решением.
3. **Шлюзы.** Фаза закрывается, когда основатель сказал «утверждаю» по её артефактам.
4. **Вертикальные срезы.** Строим не «сначала всю базу, потом весь интерфейс», а одну функцию целиком: база → API → веб → iOS → тесты. После каждого среза есть работающий кусок продукта.
5. **Проверка на реальном бизнесе.** Каждый срез основатель пробует на своей gutter-компании.
6. **Деньги как фильтр.** У каждой функции есть ответ на вопрос «как это помогает подрядчику заработать».
7. **Безопасность с первого дня**, а не «потом добавим».
8. **Definition of Done.** Задача готова, только если: есть критерии приёмки, тесты написаны и реально запущены (с выводом команд), проверен доступ к чужим данным, обновлены документы. Фраза «всё готово» без проверки не принимается.
9. **Цикл каждой задачи:** анализ → план → согласование (обязательно для схемы БД, прав, денег, интеграций) → реализация → тесты → ревью → документация.
10. **Журнал решений (ADR).** Важные технические решения (стек, база, офлайн, AI) записываются коротко: контекст, варианты, выбор, последствия.

### Фаза 4. Фундамент (Sprint 0)

**Шлюз 4:** «Hello world» работает на iPhone (TestFlight) и в браузере, тесты зелёные.

### Фаза 5. MVP вертикальными срезами
Порядок срезов (каждый от базы до iPhone):
1. Клиенты, объекты, лиды, источник лида
2. Каталог и Estimating Engine (сборки, формулы)
3. **Gutters: чертёж на спутнике → смета G/B/B → BOM → cut list**
4. Портал клиента: смета, подпись, депозит (Stripe)
5. Инвойсы, платежи, расходы с фото чека
6. Календарь, работы, повторяющиеся работы
7. Карта со слоями
8. Заказ поставщику (PDF/email)
9. AI-помощник v1
10. Отзывы, дожим смет, ROI по источникам
11. Офлайн-режим: доводка и тесты в поле

После каждого среза: демо, тест на компании основателя, исправления.

### Фаза 6. Бета
- 4–8 недель компания основателя работает **только** в приложении.
- Затем 5–10 подрядчиков в LA бесплатно или со скидкой.
- Метрики: время на смету, конверсия смет, ошибки, расход AI и SMS на компанию.

### Фаза 7. Запуск
App Store (ревью, скриншоты, политика конфиденциальности), сайт и SEO-страницы, тарифы, оплата, поддержка (AI + email), юридические документы.

### Фаза 8. Рост
Android, модуль Roofing, интеграции лидов (Thumbtack, Angi, Yelp, Google LSA, Meta), call tracking, финансирование, новые ниши.
