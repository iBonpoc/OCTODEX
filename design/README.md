# Папка `design/` — оглавление

Статус: действует · сверено 26.11.2026 · обложка библиотеки — `../docs/README.md` (раздел 4 «Дизайн»).

**Правила вида и поведения — только `naryad-ds/DESIGN-SYSTEM.md`** (решение основателя 11.11.2026), пока его не заменит дизайн-система GoRix (#2893). Всё остальное в этой папке — материалы, из которых он вырос, и черновики. Где они расходятся с дизайн-системой, верна дизайн-система. Папку `naryad-ds/` ведёт чат «Дизайн-система GoRix», сейчас действует заморозка вида #2893. Это оглавление только называет файлы, ничего не переносит.
