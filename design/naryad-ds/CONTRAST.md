# Проверка контраста (WCAG 2.1, порог 4.5:1 для текста)

Прозрачные поверхности стекла пересчитаны поверх фона. Минимальные значения по группам.

| Тема и стиль | Текст и подписи | Цветной текст статуса | Тёмный текст на цветных чипах и акценте |
|---|---|---|---|
| dark-glass | 4.9:1 | 4.7:1 | 7.0:1 |
| dark-matte | 6.2:1 | 6.0:1 | 7.0:1 |
| dark-soft | 6.9:1 | 6.2:1 | 7.0:1 |
| light-glass | 5.6:1 | 6.1:1 | 7.0:1 |
| light-matte | 5.6:1 | 5.4:1 | 7.0:1 |
| light-soft | 5.2:1 | 5.1:1 | 7.0:1 |

Цвета текста статусов: тёмная тема ok #7CE08A, info #AAB8FF, warn #FF9A55, bad #FF8F8F; светлая ok #176428, info #3647C4, warn #944600, bad #B4232A. Вторичный текст: тёмная #BEC3CD, светлая #575C68. Заливки чипов: ok #7CE08A, info #8FA2FF, warn #FF8A3D, bad #FF6B6B с текстом #0B0C0F. Акцент #FBFF00 с текстом #0B0C0F.

Не проверяется автоматически: контраст поверх цветных пятен фона, состояние наведения, градиент зерна матового стиля. Проверку нужно повторять после каждого изменения палитры.
