# Правило: проверка каждого экрана и компонента

Запускать после каждой правки, до передачи. Результат записывать в сообщении.

## 1. Три устройства
Телефон 390, планшет 820, десктоп 1280. Проверять каждое отдельно, не только десктоп.
- Размеры нажимаемых элементов: телефон 44 по высоте и ширине, десктоп и планшет 28–32 (см. раздел «Размеры» в дизайн-системе).
- Нет горизонтальной прокрутки страницы, текст не обрезан, подписи не переносятся на одну букву.
- Безопасные зоны телефона: сверху 44, снизу 34.
- Нижняя панель на телефоне, верхняя пилюля на десктопе и планшете.

## 2. Две темы, один стиль «Стекло»
Тёмная и светлая, стекло, матовый, мягкий (6 комбинаций).
- Контраст текста не ниже 4.5:1, крупного и значков не ниже 3:1 (скрипт описан в CONTRAST.md).
- Цвет только для статуса, всегда со значком и словом.

## 3. Состояния
Обычное, наведение, нажатие, фокус (кольцо акцента), недоступное, загрузка, пусто, ошибка, нет сети.

## 4. Код
- Компиляция логики без ошибок до запуска.
- Консоль без ошибок и предупреждений о незакрытых токенах.
- Нет ссылок на несуществующие переменные из шаблона.

- Прогон renderVals без браузера: логика каждого файла выполняется для всех экранов, трёх устройств, двух тем, стиля «Стекло» и окон (модалки). Ловит обращение к переменной до её объявления и другие ошибки выполнения. Далее проверка в браузере.

- Поиск повторяющихся ключей в возвращаемом объекте и значений шаблона без ключа (именно так нашлось, что `roleSel` был объявлен дважды и ломал страницу на экране «Участники»).

## 5. Доступность
Роли и подписи у иконок-кнопок, переключателей, ползунков, схем. Порядок фокуса, «уменьшить движение» отключает анимации.

## 6. Документация
Новый компонент: добавить в «Наряд Design System» (внешний вид, размеры для трёх устройств, состояния, движение) и в HANDOFF.md.

## 7. Размеры и подсказки (добавлено)
- Ни одной кнопки выше 36 (телефон), 32 (десктоп). Плавающая кнопка 36.
- Знак «?» видимый 18, tooltip шрифт 11, оба не выше строки заголовка.
- Новые значения сначала заводятся токеном, потом применяются.
- Сегменты, вкладки, нижняя панель: жидкий переключатель, не мгновенная перекраска.
- На телефоне знак «?» виден в шапке каждого экрана (проверять, что у экрана есть запись в справке).
- Строки списков 44–52 допустимы; кнопки внутри строк следуют правилу 36 видимых.
