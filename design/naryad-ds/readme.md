# Наряд: дизайн-система

CRM для выездных сервисов (кровля, сантехника, электрика, газоны). Источник: референсы пользователя (тёмное стекло, пилюли) и прототип `Наряд CRM.dc.html`. Подробности для разработки: `HANDOFF.md`.

## Content fundamentals
Русский, на «вы» без обращений, короткие подписи. Статусы словами: «Опаздывает», «Ждёт ответа», «Оплачено». Суммы с пробелом и ₽. Эмодзи нет.

## Visual foundations
- Цвет только для статусов (зелёный, синий, оранжевый, красный). Основное действие и выбранное: акцент `--acc` (по умолчанию #FBFF00) с тёмным текстом.
- Нейтральная графитовая тёмная тема и тёплая светлая. Один стиль поверхностей: «Стекло» (blur 20px, окна и шторки blur 24px, радиус 24). «Матовый» и «Мягкий» отключены.
- Шрифт Onest (Google Fonts). Размеры 11–28px.
- Формы: пилюля 999 для кнопок и чипов, карточки по токену `--r`.
- Движение: подъём 1px при наведении, сжатие 0.95 при нажатии, панели 0.35 с.
- Иконок нет: используются значки ✓ ● ▲ ✕ и текст. Логотипа нет: «Наряд» набран шрифтом.
