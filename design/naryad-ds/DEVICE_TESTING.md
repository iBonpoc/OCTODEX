# Проверка на настоящем телефоне

Тесты (`npm test`, `npm run test:screens`) не видят жесты, системные шрифты, VoiceOver, безопасные зоны и клавиатуру. Это проверяется руками на устройстве по списку ниже. Результат записывать в таблицу в конце.

## 1. Как открыть на iPhone
**Прототип и дизайн-систему (HTML):**
1. Скачайте `dist/Naryad-CRM-prototype.html` и `dist/Naryad-Design-System.html` из архива.
2. Отправьте файлы на iPhone через AirDrop или iCloud Drive, откройте через «Файлы» → Safari. Если Safari не открывает файл, поднимите локальный сервер на компьютере (`npx serve dist`) и откройте адрес в Safari по Wi-Fi.
3. Для проверки без панели Safari: «Поделиться» → «На экран Домой», затем открыть с иконки.
4. Проверять в портрете и в ландшафте.

**Нативное приложение (когда будет):** TestFlight или запуск из Xcode на устройстве. Симулятор не заменяет телефон для жестов, haptic, клавиатуры и камеры.

## 2. Подготовка телефона
- iOS 17 или новее, обновления установлены.
- Два телефона: с вырезом или Dynamic Island и маленький (iPhone SE или mini).
- Включить по очереди: тёмная и светлая тема (Настройки → Экран и яркость).

## 3. Список проверки

### Жесты и касания
| Что сделать | Ожидание |
|---|---|
| Свайп влево по клиенту в списке | Строка сдвигается на 88, появляются «Позвонить» и «SMS» иконками. Свайп вправо или нажатие закрывает |
| Вертикальная прокрутка списка, начав со строки | Список прокручивается, строка не сдвигается вбок |
| Зажать иконку-кнопку 0.4 с | Над ней появляется подпись на 1.6 с. Обычное нажатие выполняет действие |
| Нажатие по строке сразу после свайпа | Карточка не открывается (защита 350 мс) |
| Плавающая «+»: нажатие, перетаскивание | Нажатие открывает быструю запись, перетаскивание двигает кнопку |
| Размер зоны нажатия | Каждую кнопку удаётся нажать пальцем с первого раза, соседние не срабатывают |
| Двойное касание и щипок | Страница не увеличивается случайно |

### Dynamic Type (Настройки → Экран и яркость → Размер текста)
Проверить на самом мелком, стандартном и на 2–3 размерах крупнее:
- нет обрезанных подписей у кнопок, чипов и вкладок;
- строки списков растут по высоте, не накладываются;
- нижняя панель читается (подпись не исчезает);
- нет горизонтальной прокрутки страницы.
Для HTML-прототипа Dynamic Type работает частично (у Safari свои настройки размера текста: «аА» в адресной строке). В нативном приложении обязателен.

### VoiceOver (Настройки → Универсальный доступ → VoiceOver; включение тройным нажатием кнопки)
- Каждая кнопка-иконка произносится осмысленно: «Позвонить, Ольга Миронова, кнопка».
- Порядок фокуса: шапка → содержимое → нижняя панель, без возврата назад.
- Открытое окно или шторка: фокус уходит в окно, содержимое под ним недоступно, закрытие работает жестом «Выход» (двумя пальцами зигзаг).
- Переключатели произносят состояние («Автоответ, выключено»), статусы произносят слово, не только цвет.
- Тост с отменой произносится автоматически.

### Безопасные зоны
- На iPhone с вырезом: заголовок не под вырезом, нижняя панель не под индикатором «домой», плавающая «+» выше панели.
- Ландшафт: содержимое не под вырезом слева и справа.
- Шторки: кнопки не прилипают к нижнему краю ближе 34.

### Клавиатура
- Нажать поле поиска или поле заметки: поле остаётся видимым, шторка поднимается над клавиатурой, нижняя панель не накладывается.
- Тип клавиатуры: телефон — цифровая, почта — с @, сумма — цифровая.
- Кнопка «Готово» или «Отправить» закрывает клавиатуру.
- Выбор текста и вставка работают.

### Тема, движение, сеть
- Переключить тему на устройстве: цвета и контраст читаются на улице при высокой яркости.
- Включить «Уменьшить движение»: анимации отключаются, всё остаётся работоспособным.
- Режим «В самолёте»: плашка «Нет сети», действия встают в очередь, после включения сети очередь уходит.
