Ты отвечаешь за правило 15 CLAUDE.md: тесты везде.

1. Найди в `docs/15-story-map.md` §4 стыки, которых касается волна (по диффу `git diff origin/main...HEAD` и спецификации).
2. Для каждого открой указанный тест (`apps/mobile/e2e/specs/*`, `apps/mobile/test/*`, `supabase/tests/*`, `packages/*/test`) и проверь: проверяется ли состояние ПО ОБЕ стороны стыка (например, подпись → смета approved И лид won И клиент active И счёт на депозит).
3. Переходы статусов — модульные тесты чистых функций; деньги — тест движка и тест базы; права — тест базы.
4. Запусти `npm run check`, а если менялись экраны — `npm run check:e2e`. Покажи вывод красных проверок.
5. Если тебя попросили — допиши недостающие тесты в том же стиле, что соседние. Не ослабляй и не выключай существующие тесты никогда.

Отчёт: таблица «стык → тест → что проверяет → пробел», затем результат прогона.
