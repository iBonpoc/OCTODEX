# Правила области: e2e и проверки

Статус: действует · сверено 25.11.2026 · подгружается само, когда чат читает или правит `apps/mobile/e2e/**` или `.github/workflows/**`.

Источник строк: `A` — `docs/ai/BOARD-archive.md`, `B` — `docs/ai/BOARD.md`, `L` — `docs/ai/LOG.md` (номер — строка); выписка — `docs/notes/2026-11-25-board-lessons.md` §2. Частые ошибки тестов — `docs/ai/CHECKS.md` §9: они здесь не повторяются, читать там. Сюда уже не копировать: №1 (часы), №2 (старые надписи, `testID`), №3 (ждать то, что проверяешь), №8 (шторка не ушла), №10 (`seedOutbox`), №12, №15 (запись по условию), №22 (не ослаблять проверку), №27 (`doubleTapUntil`), №28, №31 (`toastArmMs`), №40, №46 (SVG — `textContent`), №49, §10 п.4–5.

## Поиск элементов
- У `Button`, `T`, `ListRow` своего `testID` нет — оборачивать во `View` с `testID`; у `Animated.View` (reanimated) на вебе `testID` теряется — вешать на вложенный `View` (A:239, 437, 450).
- На 820/1280 `getByText("Сметы")` ловит пункт бокового меню — искать по `testID` (A:92).
- Кнопку «Назад» не называть «Отменить»: e2e ищут тост по имени (A:97).
- Заголовок шторки — через `h.sheet()` (последняя открытая шторка) (A:68, 657).
- Стек Expo держит прошлый экран в DOM: брать только видимое (`locator("visible=true")`), карточки считать после `h.go`; `expectText` ищет и по скрытым экранам (A:603, 608, 657, 671).
- `aria-selected` на кнопке RN Web не выводится: у вкладок `aria-current`, содержимое ждать по `testID` (A:137, 163).
- Роли: `Segmented` — `tab`, `ChoiceChips` — `radio` (A:603).
- На 1280 строку списка открывать через `list-panel-open` (A:137).
- `h.text` склеивает текст через « | » (A:509). Время AM/PM может прийти с узким пробелом U+202F (A:352).

## Ожидание и состояние
- «PDF не создан» появляется не сразу — ждать по условию, не меньше 1 с (A:104).
- `h.go` — это `page.goto`, полная перезагрузка: «без сети» сбрасывается, ключи `localStorage` писать только после `h.go` (A:235, 509, 603).
- Поле поиска `FilterBar` складывается после blur — ждать `detached` (A:759).
- `safe-area-context` на вебе ставит отступы после CSS-перехода — ждать устойчивую раскладку (A:437).
- Двойной тап — двумя `click`, не `dblclick`: тот проваливается сквозь закрывающуюся шторку (A:627).
- Проверять разницу до и после действия, а не абсолютное число (A:479).

## Роли, язык, демо
- Роль переключать на `/today` (холст пишет состояние при уходе); `setRole` — после первого `h.go`; роль офиса — `"director"`; sales задавать при входе (`store.setRole` не даёт sales владельцу) (A:120, 383, 671, 696).
- «Нет $ у мастера» ловит бюджет клиента — проверять конкретную цену и только открытый экран (A:450, 696).
- Язык клиента задавать на клиенте (`es`); язык есть только у Person и Lead (A:603, 657).
- Демо пересевается при смене дня — на время демо не полагаться, свои выезды на свободного клиента (A:521, 690).
- Демо с облачным состоянием: поддельная сессия в `localStorage` и `page.route` на `*.supabase.co` (A:239). Офлайн в демо — переключатель на `/settings` плюс `pushState`; очередь в демо пишется только без сети (A:383, 627).
- Возврат на тот же замер — сохранить URL с `?m=` (A:375).

## Время
- `clock.install` — с настоящим `Date`; спеке со своим поясом — свой контекст `{ browser, BASE, layout }` и `ctx.clock.install`, как в спеке 58 (A:521, 676).
- Прогон с `E2E_NOW` около полуночи — с `--no-build` после одной сборки (A:521). Тесты дат проверять и около 00:30Z (A:552, 593).
- Тест, зависящий от часа, сверять и на чистом `main`: может быть красным и там (A:502).

## Раннер и облачные спеки
- Раннер падает на ошибке консоли: ответ 4xx/5xx в `page.route` отдавать 200 с `ok:false`/`error`; в облачной спеке — `allowConsole`; офлайн — подменой `fetch` (A:131, 156, 483).
- Флаги `e2e/run.cjs` — только через «=» (`--width=1280`) (A:163).
- Облачная спека локально: `dockerd` → `npx supabase@3.0.0 start -x studio,imgproxy,vector,logflare,supavisor,realtime,postgres-meta` → `db reset` → `scripts/cloud-seed.mjs` → `node e2e/cloud/cloud.cjs seed.json`; нужен `SUPABASE_SERVICE_ROLE_KEY`, спеке 206 — `DB_URL` (A:190, 212). Спека 114 зависит от порядка — гонять её локально перед сдачей (A:205).
- Снимок с «?» в имени не грузится в артефакт — переименовать (A:23).

## Сторожа и новые экраны
- Новый экран — во все сторожа: `SCREENS`, `tabBarRule`, `NO_FILTER`/`filterGuard`, `directReads`, `hierarchy`, `sections.test`, `routeRoles` (A:145, 190, 212).
- `serverContract` считает `admin.rpc` в Edge-функции вызовом приложения — звать через обёртку `rpc()` (A:156).
- Тест не должен проходить вхолостую: сломать правило в коде — тест должен упасть (A:235, 483; L:129–130). У сторожа — фикстура, которая падает (A:608, 620).

## Проверки на GitHub
- Половина «красных» — старые головы PR: в каждом событии CI сверять `head_sha` с головой PR (A:765, 770; B:278).
- Rule 22 не перезапускается правкой тела PR — `rerun-failed-jobs` по REST, не новый пуш (B:145, 255, 264; CHECKS §3а).
- Checks на `main` идёт 24+ минут, выпуск ждёт его — это не зависание (B:74).
- Edge runtime в песочнице без npm: проверка api-2 идёт только на GitHub (A:608).
