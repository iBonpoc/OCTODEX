# Правила области: платежи и деньги

Статус: действует · сверено 25.11.2026 · подгружается само, когда чат читает или правит функции Stripe, страницу клиента `/p/` или движок `packages/estimating-engine`.

Источник строк: `A` — `docs/ai/BOARD-archive.md`, `B` — `docs/ai/BOARD.md`, `L` — `docs/ai/LOG.md` (номер — строка); выписка — `docs/notes/2026-11-25-board-lessons.md` §3. Главное — `CLAUDE.md` правило 8 (деньги — целые центы, только через движок) и спека `docs/specs/35-stripe.md`; здесь только приёмы, которых там нет или которые там легко пропустить.

## Вебхук и события Stripe
- Подпись проверять по сырому телу; способ оплаты — из `expand`; комиссия — из balance transaction; сверять `metadata.company_id`; ошибка 55000 → ответ 500, чтобы Stripe повторил (A:143, 152).
- `account.updated` принимать по `created` события, а не по порядку прихода (A:201).
- Строки, привязанные этим же событием Stripe, блокировать и по нашему id (A:184).
- Откат упавшего возврата — только по подписанному событию Stripe (A:181).
- Правка платежа у void-счёта роняла обработку события (цепочка t85 → invoices) — проверять всю цепочку триггеров (A:184).

## Страница клиента и защита
- `/p/`: сверять токен ссылки со счётом (против IDOR); переиспользовать попытку с тем же PaymentIntent (A:143).
- Лимит запросов по адресу — только за промах, после проверки ссылки; иначе соседи по /48 блокируют друг друга (A:201; L:32).

## Деньги в данных
- Платёж нельзя мягко удалить (A:156).
- Отказ 55000 молча выбрасывал задаток: свой код (P0001) и перечитывание после отказа (L:126).
- Скидка в процентах: `Math.round(Number(x)*10000)` врёт на float — базисные пункты только через `discountBps` движка (A:126).
- Налог работы — снимок на момент записи, как t18 (A:603).
- В `calc_inputs` хранится одна копия документа; клиенту её режет `app.client_doc` на сервере (белый список). Не путать с `clientDoc` приложения (A:344).
