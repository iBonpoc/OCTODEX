# Правила области: офлайн-очередь и хранение на телефоне

Статус: действует · сверено 25.11.2026 · подгружается само, когда чат читает или правит `apps/mobile/src/data/**` или `apps/mobile/src/cloud/**`.

Источник строк: `A` — `docs/ai/BOARD-archive.md`, `B` — `docs/ai/BOARD.md`, `L` — `docs/ai/LOG.md` (номер — строка); выписка — `docs/notes/2026-11-25-board-lessons.md` §4. Главное — `CLAUDE.md` правило 6 (офлайн с первого дня) и 16 (старые версии не ломать), `docs/ai/CHECKS.md` §9 №6 (`classify`). Одна строка выписки помечена «не уверен» (№141) — не взята.

## Что ставить в очередь
- Мутацию, которую сервер точно отклонит, в очередь не ставить: 5 отказов стопорят очередь (A:68). Отказ останавливает очередь — человеку подсказка из `REJECT_REASONS` (RU/EN/ES, тест `rejectReasons.test`) (A:212).
- На сервер слать только изменённые поля: «null = стереть» опасно (A:84). «Сбросить» — `null`, «не знаю» — поля нет: JSON теряет `undefined` (A:450).
- Общий массив (`photo_ids`) сливать на сервере, а не перезаписывать с телефона (A:68).
- Зависимости операций — только серверные (`SELF_KINDS`) (A:483); порядок зависимых операций держать: новый лид раньше нового источника терялся (L:131).
- «Отменить» обратной операцией — с той же проверкой, что и прямая (A:603).
- `createdBy` для всех видов операций — через `Record<Op["k"]>`, чтобы TypeScript не пропустил новый вид (A:235).

## Ответы сервера
- Ошибка 22023 из операции — отказ (rejected), а не «застряло» (A:114).
- PostgREST 54* приходит как HTTP 500 — без разбора повтор идёт вечно (A:383).
- Запасное чтение по старому пути — только на ошибку «таблицы нет», не на любую (A:68).

## Хранение и старые версии
- Запись — сразу при уходе со страницы: правка за 250 мс до выгрузки терялась вместе с очередью (L:86).
- `persist.ts`: строгие ключи (outbox, queue, rejected) при порче — экран ошибки и «Сохранить копию» (`octo.broken.*`); нестрогие (кэш, роль) — старт заново (A:745).
- Стирание: `WIPE_PENDING` — полная «u1,u0» или «filter:u1,u0», метка «стёрто» `octo.wipe.done.v1`; повтор сначала зовёт `forgetSharedOps`; очередь `oneAtATime` запускается сразу (A:745).
- Новое значение, неизвестное старой версии (пример — пояс), может обнулить её сохранение — проверять, что старые сборки его переживут (L:128).
- Ручную правку определять сравнением с источником, а не флагом: старые версии флаг не ставят (A:375).
- Формы следуют за стором, пока их не тронули; «изменено» у шторки — только после правки (A:212, 603).
